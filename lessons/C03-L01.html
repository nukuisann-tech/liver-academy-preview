原本 03 §1　Characterは「作り物」ではない 原本内のタグ: [OFFICIAL]／[INFERENCE]

原本内のタグ[OFFICIAL]

TikTok公式教材では、キャラクターは無理に別人格を演じることではなく、自分が元々持つ強みを分かりやすく強調することとして扱われている。

原本内のタグ[INFERENCE]

Projectではこれを、

AUTHENTICITY × DISTINCTIVENESS

と定義する。

  • 本人らしいが普通すぎる → 記憶されにくい
  • 目立つが本人ではない → 維持できない
  • 本人らしく、かつ一言で差がある → 強い
原本 03 §3　強み診断｜SUSTAINABILITY × VIEWER VALUE 原本内のタグ: [OFFICIAL]／[EXPERT ADDITION]

原本内のタグ[OFFICIAL]

公式教材の強み診断では、話すこと、疲れず続けられること、周囲から褒められることなどから配信タイプを考える。

代表タイプ：

  • TALK
  • PERFORMANCE
  • KNOWLEDGE
  • CHARACTER

原本内のタグ[EXPERT ADDITION]

この4タイプを固定分類にせず、次で見る。

本人が続けやすい × 視聴者が価値を感じる × LIVEで参加しやすい

表現者では、

SKILL + PERSONA + STORY + RELATIONSHIP VALUE

まで見る。
