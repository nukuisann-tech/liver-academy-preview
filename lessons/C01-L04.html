原本 01 §9　成長ステージと目的 原本内のタグ: なし
Beginner｜成立させる

最初の課題：

  • 安定して配信開始できる
  • 自己紹介できる
  • 無言になりすぎない
  • コメントに反応できる
  • 初見を歓迎できる
  • 次回配信へつなげる
Intermediate｜コミュニティを作る

次の課題：

  • 常連が生まれる
  • 新規も入りやすい
  • 配信に定番がある
  • 参加が増える
  • ファンが目標を共有する
  • 売上が単発ではなくなる
Advanced｜システム化する

上位の課題：

  • LIVEを番組として設計する
  • 流入源を複数持つ
  • イベントを戦略的に配置する
  • 売上集中リスクを管理する
  • 高同接でも会話品質を保つ
  • 数字から自分で戦略転換する
  • ブランドと収益を統合する

Projectではこの成長を、

SELF → COMMUNITY → SYSTEM

と整理する。 [E]

原本 01 §10　「配信量」の正しい扱い 原本内のタグ: なし

TikTok公式教材では、配信時間と収益に一定の相関があること、上級を目指す参考値として月130時間以上というガイド例が紹介されている。 [A｜公式ヒューリスティック / Update-sensitive]

一方、他教材では月80時間、100時間など異なる目安も出ている。 [D]

したがって、Projectでは固定時間を普遍ルールにしない。

重要なのは、

HOURS ARE INPUT, NOT SUCCESS

配信時間を増やすと、

  • 新規に出会う機会
  • 関係を作る接触回数
  • 実験回数
  • 学習データ

は増えやすい。

しかし、疲労でトーク・表情・初見対応が崩れれば、長時間配信が逆効果になる。

見るべきは、

  • Revenue / Hour
  • Followers / Hour
  • New Gifters / Hour
  • Average Watch Time
  • Return
  • Creator Fatigue
  • 本業への影響

である。

Projectでは、

TOTAL VALUE × EFFICIENCY × SUSTAINABILITY

で配信量を評価する。 [E]

原本 01 §11　目標設定の原則 原本内のタグ: なし

目標は「トップライバーになる」のような抽象表現だけでは機能しにくい。

TikTok公式教材でも、フォロー増、いいね、配信時間等の具体的な小目標を置く考え方が示されている。 [A]

Projectでは3層に分ける。

Outcome Goal

結果目標。

例：

  • 月間Diamonds
  • フォロワー増
  • 平均同接
Process Goal

自分で制御しやすい行動。

例：

  • 週5配信
  • 初見へ毎回自己紹介
  • 1配信1つ改善
Capability Goal

スキル成長。

例：

  • コメント展開
  • 初見対応
  • ギフトリアクション

原則：

MONTH = OUTCOME / WEEK = ACTION / LIVE = EXPERIMENT
