原本 01 §12　データを見る目的 原本内のタグ: なし

データの目的は、自分を評価して落ち込むことではない。

次に何を直すか決めるために見る。

Projectの基本改善ループ：

SYMPTOM → METRIC → FUNNEL STAGE → ROOT CAUSE → ONE ACTION → RE-MEASURE

例：

症状

人は来るがすぐ離脱する。

Metric

平均視聴時間が弱い。

Funnel

RETENTION。

仮説

入室しても何の配信か分からない。

One Action

次の5配信で入室者向けOrientationを改善する。

Re-measure

平均視聴時間、コメント率、フォロー率を見る。

原則：

ONE BOTTLENECK → ONE PRIMARY CHANGE

複数の変数を一度に変えると、何が効いたか分からない。
