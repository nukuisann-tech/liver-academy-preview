原本 05 §12　参加設計｜LOW-FRICTION ACTION 原本内のタグ: [OFFICIAL]／[INFERENCE]

原本内のタグ[OFFICIAL]

投票はワンタップで参加できる基本的なインタラクションとして公式教材で扱われる。

原本内のタグ[INFERENCE]

参加の基本：

NOTICE → LOW FRICTION ACTION → AGENCY → VISIBLE OUTCOME → RECOGNITION → ANTICIPATION

参加コスト

低：タップ / 投票
中：コメント / シェア
高：ギフト / 長文 / 外部行動

まず低負荷から入れる。

原本内のタグ[CASE / INFERENCE]

WATCH → TAP → COMMENT → FOLLOW → RETURN → SHARE → JOIN → SUPPORT → ADVOCATE

MAKE PARTICIPATION EASY & REPEATABLE

原本 05 §14　視聴者をCo-creatorへ 原本内のタグ: [OFFICIAL / INFERENCE]

原本内のタグ[OFFICIAL / INFERENCE]

視聴者の選択が配信に反映されるとAgencyが生まれる。

例：

  • 次の話題を投票
  • 衣装選択
  • 罰ゲーム選択
  • クイズ
  • コメントから企画変更
FAKE PARTICIPATION TRAP

投票結果を毎回無視するなど、参加が結果へ影響しないと逆効果。

ASK → VOTE → RESULT → ACTION → ACKNOWLEDGE
