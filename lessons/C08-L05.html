原本 08 §7　GIFT ASSOCIATION MAP 柱　原本内のタグ: [CASE]

原本内のタグ[CASE]

ギフトアイコンから本人らしいリアクションを作る。

GIFT ICON → ASSOCIATION → PERSONA FIT → ACTION → LINE → PARTICIPATION

例：ヘルメット → 工事 / バイク → 動作 → セリフ。

表現者なら、

  • 俳優：短い演技
  • 声優：声色
  • ダンサー：固有ムーブ
  • アーティスト：短い音 / フレーズ

へ変換可能。
