原本 02 §7　画面設計｜BACKGROUND → FOREGROUND → COMPOSITION 原本内のタグ: [OFFICIAL]／[EXPERT ADDITION]

原本内のタグ[OFFICIAL]

TikTok公式教材では、最初の1秒の視覚情報として、背景・前景・構図が重要と説明されている。

背景
  • テーマ / 世界観が伝わる
  • 散らかりを減らす
  • 記憶に残るSignature Cueを1〜3個持つ
前景
  • 机・マイク・小物等で奥行き
  • 距離感・親密さを作る
構図
  • 目線
  • 顔のサイズ
  • 頭上余白
  • 中央配置 / 意図した配置

原本内のタグ[EXPERT ADDITION]

REMOVE ACCIDENTAL CLUTTER, KEEP INTENTIONAL CONTEXT

「生活感を全部消す」は誤り。車ライバーのガレージ、料理ライバーのキッチン、アーティストの作業部屋など、ブランドになる生活感は残す。

評価式

Cleanliness × Consistency × Identity Fit × Distinctive Cue

原本 02 §8　照明｜BEAUTYではなくEXPRESSION VISIBILITY 原本内のタグ: [OFFICIAL]／[EXPERT ADDITION]

原本内のタグ[OFFICIAL]

公式教材では、照明により顔の印象が大きく変わること、初心者は正面光から試すこと、まず現在の環境を確認してから必要なら機材を足すことが推奨されている。

基本
  • 顔が暗くならない
  • 逆光を避ける
  • 正面〜少し上からの光を試す
  • 目にキャッチライトが入る
  • 白飛びしない

原本内のタグ[EXPERT ADDITION]

LIVEで照明が重要な本質は、

LIGHTING → FACE READABILITY → EMOTIONAL COMMUNICATION

表情が読めるほど、リアクション・感情・人柄が伝わりやすい。

原本 02 §9　フィルター / 美肌 / 加工 原本内のタグ: [SOURCE]／[EXPERT ADDITION]

原本内のタグ[SOURCE]

教材では「加工はマナー」という強い表現があった。

原本内のタグ[EXPERT ADDITION]

Canonical化するなら、

加工はマナーではなく、視認性を整えることがマナー。

Guardrail

ENHANCEMENT ≤ AUTHENTICITY

  • 暗さ補正：有効
  • 不自然な肌補正：注意
  • 本人と別人になる加工：ブランド毀損リスク

表現者ではSNS / オフライン / 作品での本人との乖離が大きすぎないこと。

原本 04 §2　最初の1秒｜VISUAL PROMISE 原本内のタグ: [OFFICIAL]

原本内のタグ[OFFICIAL]

TikTok公式教材では、最初の1秒の画面構成を重要視している。

入室前後の画面で伝えるもの：

  • 誰が主役か
  • どんな空気か
  • 何のテーマか
  • 見続けても不快でないか
本質

FIRST IMPRESSION = RAPID PERCEPTION

「0.5秒」「1秒」など厳密値を普遍則にせず、非常に短時間で判断されるという原理を使う。

原本 03 §6　Visual / Audio Identity 原本内のタグ: [OFFICIAL / INFERENCE]

原本内のタグ[OFFICIAL / INFERENCE]

公式教材では、背景・照明・画角・BGM等の一貫性が、印象と記憶に影響することが示されている。

Projectでは、

CONSISTENCY → RECOGNITION → ASSOCIATION → MEMORY → RETURN CUE

と整理する。

Signature Cue例
  • 固有のライト
  • 背景小物
  • ガレージ
  • 花
  • マイク
  • 特定の冒頭フレーズ
  • 特定のBGM（権利範囲内）
