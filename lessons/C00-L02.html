原本 01 §9　成長ステージと目的 原本内のタグ: なし
Beginner｜成立させる

最初の課題：

  • 安定して配信開始できる
  • 自己紹介できる
  • 無言になりすぎない
  • コメントに反応できる
  • 初見を歓迎できる
  • 次回配信へつなげる
Intermediate｜コミュニティを作る

次の課題：

  • 常連が生まれる
  • 新規も入りやすい
  • 配信に定番がある
  • 参加が増える
  • ファンが目標を共有する
  • 売上が単発ではなくなる
Advanced｜システム化する

上位の課題：

  • LIVEを番組として設計する
  • 流入源を複数持つ
  • イベントを戦略的に配置する
  • 売上集中リスクを管理する
  • 高同接でも会話品質を保つ
  • 数字から自分で戦略転換する
  • ブランドと収益を統合する

Projectではこの成長を、

SELF → COMMUNITY → SYSTEM

と整理する。 [E]

原本 10 §3　Session Diagnosis 原本内のタグ: [OFFICIAL / INFERENCE]

原本内のタグ[OFFICIAL / INFERENCE]

公式教材では、症状→見る数字→原因→改善という診断思想が示されている。

Projectでは、

SYMPTOM → METRIC → FUNNEL STAGE → ROOT CAUSE → ONE ACTION → RE-MEASURE

と定義。

症状例
視聴者が少ない

見る：

  • 配信時間
  • タイトル / テーマ
  • Entry
最初にすぐ離脱

見る：

  • Avg watch
  • 0〜30秒
  • Visual / Audio
盛り上がらない

見る：

  • Peak concurrent
  • Comments
  • Active viewers
応援が弱い

見る：

  • Gifters
  • Repeat gifters
  • Diamonds
一方通行

見る：

  • Comments
  • Active viewers
  • Likes
