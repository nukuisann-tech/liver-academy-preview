原本 03 §6　Visual / Audio Identity 原本内のタグ: [OFFICIAL / INFERENCE]

原本内のタグ[OFFICIAL / INFERENCE]

公式教材では、背景・照明・画角・BGM等の一貫性が、印象と記憶に影響することが示されている。

Projectでは、

CONSISTENCY → RECOGNITION → ASSOCIATION → MEMORY → RETURN CUE

と整理する。

Signature Cue例
  • 固有のライト
  • 背景小物
  • ガレージ
  • 花
  • マイク
  • 特定の冒頭フレーズ
  • 特定のBGM（権利範囲内）

CORE FIXED × EDGE EVOLVES
