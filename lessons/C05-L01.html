原本 05 §1　LIVEはプレゼンではない 原本内のタグ: [OFFICIAL]／[INFERENCE]

原本内のタグ[OFFICIAL]

TikTok公式教材では、配信は一方的なプレゼンではなく、一緒に時間を過ごす感覚が重要とされている。

原本内のタグ[INFERENCE]

LIVEトークの目的は、

SPEAKING → INTERACTION → RELATIONSHIP

である。

話が上手くても、視聴者が入れないならLIVEとして弱い。

原本 05 §2　HOST-LED CONVERSATION LOOP 原本内のタグ: [CASE]

原本内のタグ[CASE]

実践者インタビューでは、

「コメントが来たから喋る」ではなく、「ライバーが投げかけ、視聴者がコメントする」

という姿勢が共有された。

Projectでは、

PROMPT → COMMENT → RESPONSE → EXPANSION → NEXT PROMPT

と定義する。

コメント待ち配信から脱却する。
