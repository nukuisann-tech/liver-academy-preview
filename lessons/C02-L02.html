原本 02 §6A　LIVEタイトル｜PRE-ENTRY EXPECTATION 原本内のタグ: [OFFICIAL]／[EXPERT ADDITION]

原本内のタグ[OFFICIAL]

TikTok公式教材では、LIVEタイトルは「おすすめ」等でLIVEを見かけた際に表示される、配信内容を事前に伝える入口情報として扱われている。

本質は挨拶や自己紹介を書くことではなく、

「今、何をしている配信か」を入室前に理解させること。

良いタイトルの条件
  • 今していることが分かる
  • 初見が参加方法を想像できる
  • 配信内容と実際の体験が一致する
  • 必要なら対象者・状況が分かる

例：

  • 初配信｜コメントもらえると嬉しい
  • 【初見歓迎】雑談｜コメントしてね
  • 深夜雑談｜無言OK・作業BGMにも
  • 舞台稽古終わり｜役作り相談
弱いタイトル
  • 挨拶だけ：「おはよう」「今日もよろしく」
  • 属性だけ：「新人です」「会社員」「留学生」
  • 気分だけ：「眠い」「疲れた」
  • 絵文字だけ
  • 自信のなさだけ：「試し配信」「うまく話せません」

これらは「何を見るLIVEか」の情報量が少ない。

原本内のタグ[EXPERT ADDITION]

タイトルはPRE-ENTRY ORIENTATIONであり、入室後のOpeningと一貫させる。強いタイトルでも実際のLIVEが別内容ならExpectation mismatchで離脱要因になる。

原本 02 §6B　LIVEカバー｜OPTIONAL VISUAL PROMISE 変わる仕様原本内のタグ: [OFFICIAL / UPDATE-SENSITIVE]／[EXPERT ADDITION]

保存時点の情報です。現在の条件は TikTok の公式案内で確認してください

原本内のタグ[OFFICIAL / UPDATE-SENSITIVE]

保存されたTikTok公式教材では、LIVEカバー画像は必須ではなく、デフォルト表示で配信するCreatorも多いと説明されている。設定する場合は、第一印象を補強するVisual Assetとして扱う。

設定する場合の基本
  • 顔・主役が分かりやすい
  • 明るく潰れていない
  • LIVE内容・ブランドと一致する
  • スマホの小さい表示でも意味が伝わる
避ける
  • 暗すぎる
  • 主役が分からない
  • LIVE内容と無関係
  • カバーの印象と本番画面が大きく違う

原本内のタグ[EXPERT ADDITION]

TITLE = WHAT PROMISE / COVER = VISUAL PROMISE

カバーは必須施策ではない。設定コストより、タイトル・配信画面・Opening改善の方がボトルネックならそちらを優先する。

判断基準

原本内のタグ[EXPERT ADDITION]

形式は「使える機能」ではなく、提供価値と運営能力に合うかで決める。

  • 表情・人物ブランドが価値 → カメラ中心

  • ゲームそのものが価値 → Game形式

原本 04 §1A　入室前からFIRST IMPRESSIONは始まっている 原本内のタグ: [OFFICIAL / INFERENCE]

原本内のタグ[OFFICIAL / INFERENCE]

ENTRYはLIVE画面に入ってから始まるわけではない。LIVEタイトル・カバー・アイコン・プロフィール等のPRE-ENTRY PACKAGEが、「入る / 入らない」の期待形成に影響する。

PRE-ENTRY PROMISE → ENTRY → ON-SCREEN CONFIRMATION

タイトルで「何をしているか」を約束し、入室直後の画面とOpeningでその約束をすぐ確認できる状態が理想。詳細は 02_ACCOUNT_AND_LIVE_PREPARATION.md。
