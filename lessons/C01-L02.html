原本 01 §4　MASTER GROWTH FUNNEL 原本内のタグ: なし

TikTok LIVEの成長を、Projectでは以下のファネルで捉える。

DISCOVERY → ENTRY → FIRST IMPRESSION → RETENTION → ENGAGEMENT → RELATIONSHIP → FOLLOW → RETURN → FANDOM → MONETIZATION → ADVOCACY

この順番が重要である。

売上が弱いからといって、必ずしも「ギフト訴求」が問題とは限らない。

例えば、

  • DISCOVERYが弱ければそもそも人が来ない
  • ENTRYが弱ければ露出されても入室されない
  • RETENTIONが弱ければすぐ帰る
  • RELATIONSHIPが弱ければ再訪しない
  • FANDOMが弱ければ継続支援につながらない

したがって、改善はファネル上のボトルネックを探して行う。

原本 01 §5　各ファネルの意味 原本内のタグ: なし
5.1 DISCOVERY｜見つけてもらう

主な入口：

  • TikTok LIVEおすすめ
  • ショート動画
  • フォロー中ユーザー
  • コラボ / バトル
  • ランキング / イベント
  • 切り抜き
  • 外部SNS

ここでは「露出量」が重要。

ただし露出があっても、次のENTRYが弱ければ成果にならない。

5.2 ENTRY｜入室してもらう

視聴者は、LIVEを表示されたあと「入る / 入らない」を判断する。

影響要素の例：

  • 顔・表情
  • 背景
  • 画面の明るさ
  • タイトル / テーマ
  • 本人のキャラクター
  • 動き
  • 何をしている配信か理解できるか

Projectでは、入口の考え方を次の式で整理する。

EXPOSURE × ENTRY RATE = ENTRANTS

これはTikTok公式指標の式ではなく、成長診断用の概念モデルである。 [E]

「人が来ない」を、露出不足と入口不足に分けて考えられる。

5.3 FIRST IMPRESSION｜入った瞬間に意味を伝える

入室者は短時間で、

  • 誰なのか
  • 何をしているのか
  • 自分がいてよい場所か
  • 面白そうか
  • コメントできそうか

を判断する。

このため、初見対応では次を早く伝える。

IDENTITY → ACTIVITY → VALUE → PARTICIPATION CUE

例：

「こんばんは、舞台俳優の○○です。今日は次の役作りについてみんなに相談してます。初見さんも“どっち派？”ってコメントしてね。」

人物・テーマ・見る価値・参加方法が一度に伝わる。

5.4 RETENTION｜居続けてもらう

滞在は、「帰らせない」ことではない。

帰れない配信ではなく、帰りたくない配信を作る。

滞在に影響する代表要素：

  • 入室後すぐ内容が分かる
  • 会話が止まらない
  • コメントが拾われる
  • 自分も参加できる
  • この先に何か起こりそう
  • 感情の変化がある
  • 企画・目標・進捗がある
  • 内輪だけで会話していない

TikTok公式はLIVE推薦において視聴時間等のユーザー反応を利用すると説明している。 [A]

ただし「平均視聴時間が唯一の最重要指標」「○分ならおすすめに載る」といった固定ルールは扱わない。

5.5 ENGAGEMENT｜見る人から参加する人へ

参加のハードルには段階がある。

例：

  • タップ / いいね
  • 投票
  • コメント
  • フォロー
  • シェア
  • ファンクラブ等
  • ギフト

重要なのは、いきなり最も負荷の高い行動だけを要求しないこと。

Projectの基本モデル：

WATCH → TAP → COMMENT → FOLLOW → RETURN → SHARE → JOIN → SUPPORT → ADVOCATE

これを PARTICIPATION LADDER と呼ぶ。 [E]

5.6 RELATIONSHIP｜「誰か」から「知っている人」へ

関係構築では、視聴者が「自分を認識してもらえた」と感じる体験が重要になる。

代表的な行動：

  • 名前を呼ぶ
  • 前回の話を覚える
  • コメントへ質問で返す
  • 変化に気づく
  • 感謝を具体的に伝える

Projectでは、名前呼びの役割を2つに分ける。

  • 新規：ATTENTION CAPTURE
  • 再訪者：RELATIONSHIP CONFIRMATION

同じ行動でも、ファネル上の役割が違う。 [E]

5.7 FOLLOW｜つながりを残す

フォローは「ファン化完了」ではない。

フォローは、次に本人へ再接触する確率を上げる接点の1つ。

フォローを促す場合も、単なる「フォローして」ではなく、

  • 次回配信
  • 続きの企画
  • 定期テーマ
  • 本人の目標

など、フォローする理由を与える。

5.8 RETURN｜再訪

強いLIVEは、1回の視聴を最大化するだけではなく「また来る理由」を作る。

代表的な再訪要因：

  • 次回日時が分かる
  • 続きがある
  • 自分の名前・話を覚えてくれている
  • 常連儀式がある
  • 配信に居場所を感じる
  • 応援したいストーリーがある

終了時には、

感謝 → 次回予定 → 次回の見どころ

まで行う。

5.9 FANDOM｜この人を応援したい

ファンは、単に「よく見る人」ではない。

Projectでは、ファンダム形成を以下で捉える。

Recognition → Participation → Agency → Co-creation → Belonging → Return → Fandom

強いファンダムでは、視聴者が、

  • 自分も場に影響している
  • 仲間がいる
  • 本人の物語を一緒に追っている
  • 自分の応援に意味がある

と感じる。

5.10 MONETIZATION｜支援を売上へ変える

収益は、Relationshipの下流にある。

MONETIZATION IS DOWNSTREAM OF RELATIONSHIP DESIGN

Projectの重要原則である。 [E]

ギフトを「お願い」だけで生むのではなく、

  • 参加したい
  • 応援したい
  • 自分の貢献が見える
  • 目標が分かる
  • リアクションが楽しい
  • ストーリーを進めたい

という構造を作る。

5.11 ADVOCACY｜ファンが新しい人を連れてくる

最上流へ再び戻る段階。

  • シェア
  • 友人紹介
  • 切り抜き
  • SNSでの言及
  • コミュニティ内で新規歓迎

ファン自身がDiscoveryを作るようになる。

ここまで来ると、成長は直線ではなくFlywheelになる。

原本 01 §6　GROWTH FLYWHEEL 原本内のタグ: なし

ファネルは診断には便利だが、実際の成長は循環する。

DISCOVERY → ENTRY → RELATIONSHIP → FANDOM → SUPPORT → ADVOCACY → NEW DISCOVERY

この循環が強くなるほど、毎回ゼロから集客する必要が減る。

原本 01 §7　同接を理解する基本モデル 原本内のタグ: なし

第三者教材では「滞在時間 × 流入人数 = 同時視聴者数」という考え方が提示された。

Projectでは数学的に少し正確にして、概念上以下で捉える。

平均同接 ≒ 1分あたりの流入人数 × 平均滞在時間（分）

例：

  • 1分あたり20人入室
  • 平均3分滞在

なら概念上の平均同接は約60人。

平均滞在が6分になれば、流入速度が同じでも約120人になる。

この式はTikTok公式の算出式ではない。同接改善の2レバーを理解するためのProjectモデルである。 [E]

つまり、同接改善の基本は、

  1. MORE PEOPLE IN
  2. KEEP THEM LONGER

である。

原本 01 §8　TikTok LIVE成長の4レイヤー 原本内のタグ: なし

Projectでは、成長を以下4層で見る。

8.1 Reach｜広げる
  • Discovery
  • Exposure
  • Entry
  • New viewers
8.2 Experience｜整える
  • First impression
  • Retention
  • Talk
  • Participation
8.3 Relationship｜深める
  • Follow
  • Return
  • Recognition
  • Belonging
  • Fandom
8.4 Monetization｜収益化する
  • First gifter
  • Repeat gifter
  • Revenue
  • Events
  • Supporter health

TikTok公式教材でも「広げる→整える→深める→収益化する」という方向性が示されている。 [A]

この順番は、売上だけを先に追わないための重要な診断軸になる。

原本 06 §1　Retentionの基本式 原本内のタグ: [INFERENCE]

原本内のタグ[INFERENCE]

同接は概念的に次で理解すると分かりやすい。

平均同接 ≒ 1分あたりの流入人数 × 平均滞在時間（分）

厳密なTikTok内部式ではないが、配信診断の考え方として重要。

例：

  • 1分20人流入 × 平均3分 = 約60人
  • 1分20人流入 × 平均6分 = 約120人

同接改善には、

  1. MORE PEOPLE IN
  2. KEEP THEM LONGER

の2レバーがある。
