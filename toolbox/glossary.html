用語辞書

原本 18 の全用語です（原文のまま）。仕様に関わる語は変わることがあります。

CO-HOST

複数Creatorが同一LIVE体験を作るTikTok LIVE機能群。仕様はUpdate-sensitive。

CREATOR LEAGUE

TikTok LIVEの収益力等をもとにしたランク機能。階級・報酬・ルールはUpdate-sensitive。

DIAMONDS

TikTok LIVEでCreator側の収益・Rewardに関連して用いられる単位。Coins / Gift / 最終受取額と同一ではなく、換算・条件は最新公式確認。

FAN CLUB

TikTok LIVEのファン参加・Mission・Benefit等に関連する機能。Heart Me等との関係は最新仕様確認。

HEART ME

LIVE Fan Club参加等に関連して使われるGift / 機能名。価格・効果はUpdate-sensitive。

LIVE MATCH

Creator同士が対戦形式で配信するTikTok LIVE機能。一般にBattleと呼ばれる。ルールはUpdate-sensitive。

ADVOCACY

ファンが自発的に紹介・シェア・切り抜き等を行い、新規認知を生む状態。

AFTERCARE

イベント・コラボ・バトル後の感謝・振り返り・次回接続。

ANTICIPATION

「このあと何が起こるか見たい」という期待。

AUDIENCE ACTIVATION LADDER

Viewer→Free Action→Micro Support→Repeated Participation→Event Support。

BATTLE DOSAGE

バトル頻度を固定回数でなくAudience / Content / Revenue / Fatigueで決める考え。

BELONGING

視聴者が「この場所の一員」と感じること。

BRAND FIT

施策が本人のブランドと一致している度合い。

CATEGORY WEDGE

本人資産×カテゴリー×LIVE体験×獲得経路から、記憶されるポジションを取る戦略。

CLIQUE TRAP

常連文化が閉鎖化し、新規が入りにくくなる状態。

CLIPPABILITY

LIVEの瞬間が切り抜きとして単独でも理解・共有されやすい性質。

CO-CREATOR

視聴者が投票・コメント・ギフト等で配信展開に影響する状態。

COMMENT DEPTH

1コメントが何ターンの会話へ展開したかを見る概念。

COMMENT EXPANSION TREE

コメント→返答→深掘り→自己開示→全体話題へ広げる型。

COMMUNITY LAYERS

Open / Active / Core Operations等、課金額ではなく役割でコミュニティを分ける考え。

CONTROLLED FIELD EXPERIMENT

LIVE現場で主変数を1つに絞って行う実験。

CREATOR NETWORK CAPITAL

コラボ相手・同業・メンター等の関係資産。

CREATOR SOVEREIGNTY

高額支援者等に意思決定権を渡さず、ライバー自身が配信を主導すること。

CTA ROTATION

同じ行動依頼を複数の意味・角度で伝える方法。

DISCOVERY

TikTokおすすめ・投稿・コラボ等で認知される段階。

ENTRY

視聴者がLIVEルームへ入る段階。

EVENT FATIGUE

イベント頻度・課金負荷等が高くなり、ファンの反応が弱る状態。

EVENT MEMORY LOOP

参加→達成→記録→後日再提示→感情再想起→関係強化。

EVENT READINESS SCORE

Audience / Relationship / Support / Momentum / Fatigueからイベント適期を評価する仮説モデル。

FANDOM

関係性・所属・応援理由を持つファン集団。

FAN HEAT

ファンの前向きな熱量。Fan Pressureとは区別。

FAN PRESSURE

応援が義務や圧力に変化した状態。

FATIGUE CLIFF

配信時間増加により品質・効率が急低下する地点。

FIRST IMPRESSION

入室直後に形成される視覚・人物・雰囲気の初期評価。

GIFT ASSOCIATION MAP

ギフト見た目→連想→Persona Fit→Action→Line→Participationでギフリアを作る方法。

GIFT TEMPERATURE

ギフトが金額以上に「意味ある出来事」として感じられた度合い。

GIFTRIA

ギフトリアクションの略。ギフトへの反応・演出。

GOAL GRADIENT / COMPLETION MOTIVATION

ゴール接近に伴い達成動機が強まりやすい現象として扱う概念。

GUARDRAIL KPI

Primary KPIを改善する際に壊してはいけない副次指標。

HOME WARMTH × OPEN DOOR

常連に居心地がよく、新規にも開かれたコミュニティ状態。

INTERACTION BANDWIDTH

同じ状況に対して持つ反応・会話展開の幅。

LIVE DRAMATURGY

Promise→Build→Participation→Peak→Payoff→Next HookでLIVEを番組化する考え。

LIVE MOMENT

TikTokの特別日 / 記念日向け公式機能。仕様はUpdate-sensitive。

MARGINAL HOUR VALUE

追加1時間の配信が生む追加価値。

MICRO COMMITMENT

低負荷行動から参加を始める設計。強制ではなく自発参加を前提。

MONETIZATION PERIODIZATION

Build→Activate→Unite→Peak→Recover等、収益訴求を期分けする考え。

MONETIZATION RHYTHM

Goal→Participation→Contribution→Recognition→Recoveryの収益リズム。

MOMENTUM HARVEST

コミュニティの勢いが高い時に強いイベントを配置する考え。

NEW VIEWER ORIENTATION

入室直後にIdentity / Activity / Value / Participationを理解させること。

OPEN CONTEXT RULE

常連だけに分かる話を、新規も理解できる公開文脈へ翻訳するルール。

PARTICIPATION LADDER

Watch→Tap→Comment→Follow→Return→Share→Support→Advocate。

PAYWALLED BELONGING

課金しないと所属感・会話参加が得られない状態。

PEAK DENSITY

単位時間あたりの意味ある感情ピークの密度。

PRIMARY KPI

今回の改善施策の勝敗判定に使う主指標。

RECOGNITION WITHOUT HIERARCHY

貢献差は認識しつつ、人間価値を支払額で序列化しない考え。

RETENTION

視聴者がLIVEに滞在すること。

RETURN

次回以降に再訪すること。

REVENUE CONCENTRATION RISK

売上が少数ギフターに偏るリスク。

REVENUE WAVE DESIGN

Build / Peak / Recovery等、売上に意図的な波を作る運用。

RITUAL

枠独自の繰り返し習慣・合図・定番行動。

SIGNATURE CUE

背景・フレーズ・動作等、本人を思い出す固有手掛かり。

SOCIAL PRESENCE

「自分が認識され、この場に影響している」という感覚。

STABLE SHELL × FRESH CORE

基本構成は固定し、内容・驚きを更新する設計。

SUPPORTER CONFIDENCE

「この人は継続して活動する」という安心が支援意欲を支える考え。

SUPPORT LOAD

Financial / Attendance / Emotional / Action / Socialのファン負担。

SUPPORT LADDER

見る→参加→所属→支援→共同達成へ段階化するモデル。

TALK GYM

会話・初見・コメント展開を反復練習するLearning UX概念。

WARM ENTRY

動画等で人物理解した上でLIVEへ入る状態。
