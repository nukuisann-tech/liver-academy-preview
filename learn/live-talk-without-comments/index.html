会話・参加

話すのが苦手でも配信できる。沈黙とコメント不足を乗り越える、LIVE会話術

  • 原本：プロから学ぶ！コミュニケーション術

「面白い話をし続ける」ことと、「視聴者が楽しめる会話の場をつくる」ことは違います。話題の準備、コメントゼロでも進む自走トーク、コメントの広げ方、人数に応じた進行まで。配信中に見られる「会話カンペ」も作ります。

コメントが止まると、頭が真っ白になる

こんなことで迷っていませんか。

  • 一人で話すのが苦手。話題がすぐ終わる
  • コメントがないと、何も話せない
  • 「誰かコメントして」と言ってしまう
  • コメントに答えても、そこで終わる
  • 常連一人としか話せない
  • コメントが多くて、全部拾えない

コメントが少ないのは、あなたがつまらないからとは限りません。見ながら別のことをしている、初めて来て様子を見ている、その話題では言うことがない——理由はさまざまです。変えられるのは、話題の準備・コメントの広げ方・今の状況の伝え方の3つです。

LIVEに必要なのは、お笑い芸人のような話術だけではありません。視聴者が聞いて楽しめて、参加したい時に参加できる時間をつくること。目指すのは「会話がうまい人」ではなく、「会話の場をつくれる人」です。

解決すると、こんな状態へ

コメントが止まっても、手元のカンペにある話題を自分の言葉で続けられます。コメントが来たら、一言で終わらせずに部屋全体の話へ広げ、途中から来た人にも今の話題を伝えられます。少ない日も多い日も、会話の場を保てるようになります。

たとえば、学んだあとのアカリさん（架空）。

  • コメントゼロの時間に、「最近買ってよかったもの」の話を自分の言葉で続ける。
  • 1つ届いたコメントを、「みんなは？」と部屋へ広げる。
  • 途中から来た人に「今ちょうど、買ってよかったものの話をしてたところ。ゆっくりしていってね」。

「面白いことを言わなきゃ」と焦る人から、「視聴者がまた来たくなる会話の場をつくれる人」へ。

攻略ノート

このコンテンツで学べること

  1. 01

    会話の場には、2つのモードがある

    コメントがなくても進める「自走トーク」と、来たコメントを取り込む「参加型トーク」。

    LIVEに効く理由コメント待ちで止まらずに済みます。

    だからコメントゼロの時間も、怖くなくなる

  2. 02

    話題は、体験・気持ち・気づきで育てる

    何があった？ どう感じた？ どこが意外？ みんなにも共通する所は？

    LIVEに効く理由一言で終わっていた話が、会話になります。

    だから準備した話題1つで、しばらく話せる

  3. 03

    コメントは、受け取って部屋へ広げる

    受け取る → 反応する → 本人へ返す → 自分の言葉を足す → 必要なら全体へ。

    LIVEに効く理由1人との会話が、部屋全体の話題になります。

    だから常連も初めての人も、同じ話題で楽しめる

  4. 04

    人数で、進め方を変える

    コメントする人が0人・1人・数人・多い時で、配信者の役割が変わる。

    LIVEに効く理由全部拾おうとして止まらずに済みます。

    だから少ない日も多い日も、会話の場を保てる

学んだ先に変わること

  1. 配信者がすること配信前に話題を準備し、コメントがなくても自分の言葉で進められる
  2. コメントを一言で終わらせず、部屋全体の話へ広げられる
  3. 視聴者見るだけでも楽しめ、途中から来ても今の話題が分かる
  4. LIVE会話が途切れにくく、また来たくなる時間が増える（約束ではない）
  5. その先カンペと振り返りが積み上がり、返しの引き出しが毎回増える
  6. 「面白いことを言わなきゃと焦る人」から、「会話の場をつくれる人」へ

話がうまい人を目指すより、視聴者が自然に楽しめる会話の場をつくる。

秒数や手順は練習のための例です。コメント管理の機能の名前や操作は変わることがあります。

まずは、「面白い話をしなきゃ」という考え方から変えます。

「面白い話をしなきゃ」を、変える

LIVEは、上手に話を披露する場というより、一緒に時間を過ごす場です。そして「面白い」には、いくつもの種類があります。

  1. 1笑える

    失敗談や、ちょっとした出来事で笑える。

  2. 2共感できる

    「わかる」と思える。

  3. 3知らないことを知る

    へえ、と思える情報や体験。

  4. 4人柄を知る

    この人はこう考えるんだ、が分かる。

  5. 5一緒に考える

    どっちがいいか、みんなで考える。

  6. 6ほっとする

    安心して過ごせる心地よさ。

全員が、いつも笑いを取る必要はありません。

スタイルたとえば
にぎやか失敗談を明るく話す
落ち着き仕事終わりに、今日あったことをゆっくり話す
趣味型好きな映画や旅行について話す

  1. A自走トーク

    コメントがなくても、自分から話を進める。

  2. B参加型トーク

    コメントが来たら、話題に取り込む。

この2つを、状況に合わせて切り替えられることが大切です（この記事で使う考え方の枠です）。

コツ

最初にやること

自分のLIVEで、視聴者に感じてほしいことを1つ選びます。「笑ってほしい」「落ち着いて過ごしてほしい」「一緒に考えてほしい」。ここが、話し方の出発点です。

例

どこから読む？（悩み別）

  • 話題がすぐ終わる → 「配信前に、話題を準備する」

  • コメントがないと何も話せない・「誰かコメントして」と言ってしまう → 「コメントゼロでも進む自走トーク」

  • 緊張で頭が真っ白になる → 「自走トーク」の最後の「緊張で真っ白になった時」

  • コメントに答えても、そこで終わる → 「コメントは受け取って終わりにしない」

  • 常連一人としか話せない → 「1人との会話を、部屋全体の話題に」

  • コメントが多くて全部拾えない → 「コメントの量で、進め方を変える」

  • 始めたばかりなら：話題の準備 → 自走トーク → 最後の会話カンペ（最初の3欄）だけでOK

次に、話す材料を準備します。

配信前に、話題を準備する（まずは1つ）

  1. 1今日の出来事

    「今日、コンビニでちょっと面白いことがあって……」

  2. 2自分の好きなもの

    「最近、昔の映画にハマっていて……」

  3. 3誰でも想像しやすい話題

    「休日って、家でのんびりする派？ 外に出る派？」

最初から3つ全部を使わなくて大丈夫。まずは1つを、自分の言葉で広げられることが大事です。

話題を育てる4つの問い

  1. 何があった？

  2. 自分はどう感じた？

  3. どこが意外だった？

  4. 視聴者にも共通する所は？

話題の広げ方

  • 今日の出来事

    よくない
    「今日コンビニ行ったんですよ。以上です」
    より良い
    「今日コンビニに行ったら、いつも買ってる飲み物が売り切れてて。仕方なく違うものを買ったら、意外とおいしかったんですよ。たまには違うものを選ぶのもいいですね」
    上級の言い方
    （上の話のあとに）「みんなにも、つい買っちゃう定番ってあります？ ちなみに私のもう一つの定番は……」（開いても、返事を待たずに続けられる）
一段上の攻略ポイント話題が尽きない人は、何を準備している？話題と返しの引き出しを、配信の前に増やせるようになります。深掘りする ＋閉じる －

今覚えたこと：話題は、体験・気持ち・気づきで育てる。

注意

即興力は、才能だけではない

その場でうまく返せる人も、多くは準備の量で支えられています。

  1. 1日常をメモする

    出来事 → 気づいたこと → 配信での話し方、を1行ずつ。

  2. 2よく来るコメントへの返しを用意

    「仕事終わった」「初見です」「久しぶり」などに、自分らしい返しを2つずつ。

  3. 3シリーズにする

    「今週の小さなうれしいこと」のような、毎回の定番トーク。前回の続きも話題になる。

ここが要点

判断できること

話題が尽きるのは、話す力が足りないからではなく、材料のストックが少ないからかもしれません。

次のLIVEでは：よく来るコメント1つに、返しを2通り用意しておきます。

話題ができたら、コメントがなくても進める練習です。

コメントゼロでも進む「自走トーク」と、緊張した時

自走トークの基本形

  1. 1

    テーマを伝える

  2. 2

    自分の体験を話す

  3. 3

    その時の気持ち

  4. 4

    小さな気づき・意見

  5. 5

    必要なら、みんなへ開く

  6. 6

    反応がなくても、次へ

90秒くらいの練習の例（ぴったり90秒でなくていい）

  1. テーマ（0〜15秒）

    「今日は、最近買ってよかったものの話をします」

  2. 体験（15〜45秒）

    「この前、ちょっと高めのマグカップを買ったんです。最初は高いかなと思ったんですが……」

  3. 気持ちと気づき（45〜70秒）

    「毎日使うものだから、意外と満足度が高くて。ちょっとしたものでも気分が変わるんだなと思いました」

  4. 開く（70〜90秒）

    「みんなにも、買ってよかったものってあります？」——コメントがなければ、「ちなみに次に気になっているのは……」と自分の話を続ける。

こんな時言えること
1つ目の話題が尽きた「今の話で思い出したんだけど、もう1つ話してもいい？」と話題2へ
準備した話題を全部使った「さっきのマグカップの話、実は続きがあって……」と、前の話を深掘りするか戻る
次の話題を考えたい「今、次の話題をメモで確認してます」と、していることを実況する
自分で問いかけて、答えがない「どっちにしよう。私は右かな、理由はね……」と、自分で答えて進む
話している途中で誰か入ってきた「あ、こんばんは！ 今ちょうど、買ってよかったマグカップの話をしてたところです。続けますね——」（一文で伝えて、元の話に戻る）

驚いた時の一瞬の間や、表情・相づちは、見せていい「間」です。入ってきたばかりの人に、名前や出身を続けて聞くのはやめます。「家派か外派か、一言でどうぞ。見てるだけでも大丈夫」のように、答えなくていい参加の仕方を1つ示すのはOKです。

コメントがない時

  • 静かになった時

    よくない
    「誰かコメントして！」「何か話して！」をくり返す
    より良い
    まず自分から話題を出し、コメントが来たら取り入れる

ここが要点

コメントゼロは、失敗ではない

見ながら別のことをしている、話すタイミングを待っている、初めてで様子を見ている——コメントがない理由はさまざまです。直すとしたら、沈黙そのものより、今何をしているか分からない時間が続いていないかです。

コツ

緊張で真っ白になった時

話題メモを見る → 今何を話していたか思い出す → 「ちょっと緊張しちゃったので、今日話そうと思ってた話題に戻りますね」と短く整える → 次の話題へ。緊張を必ず説明する必要はありません。続けるのが強い負担になっている時は、無理に続けなくて大丈夫です。

では、コメントが来た時です。

コメントは「受け取って終わり」にしない

コメントの5ステップ

  1. 1

    受け取る

    コメントを読む

  2. 2

    反応する

    自然な共感

  3. 3

    本人へ返す

    その人に1つだけ聞く

  4. 4

    自分の言葉を足す

    小さな体験や意見

  5. 5

    場へ広げる

    必要なら、みんなへ

「今日仕事で疲れた」に

  • 視聴者のコメント

    よくない
    「お疲れー！」と言って、そのまま別の話へ
    より良い
    「お疲れさま！ 今日も頑張ったね。私も今日バタバタで。○○さんは、帰ったらまず何する派？」（本人へ返す）
    上級の言い方
    （答えが来たら）「お風呂派なんだ、わかる！ 私はまず冷たい飲み物かな」ともう一度だけ返してから、「みんなは、帰ったらまず何する？ 聞いてるだけの人も、心の中で答えてみて」（全体へ・答えなくていい）

注意

すべてのコメントを長く広げる必要はありません。短い共感で十分な時もあります。質問を重ねて問い詰めない。話したくなさそうな話題は、深追いしません。初めての人への迎え方と、1つのコメントを会話にする基本は「初見の心をつかむ歓迎・会話術」の記事でも扱っています。

一段上の攻略ポイント同じコメントに、何通り返せる？コメントの種類に合わせて、返し方を選べるようになります。深掘りする ＋閉じる －

今覚えたこと：受け取る → 反応 → 本人へ返す → 自分の言葉 → 場へ。

注意

いつも同じ返しの限界

どのコメントにも「ありがとう！」だけだと、会話の深さが生まれにくくなります。

コメントの種類返し方の例
質問答える＋少し自分の話を足す
感想受け取って、どこが良かったか聞く
共感「わかる！」＋自分の体験
リアクション（笑・👏）一言で受けて、流れを止めない
プライベートな話本人が話した範囲だけ。深掘りしない
不適切な内容広げない。下の「困ったコメント」へ

ここが要点

判断できること

上手な配信者は、同じ「かわいい」にも、喜ぶ・照れる・ツッコむ・話を広げる・聞き返す、と何通りも動けます。その場で選べるよう、よく来るコメントで練習しておきます。

次のLIVEでは：よく来るコメントに、いつもと違う返しを1回だけ試します。

1人との会話を、部屋全体の話にします。

1人との会話を、部屋全体の話題に。初めての人にも

広げ方の型

  1. 1

    1人のコメント

  2. 2

    共通するテーマ

  3. 3

    誰にでも分かる話

LIVE会話の例

  1. 常連この前おすすめしてくれた映画見たよ！

  2. 配信者

    見てくれたんだ！ うれしい！ どのシーンが好きだった？

  3. 常連最後のどんでん返し！

  4. 配信者

    わかる、あそこ鳥肌！ 今来た人向けに説明すると、先週『○○』っていうサスペンス映画をおすすめしてたんです。最後にびっくりする映画で……

  5. 配信者

    みんなは、最後に驚かされる映画って好き？ それとも安心して見られる方が好き？

話の途中で、今の状況を伝え直す

  • 途中から人が来た

    よくない
    「初見さん！ 名前は？ どこから来たの？ フォローした？」
    より良い
    「こんばんは、○○です。今は買ってよかったものの話をしてます。見てるだけでも大丈夫なので、ゆっくりしていってね」

  • 入室が続く時

    より良い
    「今来てくれたみなさん、こんばんは！ 今は○○の話です」（1人ずつ長く挨拶しない）

  • 話題を変えた時

    より良い
    「今来た人へ。いま○○の話をしてます」（入室がなくても、話題の区切りで1回）

歓迎の基本の型は「初見の心をつかむ歓迎・会話術」、1人と部屋全体の両立は「LIVEの基本4か条」の記事で扱っています。ここでは、話の途中で状況を伝え直す一言を練習します。

注意

1人のコメントを全体の話題にする時、その人の私生活や個人的なことを、勝手にみんなの話題にはしません。

うまくいった進め方は、習慣にします。

カンペの一言を、毎回の習慣にする

  1. A始めに、今日の話題を伝える

    「今日は○○の話から始めたいと思います」

  2. B話題の背景を短く説明する

    「今来てくれた人向けに説明すると……」

  3. Cコメントから全体の話題をつくる

    「今のコメントで思い出したんだけど……」

  4. D終わりに振り返る

    「今日は○○の話が楽しかったです。次は○曜日に、○○の話をしますね」（日時と中身が決まっている時だけ予告する）

  5. E前に出たコメントに、あとで触れる

    「さっき○○さんが言ってた定番、私も試したい」（覚えてもらえた、が生まれる。効果は未検証の仮説）

5つ全部ではなく、次のLIVEで1つだけ試します。A〜Dはカンペの行と同じ一言です。Eは効果がまだ確かめられていない仮説として試します。

人が増えてくると、進め方も変わります。

コメントの量で、進め方を変える

コメントする人配信者の役割実際にすること
コメントゼロ自分で話を進める体験談や準備した話題を話す
コメントが1人1対1を全体に開く背景を補って、共通のテーマにする
数人が会話話題を整理するそれぞれの意見をつなぐ。「Aさんは家派、Bさんは外派なんだね。Cさんの話はAさんに近いかも」
コメントが多い進行をまとめる代表的な意見を拾い、全体に共有する
多い → 急にゼロになった余韻を材料にする「さっきのみんなの意見を見て思ったんだけど……」と自走トークへ

コメントが多い時

  • 拾いきれない時

    より良い
    「コメントありがとう！ 今、似た意見がいくつか来てるので、まとめて紹介しますね」
    上級の言い方
    「全部は読み切れないかもしれないけど、みんなの意見を見ながら進めます。今のところ『家派』が多いね——外派の人の理由も聞きたい！」（まとめる ＋ 少ない方にも光を当てる）

注意

全部のコメントを拾うことを、成功の条件にしません。ギフトの有無だけで、コメントの価値を決めません。同じ人に会話が偏りすぎたら、自然に全体へ戻します。

一段上の攻略ポイントコメントが多い時、何を拾う？人が増えても、流れを止めずに、みんなが参加できる会話を保てるようになります。深掘りする ＋閉じる －

今覚えたこと：人数で、配信者の役割が変わる。

注意

全部読もうとすると

コメントが速い時に全部読もうとすると、進行が止まり、読まれなかった人も、待っている人も置いていかれます。

  1. 1選ぶ基準

    今の話題を広げる・初めての人も参加できる・多くの人に意味がある・気持ちが動く・次の企画につながる。

  2. 2初めて・常連・コアファンのバランス

    常連だけが分かる話が続いたら、背景を一言足して開く。

  3. 3まとめ役を助けてもらう

    荒れや速すぎるコメントには、コメント管理の機能や、信頼できる人の手を借りることも考える（機能は変わることがある）。

ここが要点

判断できること

コメントが少ないうちは、できるだけ拾う方が関係が育ちやすい場合があります。多くなったら、選んで、まとめて、全体に返すに切り替えます。

次のLIVEでは：コメントが続いたら、「似た意見がいくつか来てる」とまとめて返すのを1回試します。

それでも会話が続かない時は、原因を分けて考えます。

会話が続かない時は、原因を分けて考える

原因直し方
話題の背景が分からない何について話しているかを短く説明する
質問が答えにくい抽象的な質問を、具体的な質問に変える
1人の話に偏っている共通するテーマへ広げる
話が一言で終わる自分の体験・気持ち・具体例を足す
コメントを待ちすぎている答えがなくても成り立つ話を用意する
話題が難しい・個人的すぎる前提を説明し、答えなくていい雰囲気を保つ

答えにくい質問

  • みんなに聞く時

    よくない
    「みんなどう思う？」
    より良い
    「仕事が終わって家に着いたら、まずお風呂派？ ごはん派？」

コメントが少ない＝話が下手、と決めつけない。直せる所を探す。

一段上の攻略ポイント会話のテンポは、どう使い分ける？にぎやかな場面・落ち着いた雑談・相談で、話し方を自分らしく切り替えられるようになります。深掘りする ＋閉じる －

今覚えたこと：続かない原因を分けて考える。

注意

テンポは、早口のことではない

同じ話題が長すぎる、同じ人とだけ話している、自分が説明ばかりしている——そんな時は、話題を変えるサインです。

場面合う話し方
にぎやかな企画リアクション大きめ・短い区切り
落ち着いた雑談間をとる・ゆっくり
相談を受ける聞く時間を長く・結論を急がない

ここが要点

判断できること

落ち着いた話し方・明るいリアクション・丁寧な聞き方——自分に合う特徴を1つ磨くと、それがあなたの話し方の個性になります。にぎやかな人の真似は必要ありません。

次のLIVEでは：同じ話題が長すぎる・同じ人とだけ話している・説明ばかり、のどれかに気づいたら、話題を変えてみます。

会話を続けるためでも、答えなくていいコメントがあります。

困ったコメントには、答えなくていい

こんな時は

  1. 個人的すぎる質問

    「どこに住んでるの？」

    配信者「細かい場所は内緒にしています。でも、おすすめの旅行先の話なら大歓迎です」

  2. 不快なコメント

    空気を悪くするコメント

    配信者「その話題はここでは扱わないことにしています。別の話に戻しますね」

    必要に応じて、コメント管理の機能を使う。

  3. ほかの視聴者への攻撃

    視聴者どうしの言い争い

    配信者「ここは、みんなが気持ちよく過ごせる場所にしたいので、その話はここまでにしますね」

    言い争いを盛り上がりの材料にしない。ルールを伝え、必要ならコメント管理の機能を使う。

  4. 1人が会話を独占

    同じ人とだけ話が続く

    配信者「○○さん、ありがとう！ この話、ほかのみんなはどう？ 聞いてるだけの人も大歓迎」

タップで切り替えて、4つを見くらべる

コメントのフィルター・キーワードの制限・ミュート・ブロックなどの機能は、名前や操作が変わることがあります。使い方は「LIVEセーフティー実践ガイド」の記事と、アプリの最新の説明で確かめてください。

最後に、3回の配信で練習します。

3回の配信で練習する

  1. 1回目：コメントゼロでも進める

    話題を1つ準備し、体験・気持ち・具体例で90秒くらい話す。コメントが来なくても続ける。

  2. 2回目：コメントを広げる

    受け取る → 反応 → 本人へ1つ返す → 自分の言葉 → 必要なら全体へ、を1回意識する。

  3. 3回目：初めての人にも分かる進め方

    途中から来た人に、今の話題を短く伝える。答えは求めない。

  4. （任意）4回目：人数で変える

    コメントが続いた時に「似た意見がいくつか来てる」とまとめて返し、数人の意見をつなぐ。

  1. 1何ができた？

  2. 2どこで困った？

  3. 3次回は何を変える？

終わったら、この3つを1行ずつ記録します。

一段上の攻略ポイント会話の振り返りは、何を見る？コメントの数ではなく、会話の力そのものが伸びているかを確かめられるようになります。深掘りする ＋閉じる －

今覚えたこと：3回の配信で、1つずつ練習する。

注意

コメント数だけで見ると

コメント数は、その日に来た人や時間帯でも変わります。それだけでは、会話が上手くなったかは分かりません。

  1. 1自分で話を始められた？

    コメントを待たずに、話題を出せた回数。

  2. 2会話が何往復した？

    1つのコメントから、何回やり取りが続いたか。

  3. 32回目のコメントはあった？

    一度コメントした人が、もう一度書いてくれたか。

  4. 4初めての人に伝わった？

    途中から来た人に、今の話題を伝えられたか。

ここが要点

判断できること

録画やメモで、どこで質問したか・どこで話題を変えたか・誰を巻き込んだかを見ると、次に直す所が1つ見つかります。

次のLIVEでは：終わったら、会話が何往復続いたかを1つだけメモします。
