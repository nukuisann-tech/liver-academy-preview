SNS・集客

LIVEは、終了ボタンで終わらないハイライト活用術

盛り上がった瞬間を切るだけではありません。「このLIVEを見たい」と思う瞬間を、次の新規・ファン・次回LIVEへつなげます。

学んだ先に変わること

  1. 配信者がすることLIVEの瞬間を選び、意味を付ける
  2. LIVEハイライトとして届く
  3. 視聴者新しい人「こういうLIVEなんだ」／ファン「あの時だ」／しばらく来ていない人「また見たい」
  4. 次のLIVEに来る
  5. その先新しい瞬間が生まれ、また届く

攻略ノート

このコンテンツで学べること

  1. 01

    自動の候補を使う

    LIVE後に自動でできるハイライトと、おすすめの区切り（ギフト・視聴者のピーク）を見る。

    LIVEに効く理由編集に時間をかけず、配信の熱が残っているうちに届けられます。

  2. 02

    「盛り上がった」だけで選ばない

    数字の山・単体で面白い瞬間・次を見たくなる瞬間を見分ける。

    LIVEに効く理由見た人が「このLIVEに行きたい」と思う瞬間を選べます。

  3. 03

    クリップごとの目的を決める

    誰へ（初めて・ファン・しばらく来ていない人）、何のために、を1本1つに。

    LIVEに効く理由届けたい相手に、伝わる形で届きます。

    次のLIVEへ橋を作る

    小さな見どころを渡してから、「次は○○」へつなぐ。

    LIVEに効く理由1本の動画で終わらず、次の配信へ人が戻ってきます。

注意

応援してくれた人に共有するのは、感謝を伝える方法の1つです。ただし、ギフトの多い人だけを特別扱いする場にはしません（下の「応援の瞬間を使うとき」）。

自動で候補は出ます。でも、どれを選ぶかで、届くものが変わります。

盛り上がった瞬間＝いいクリップ、とは限らない

  1. 山数字の山（PEAK）

    ギフトや視聴者の数が強く動いた瞬間。

  2. 単体単体で面白い瞬間（BEST CLIP）

    その動画だけ見ても、面白い・伝わる瞬間。

  3. 橋次を見たくなる瞬間（BEST BRIDGE）

    見た人が「次のLIVEも見たい」と思う瞬間。

3つが同じ瞬間のこともあれば、違うこともあります。ボスを倒した瞬間は数字の山でも、初めて見た人には「何がすごいのか」が分からないかもしれません。

だから、選ぶ前に「誰に、何のために」を決めます。

1本のクリップに、仕事は1つ

1本に全部をやらせません。主な目的を1つ決めます。

  1. 1見つけてもらう

    初めての人へ。「この人、何者？」に答える。

  2. 2体験を見せる

    「このLIVEでは、実際にこんな体験が起きる」を見せる。

  3. 3思い出

    いつものファンへ。「あの瞬間だ」。

  4. 4次回へ

    「次どうなる？」で、次のLIVEへつなぐ。

誰へ届ける？ で、選ぶ瞬間が変わる

  1. 初めての人

    見たいもの

    気をつけること

届ける相手を選ぶ

選んだ瞬間は、切り抜くと伝わらなくなることがあります。

切り抜いたら「なんで笑ってるの？」にならないように

そのまま背景を一言足す
ただ爆笑している「初配信で、初めてコメントが来た瞬間」
ゲームで叫んでいる「3時間詰んだボス、最後の1回」

背景を足す。意味は盛らない。

注意

嘘の見出し・偽のコメント・偽の人数・大げさな煽りは使いません。実際のコメントの盛り上がり・笑い・達成・視聴者の参加は、新しい人に部屋の体験を見せる、本物の証拠になります。

注意

応援の瞬間を使うとき

ギフトのピークが候補になることもあります。ただ、高額のギフトの人だけを切り抜くことを当たり前にしません。使うときは、配信者の反応・部屋の反応・その瞬間の意味が伝わることを優先します。気づいたことを伝えるのと、順位をつけるのは別です。

一段上の攻略ポイント思い出が、ファンを育てる理由慣れてからで OK

  1. 1共通の思い出（Shared Memory）

    「あの日、あそこにいた」が、配信者と視聴者の共通の話題になる。

  2. 2山場と終わりの記憶（Peak-End）

    人は、一番盛り上がった所と終わり方を強く覚えやすい。

  3. 3なじみ（Familiarity）

    何度も見る場面・言葉が、「いつもの場所」の安心になる。

  4. 4仲間の感覚（Social Identity）

    「この枠を見ている自分たち」という感覚が生まれる。

  5. 5物語（Narrative）

    失敗 → 挑戦 → 成功のような流れが、続きを見たい理由になる。

注意

古くからのファンだけが分かる、閉じた場所にはしません。新しい人にも、一言で背景が分かるように。

一段上の攻略ポイント

ここは読み飛ばしても、上の本編だけで次のLIVEを始められます。もっと伸ばしたくなったら、気になる見出しだけ開いてください。

読み飛ばして先へ
  1. 01「盛り上がり」と「次回来場」は、なぜ違う？開く

    数字が動いた理由と、見た人が次に来たくなる理由は、同じとは限りません。

    盛り上がり（数字の山）次回来場（橋）
    動く理由その場の勢い・ギフト・人の多さ続きが気になる・この人の時間が好き
    見た人に残るものすごかった次も見たい
    クリップで足すものなぜ盛り上がったかの背景まず満足 → 次は○○

    山の瞬間を使うなら、背景を一言足し、終わりに次の約束を置くと、両方の役目を少しずつ持てます。ただし1本の主な目的は1つです。

  2. 02ファンとの思い出を、新しい人にも分かるクリップにする方法開く

    内輪の楽しさは残して、入口だけを広げます。

    1. 何が起きたかを一言

      「毎回失敗していた企画が、5回目で成功」

    2. なぜ盛り上がったか

      「みんなでずっと応援していたから」

    3. 入口を開く

      「次は6回目。初めての人も一緒にどうぞ」

    コツ

    呼び名や合言葉は消さなくてかまいません。意味が分かる一言を、キャプションか画面の文字で足します。

  3. 03再生数だけで判断しない、ハイライトの確かめ方開く

    1本ごとに、仮説を立てて確かめます。

    1. 出す前に

      「誰に・何のため・何が伝わるか」を1行で書く（MY HIGHLIGHT PLAN）

    2. 出したあと

      クリップの反応・プロフィールへの関心・フォロー・「LIVEいつ？」・次のLIVEの反応を見る

    3. 次の1本

      伝わった所を残し、伝わらなかった所（背景・長さ・終わり方）を1つだけ変える

    注意

    1本の結果を絶対の答えにしません。同じ目的で何本か出して、くり返し出る反応を見ます。
