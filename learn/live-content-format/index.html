配信の企画

毎回「何する？」で迷わないLIVEフォーマットの作り方

ネタではなく、途中から入っても分かり、参加でき、次も見たくなる「番組の型」を作ります。

学んだ先に変わること

  1. 配信者がすること今日やること・誰向け・どこまでを決める
  2. 途中から来た人を、もう一度迎え入れる
  3. 視聴者入った人が、すぐ参加できる
  4. LIVE山場と終わり方で、次回へつながる
  5. その先「いつものやつ」が、みんなの思い出になる

攻略ノート

このコンテンツで学べること

  1. 01

    3つを決める

    今日やること・誰向け・どこまで、を決める。

    LIVEに効く理由「なんとなく配信が終わる」がなくなります。

  2. 02

    途中から来ても分かるようにする

    今何をしているか・どう参加できるかを、途中でもう一度伝える。

    LIVEに効く理由LIVEは、最初から見てくれるとは限りません。

  3. 03

    次も来たくなる型にする

    山場・終わり方・次回を決め、毎回くり返す。

    LIVEに効く理由「いつものやつ」が、みんなの思い出になります。

STEP013つを決める

「今日やること・誰向け・どこまで」を決める

何度でも使い回せる配信のテンプレは、3つを決めるだけで作れます。

  1. 1今日やること

    コメント読む／寝落ち相伴／練習見せる／体験談トーク／相談室…など

  2. 2今日は誰向け？

    「眠い人」「ひとりの人」「作業したい人」「就活で悩んでる人」など

  3. 3今日はどこまでやる？

    「30分だけ」「○○が終わるまで」「質問10個答えるまで」など

ここが要点

「話が面白い人」が勝つと思われがちですが、大切なのは、視聴者が“ここにいる理由”がはっきりしている枠です。

ネタから、番組へ

  1. 1話題今日、何する？
  2. 2型視聴者は、なぜ今ここにいる？
  3. 3くり返し途中から来た人も入れる？
  4. 4シリーズ視聴者は、なぜ次も来る？

STEP02途中から来ても分かる

途中から来ても参加できるLIVEにする

LIVEは動画と違い、視聴者が最初から見るとは限りません。途中から突然入ってきます。

だから、どの瞬間から入っても「今、何をしているか」が分かることが大切です。

途中から来た人の頭の中

  1. 1

    入ってくる

  2. 2

    今、何をしてる？

  3. 3

    何を目指してる？

  4. 4

    どう参加できる？

  5. 5

    このあと何が起きる？

  6. 6

    参加する・見る

コツ

途中参加の人を、もう一度迎え入れる

長い配信では、最初の説明だけでは途中の人に届きません。自然な区切りで、「今○○してます」「今日は○○までやります」「コメントでAかB選んでます」ともう一度伝えます。決まった分数の決まりはありません。

＋番組の型の7つの部品

強いフォーマットは、7つの部品でできている

全部そろえる必要はありません。初心者は1〜4から。

  1. 1入る前の約束

    何のLIVE？

  2. 2今のミッション

    今、何してる？

  3. 3視聴者の役割

    視聴者は何ができる？

  4. 4進み具合

    今どこまで？

  5. 5山場

    何を見届ける？

  6. 6迎え直し

    途中の人を迎える

  7. 7次の回

    次は何？

ふつう番組の型（上級）
「ゲーム配信する」→「○○初見攻略」誰向け：同じゲームが好き／初見攻略を見たい
ミッション：今日はボスまで
役割：ヒントOK
進み具合：今チャプター4
迎え直し：「初見攻略で、今ボス前です」
山場：ボスの結果
次回：負けたら次回再挑戦

＋型の図鑑

6つの体験から、型を選ぶ

公式の「やること」リストを、視聴者の体験で6つに分けました。

フォーマット図鑑

  1. 会話

    向いているスタイル
    A
    視聴者の欲しいもの
    話したい
    例
    質問拾い・ごはん雑談
    視聴者の役割
    コメントする・答える
    どこまで
    質問10個に答えるまで
    迎え直しの一言
    「今、みんなの質問に答えてます。あと3つ」
    次の回のアイデア
    次回は、今日答えきれなかった質問から

  2. 伴走

    向いているスタイル
    A・D
    視聴者の欲しいもの
    癒されたい
    例
    寝落ち伴走・作業いっしょ・深夜ラジオ
    視聴者の役割
    見るだけOK・ときどき一言
    どこまで
    30分だけ／眠くなるまで
    迎え直しの一言
    「今、静かに作業してます。聞くだけでもOK」
    次の回のアイデア
    明日も同じ時間に

  3. 成長

    向いているスタイル
    B
    視聴者の欲しいもの
    見届けたい
    例
    サビ育成・苦手克服
    視聴者の役割
    どっちが良いか選ぶ・励ます
    どこまで
    できるまで／今日はここまで
    迎え直しの一言
    「今、サビの練習中。AとBどっちが良い？」
    次の回のアイデア
    続きは次回。前回からの変化を見せる

  4. 参加

    向いているスタイル
    B
    視聴者の欲しいもの
    参加したい
    例
    作戦募集・左右投票
    視聴者の役割
    選ぶ・作戦を出す
    どこまで
    投票の結果が出るまで
    迎え直しの一言
    「今、次どう動くかコメントで募集中」
    次の回のアイデア
    選ばれた作戦の結果を次回に

  5. 学び

    向いているスタイル
    C
    視聴者の欲しいもの
    学びたい
    例
    人生経験シェア・勉強のコツ・買ってよかった物
    視聴者の役割
    質問する・自分の例を話す
    どこまで
    学び1つまで
    迎え直しの一言
    「今日の学びは1つ。今それを話してます」
    次の回のアイデア
    次回の学びを予告

  6. 世界観

    向いているスタイル
    D
    視聴者の欲しいもの
    世界観に浸りたい
    例
    深夜ラジオ・おつかれ部屋
    視聴者の役割
    合言葉で参加・悩みを話す
    どこまで
    眠くなるまで
    迎え直しの一言
    「今、おつかれ部屋。合言葉は○○」
    次の回のアイデア
    いつもの時間・いつものBGMで

体験を選んで、型の中身を見る

例

公式ページのヒント

  • 20時以降は集まりやすい

  • 今日はここまで（続きは次回）

  • 学び1つ（定番化）

  • BGMを固定・口ぐせを固定（合言葉）

STEP03次も来たくなる

山場・終わり方・次回で、「また見たい」を残す

「上手い人が勝つ」より、育っていく過程を見せる枠のほうが応援されやすい、と公式ページは紹介しています。続きは、次回へ残します。

例

  • 完成

  • 投票の結果

  • ボス戦

  • 1曲

  • 話の一番いいところ

終わり方

  1. 今日の山場

    「今日はAまでできた」

  2. 視聴者の貢献に感謝

    「B選んでくれた人、ありがとう」

  3. 次回

    「次は木曜に」

  4. 続き

    「この続きをやります」

STEP の先へ

一段上の攻略ポイント

ここは読み飛ばしても、STEP 1〜3 だけで実践できます。もっと伸ばしたくなったら、気になる見出しだけ開いてください。

読み飛ばして先へ
  1. 01台本に視聴者を合わせない。場の状態に型を合わせる開く

    同じ型でも、場の状態で進め方を変えます。人数の決まった基準は使いません。

    場の状態ごとの進め方

    1. 静か

      進め方
      配信者が主に話す。参加のお願いは気軽なものに。

    2. 会話が動く

      進め方
      コメントを拾い、枠全体へ広げる。

    3. コメントが多い

      進め方
      全部に長く返さず、テーマでまとめる。

    4. 盛り上がり

      進め方
      今起きていることを言葉にし、節目を共有する。

    タップで切り替えて、見くらべる

  2. 02参加には、気軽な順の段階がある開く

    全員を上へ進めません。視聴者が自分で選びます。

    1. 1

      見るだけ

    2. 2

      いいね・絵文字

    3. 3

      AかBを選ぶ

    4. 4

      質問に答える

    5. 5

      アドバイス・話をくれる

    6. 6

      次の展開に反映される

    7. 7

      続きを見に来る

  3. 03「いつものやつ」が、みんなの思い出になる開く

    毎回くり返すものが、共通の記憶を作ります。

    例

    毎回くり返すもの

    • 始まりのあいさつ

    • 決まった言葉

    • BGM

    • 定番のコーナー

    • 視聴者の役割

    • 終わり方

    注意

    呼び方・定番の返し・昔の出来事が積み重なると、その枠らしさになります。ただし、内輪ネタを使ったら、新しく来た人にも意味が分かる一言を添えます。

  4. 04型には、切り抜ける場面と、応援される理由が入っている開く

    型を作る時から、どこがショート動画になるかも考えられます（LIVEを撮影会にはしません）。

    • 会話

      一番いいやりとり

    • スキル

      変える前と後

    • 投票

      選択 → 結果

    • 挑戦

      節目

    • 知識

      学び1つ

    • キャラ

      世界観の瞬間

    ここが要点

    応援は、型の目的ではありません。ただ、何を見届けているかがはっきりした型ほど、応援の意味が伝わりやすいことがあります。ギフトの額で、場の上下を作りません。

ファン化・応援につながる理由

  • 型が、「いつものやつ」という共通の思い出を作る

    毎回くり返す型があると、視聴者は「いつものやつ」を楽しみにできます。特別な日は、少しだけ変えます。

    1. 1いつもの型
    2. 2「いつものやつ」
    3. 3共通の思い出
    4. 4また来る

  • 分かる型が、見続ける理由になる

    何をしていて、どう参加できて、次に何が起きるかが分かると、見続ける理由・参加する理由ができます。

    「この型ならおすすめに載る」という話ではありません。

    1. 1分かる型
    2. 2見続ける・参加する理由
    3. 3視聴者の行動
    4. 4LIVEの伸び
