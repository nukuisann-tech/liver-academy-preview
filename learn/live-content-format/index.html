配信の企画

毎回「何する？」で迷わないLIVEフォーマットの作り方

「今日は雑談」を、途中から来た人にも分かる「番組の型」にします。例は1つ、「仕事終わりおつかれ部屋」を最後まで追います。

このページでは

  1. 1知る途中から来ても分かる「枠」とは
  2. 2自分に合わせるMY LIVE FORMAT を組み立てる
  3. 3次のLIVEで試す最初の一言で、今日の枠を言う

読み終わると「仕事終わりの人と、30分だけ、今日一番疲れた話をする。聞くだけでもOK」のような1文が作れます。

    1. 4そのまま、次へスワイプ。

ここが要点

LIVEでは、視聴者が最初から見ているとは限りません。

だから、途中から見ても分かる「枠」を作ります。まずは3つの質問だけ。

知る答え

今日なにする？誰向け？どこまで？

強みを見つける

「試すこと」は、このあと組み立てる「何する？」に最初から入ります。

何度でも使える配信の型は、3つを決めるだけで作れます。

ここが要点

「話が面白い人」が勝つと思われがちですが、大切なのは、視聴者が“ここにいる理由”がはっきりしている枠です。

なぜ、これだけで違うのか。視聴者の頭の中を見てみます。

見る途中から来た人

途中から来た人にも、今なにをしているかがすぐ分かる

    2. 1配信20分目。新しい人が入ってきた。

    1. 4視聴者の気持ち「あ、そういう部屋か。いてもいいんだ」

    実は、いま作ったものは3つの段で考えられます。

    1. 1話題

      毎回かわる中身。例：今日一番疲れた話

    2. 2型（フォーマット）

      毎回おなじ枠。例：仕事終わりおつかれ部屋

    3. 3シリーズ

      続けて来る理由。例：平日22時前後に、毎回

    フォーマットができました。次のLIVEで1回やってみます。

    やる試す

    次のLIVEは、最初の一言で枠を言う

    次のLIVEで試すのは、1つだけ

    始めの一言で、今日のフォーマットを言う。途中で新しい人が来たら、もう一度言う。

    例：「今日は仕事終わりの人と30分、今日一番疲れた話をします。聞くだけでもOKです」

    終わったら、1つだけふり返ります。

    やるふり返る

    終わったら、1つだけふり返る

    LIVEのあとで、1分だけ

    途中から来た人に、今何をしているか伝わった？

    その一言が、あなたの枠の入り口です。次回も同じ言葉で始めます。

    途中の人への一言を、もっと短くします。「今○○してます」だけでも伝わります。

    深める

    一段上の攻略ポイント

    ここから先は、必要な人だけ。上までで、次のLIVEはもう始められます。気になる見出しだけ開いてください。

    読み飛ばして先へ
    1. 01ネタから、シリーズへ（話題・型・くり返し・シリーズ）開く

      さっきの3つの段に、「くり返し」を足すと、こう考えられます。

      1. 1話題今日、何する？
      2. 2型視聴者は、なぜ今ここにいる？
      3. 3くり返し途中から来た人も入れる？
      4. 4シリーズ視聴者は、なぜ次も来る？
    2. 02参加の段階と、場の状態開く

      全員を上の段へ進めません。視聴者が自分で選びます。場の状態でも、進め方を変えます。

      1. 1

        見るだけ

      2. 2

        いいね・絵文字

      3. 3

        AかBを選ぶ

      4. 4

        質問に答える

      5. 5

        アドバイス・話をくれる

      6. 6

        次の展開に反映される

      7. 7

        続きを見に来る

      場の状態ごとの進め方

      1. 静か

        進め方
        配信者が主に話す。参加のお願いは気軽なものに。

      2. 会話が動く

        進め方
        コメントを拾い、枠全体へ広げる。

      3. コメントが多い

        進め方
        全部に長く返さず、テーマでまとめる。

      4. 盛り上がり

        進め方
        今起きていることを言葉にし、節目を共有する。

      タップで切り替えて、見くらべる

    3. 03山場・終わり方・「いつものやつ」開く

      毎回くり返すものと、今日だけの山場で、「また見たい」を残します。

      ここが要点

      「上手い人が勝つ」より、育っていく過程を見せる枠のほうが応援されやすい、と公式ページは紹介しています。続きは、次回へ残します。

      1. 今日の山場

        「今日一番の話は、これに決定！」

      2. 参加への感謝

        「話してくれた人、ありがとう」

      3. 次回

        「次は木曜の22時に」

      例

      公式ページのヒント

      • 時間を固定する（毎週○曜○時）

      • 20時以降は集まりやすい

      • 今日はここまで（続きは次回）

      • 学び1つ（定番化）

      • BGMを固定・口ぐせを固定（合言葉）

      注意

      呼び方・定番の返し・昔の出来事が積み重なると、その枠らしさになります。ただし、内輪ネタを使ったら、新しく来た人にも意味が分かる一言を添えます。

    4. 04伸び方・ショート動画・応援との関係開く

      型を作る時から、どこがショート動画になるかも考えられます（LIVEを撮影会にはしません）。

      • 会話

        一番いいやりとり

      • スキル

        変える前と後

      • 投票

        選択 → 結果

      • 挑戦

        節目

      • 知識

        学び1つ

      • キャラ

        世界観の瞬間

      注意

      「この型ならおすすめに載る」という話ではありません。何をしていて、どう参加でき、次に何が起きるかが分かると、見続ける理由・参加する理由ができます。

      ここが要点

      応援は、型の目的ではありません。ただ、何を見届けているかがはっきりした型ほど、応援の意味が伝わりやすいことがあります。ギフトの額で、場の上下を作りません。
