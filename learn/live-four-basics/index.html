会話・ファン化

初見が居やすく、常連が戻りやすいLIVEの基本4か条

自己紹介・歓迎・感謝・BGM。4つの言葉と空気で、「ここにいていい」と感じるLIVEを作ります。

学んだ先に変わること

  1. 視聴者何のLIVEか分かる
  2. 安心して、いられる
  3. LIVE一言、参加する
  4. 視聴者気づいてもらえる・覚えてもらえる
  5. その先また来る・関係が育つ

4つは別々のコツではなく、1本の流れです。その先で、見る・いいね・コメント・シェア・また来る・ギフトのどれもが、応援の形になります。

攻略ノート

このコンテンツで学べること

  1. 01

    途中から入った人へ「誰の・何のLIVEか」を伝える

    自分は誰か・今何をしているかを、短く伝え直す。

    LIVEに効く理由「誰？何の話？」のまま去る人が減り、今のLIVEに入りやすくなります。

  2. 02

    参加する前から、歓迎されている空気を作る

    「聞くだけでも大丈夫」のように、居方を伝える。

    LIVEに効く理由コメントしない人も、安心してその場にいられます。

  3. 03

    コメント・いいね・シェア・応援へ、具体的な感謝を返す

    誰に・何が・どう嬉しかったかを返し、部屋へ話を戻す。

    LIVEに効く理由「自分の一言が届いた」が、また参加する理由になります。

  4. 04

    音まで含めて「この枠らしい空気」を作る

    BGMを、声と内容を支える「見えない背景」として選ぶ。

    LIVEに効く理由見やすくなり、「あ、いつもの枠だ」と覚えてもらいやすくなります。

公式ページは、この4つを「テクニック以前に押さえるべき最低限の土台」と紹介し、人気のクリエイターほど安定して実践していると書いています。

まずは、入ってきた人の「誰？何の話？」に答える、自己紹介から。

自己紹介は、今このLIVEを見るための「前提」を渡すこと

公式ページの自己紹介は、誰のLIVEか・何のLIVEかを伝えること。初見が離脱しにくくなる、とされています。

自己紹介はプロフィールの読み上げではない。今このLIVEを見るための「前提」を渡す。

  1. 必ず自分は誰か

  2. 必ず今、何をしているか

  3. あればふだんの配信の時間

  4. あれば次の配信

  5. あればこの枠らしさ

例

たとえば

  • 「初めまして。仕事終わりにゆっくり話してる○○です。今日はみんなの“今日一番疲れた話”を聞いてます。」

ここが要点

長いLIVEでは、自然な節目で伝え直す

新しく入ってきた人が分かるように、区切りのいい所で、短く自分と今の配信を伝え直します。決まった分数のルールはありません。

コツ

新しい人へ説明しながら、常連との時間も止めない。「初めましての方へ一言だけ。仕事終わり雑談の○○です」と言ったら、すぐ本題へ戻ります。

一段上の攻略ポイント短い自己紹介をくり返すコツ慣れてからで OK

30秒の長い自己紹介を何度もくり返すと、常連にはくり返しに、新しい人には情報が足りない、のどちらにもなりやすいです。

  1. 一言だけ

    「初めましての方へ一言だけ。」

  2. 誰で、何の枠か

    「仕事終わり雑談の○○です。」

  3. すぐ本題へ

    「でね、さっきの話なんだけど——」

途中から来た人への一言は、「LIVEフォーマットの作り方」の「途中の人へ一言」と同じ考え方です。

注意

公式ページには自己紹介の頻度の目安も載っていますが、本文（30分に1回）と図（1.5回/30分）で数字が違います。ここでは決まった回数にせず、新しい人が来た時・話題が変わる時を目安にします。

一段上の攻略ポイント公式ページの、自己紹介の段階（Level 1〜3）公式ページの例

  1. Level 1私は誰か

    自分の立場・属性・今何をしているかを伝える。例「会社員をしながら配信している○○です。今日はお仕事終わりに、夜のスキンケアルーティンをしながら、ゆっくりお話ししています。」

  2. Level 2配信時間の案内

    配信時間帯・頻度・次回の予定を足す。例「私は基本的に、毎日19時からライブ配信をしています。」

  3. Level 3行動のお願い

    自己紹介のあとに、フォロー・いいね・コメントなどを促す。例「もし雰囲気が合いそうだなと思ったら、フォローしていただけると嬉しいです。」

誰で何をしているかが分かったら、次は「ここにいていい」を伝えます。

歓迎は、コメントを求めることではない

公式ページの歓迎は、初見でも入りやすい雰囲気をつくること。滞在時間が伸びやすくなる、とされています。

BEFORE

視聴者「初見です」→

  • 「初見ありがとう。」（ここで終わり）

AFTER

視聴者「初見です」→

  • 「初見さん来てくれてありがとう。今日は仕事終わり雑談です。聞くだけでも大丈夫ですよ。」

歓迎とは、コメントを求めることではない。「ここにどう居ていいか」を伝えること。

例

居方を選べるようにする

  • 話してもいい

  • 聞くだけでもいい

  • AかBだけでもいい

  • 絵文字だけでもいい

一段上の攻略ポイント公式ページの、歓迎の段階（Level 1〜3）公式ページの例

  1. Level 1歓迎の表現

    「来てくれてありがとう」など、歓迎の意味が伝わる。例「みなさん、こんばんは。配信に来てくださってありがとうございます。」

  2. Level 2誰を歓迎するか

    名前、または入ってきた人たちを具体的に歓迎する。例「○○さん、来てくれたんですね。お仕事お疲れさまです。」「今来てくれたみなさん、ありがとうございます。ゆっくりしていってくださいね。」

  3. Level 3会話のきっかけ（アイスブレイク）

    名前・アイコン・最近の様子などから話を広げる。例「LIVE配信を見るのは初めてですか？よかったら、気軽にコメントしてみてくださいね。」「今日はちょっと遅めですね。忙しかったんですか？」

注意

公式ページの会話のきっかけの例には、出身地をたずねる例もあります。このAcademyでは、住んでいる所・本名・職場・学校を、最初の質問にしません（下の「1人を大切に」を参照）。

一段上の攻略ポイント公式ページの、感謝の段階（Level 1〜4）公式ページの例

  1. Level 1感謝の言葉

    「ありがとう」「感謝しています」など、感謝の意味を持つ表現がある。

  2. Level 2誰への感謝か

    名前を挙げる、または部屋の一部・全体に向けて伝える。例「○○さん、ハート本当にありがとう。すごく嬉しいです。」

  3. Level 3感謝の理由

    なぜ嬉しいかを具体的に足す。例「○○さん、コメントありがとうございます。温かい言葉をもらえて、本当に嬉しいです。すごく励みになります。」

  4. Level 4気持ちが豊かに伝わる

    お礼にとどまらず、褒め言葉・称賛・祝福などで、感謝される側の嬉しさを高める。例「正直、まだ信じられない気持ちです。今日ここに来てくれた一人ひとりに、本当に感謝しています。……」

一段上の攻略ポイントコメントが多い時の返し方慣れてからで OK

コメントが増えたら、全員に同じ長さで返すことを目標にしません。次のようなコメントを選んで返します。

BGMは、LIVEの「見えない背景」

公式ページのBGMは、LIVEの雰囲気と印象を整えるもの。見やすく、覚えられやすくなる、とされています。

BGMは、LIVEの「見えない背景」。

  1. 1声が主役か

    話し声がはっきり聞こえる音量か。

  2. 2配信のテーマと合うか

  3. 3音量の変化が不自然でないか

    急に大きく・急に途切れない。

  4. 4本当に必要か

    その場面に、音が要るか。

コツ

無音も演出になる

公式ページのチェックでは、会話の合間にもBGMが流れていて、突然無音にならないことを基準にしています。そのうえで、感情的な話・静かな場面・音が主役の場面では、意図して下げる／使わないこともあります。BGMを流すことが目的ではなく、視聴者にどんな空気を感じてほしいかで決めます。

一段上の攻略ポイント公式ページの、BGMの4つのチェック公式ページの例
項目公式ページの定義・よくある例
BGMの有無配信開始直後から音楽が流れている・話題転換時や無言の時間帯でも音楽が流れている
BGMの音量クリエイターの話し声がはっきり聞こえる・音楽が注意を奪わない
スタイルBGMのスタイルが配信内容と一致し、LIVEの雰囲気づくりに貢献している
連続性会話の合間にも音楽が流れている・突然完全に無音になる場面がない

注意

音楽を使うときは、使ってよい音源かを確かめます。音楽の扱いはアプリや権利の決まりで変わることがあります。

一段上の攻略ポイント声とBGMがぶつかる時慣れてからで OK

話し声とBGMの主張がぶつかると、視聴者はどちらを聞けばいいか迷うことがあります。会話が主役なら、BGMは脇役。世界観を強く出したい日でも、話の中身を分かりにくくしない音量・曲を選びます。

一段上の攻略ポイント音が「いつもの場所」を作る理由慣れてからで OK

  2. 2お決まり（儀式）

  4. 4ブランドのそろい

    音・見た目・話し方がそろうと、「この人らしさ」として覚えられやすい。

一段上の攻略ポイントなぜ「自分の一言が届いた」が強い？慣れてからで OK

  1. 1そこにいる感じ（Social Presence）

    画面の向こうの人が、自分に向けて反応してくれると、「同じ場所にいる」と感じやすくなる。

  2. 2気づいてもらえる（Recognition）

    名前や一言を覚えてもらえると、「自分はここで見えている」と感じる。

  3. 3自分が動かした（Agency）

    自分のコメントで話が広がると、「このLIVEに自分も関わった」と感じる。

  4. 4つながり（Relatedness）

    配信者やほかの視聴者と、同じ話題でつながる感覚が生まれる。

  5. 5小さな一歩（Micro-commitment）

    絵文字1つ・AかB1つのような小さな参加が、次の参加をしやすくする。

注意

これらは、視聴者を操るためや、課金に誘導するために使いません。健全な応援が自然に生まれる関係のための知識です。
