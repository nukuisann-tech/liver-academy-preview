集客・成長

LIVEに人が少ないとき、最初に見るべきこと

「自分に魅力がない」で終わらせない。視聴者がどこで止まっているかを見つけ、次のLIVEで変える1つを決めます。

学んだ先に変わること

  1. 配信者がすること症状で見て、一番の詰まりを選ぶ
  2. 1つだけ変えて、確かめる
  3. LIVE入ってきた人が、残りやすい
  4. 視聴者視聴者「ここ、いてもいいな」
  5. その先また来る人が増え、育ち方が分かる

頑張っているのに、LIVEに人が増えない時へ

こんな状態が続いていませんか。

  • 配信しても人が来ない
  • 入ってもすぐいなくなる
  • 数人はいるけど会話にならない
  • 何を改善すればいいか分からない
  • 毎回いろいろ変えてるのに伸びない

ここで「自分に魅力がない」と決める必要はありません。視聴者が、見つける → 入る → 残る → 参加する → また来る、のどこかで止まっているだけかもしれません。

ここが要点

人数が少ないことより、原因が分からないまま施策を増やす方が危険です。

まず、「人が少ない」を、3つの症状に分けて見ます。

「人が少ない」は、3つの症状に分けられる

  1. Aそもそも来ない

    LIVEを見つけてもらえていない可能性。

  2. B来るけど残らない

    入口や、配信の体験に問題がある可能性。

  3. C残るけど、関係が育たない

    参加や、また来ることに問題がある可能性。

「人を増やす」と「来た人が残る」は、別の問題。

例

「なんとなく伸びない」ではなく、起きていることで見る

A（来ない）は「見つけてもらう」、B（残らない）は「入る・残る」、C（関係が育たない）は「参加する・また来る」の段に当たります。始めたばかりなら症状で、慣れてきたら段で見ます。

場面

場面

視聴者は3人。そのうち1人が「今日残業でした」とコメント。

  1. 大人数の日なら、一言で流れてしまうコメント

  2. 今日は、何時までだったか、どんな日だったかまで聞ける

  3. 次の配信で「この前21時までって言ってたよね」と呼び戻せる

少人数の時間は、1人との関係を深く作れる時間でもあります。

  1. 1そこにいる感じ（Social presence）

    配信者が自分に向けて話してくれると、「同じ場所にいる」と感じやすくなる。

  2. 2覚えてもらえる（Recognition）

    名前や話の中身を覚えてもらえると、「ここで自分は見えている」と感じる。

  3. 3意味のあるラリー

    一言で終わらず、聞き返し・自分の話・部屋への問いまで続くやり取り。

  4. 4呼び戻し（Callback）

    あとで前の話を持ち出すと、「ちゃんと聞いてくれていた」が伝わる。

  5. 5共通の思い出（Shared memory）

    少人数で話したことが、その後の配信での共通の話題になる。

  6. 6「最初から見ていた」（Origin witness）

    人が少ない時期を知っている人は、成長を見届けている感覚を持ちやすい。

ここが要点

現場での判断

人数が少ない時は、全員に短く返すより、1人と2〜3往復のラリーを作り、最後に部屋へ広げる。

注意

使わない方がいい時

1人とだけ長く話し続けて、ほかの人が入れなくなる時。少人数を良いことだと思い込んで、届ける工夫（時間・タイトル・予告）をやめる時。ゴールは、人が増えることです。
