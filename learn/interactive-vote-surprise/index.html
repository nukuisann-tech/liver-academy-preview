配信の企画

ただ見るLIVEから、一緒につくるLIVEへ。投票とサプライズで、参加型LIVEの企画をつくる方法

  • 原本：視聴者が参加したくなるLIVEの作り方

いつも同じ雑談になってしまう時に。投票で視聴者に展開を選んでもらい、結果を実際に使い、小さなサプライズで「このあと何か起こるかも」を作る。1つの企画を、設計から振り返りまで完成させます。

いつも同じ雑談になる。企画をやりたいけど、何から？

こんなことで迷っていませんか。

  • 話題が続かない
  • 企画を考えたいけど、何をすればいいか分からない
  • コメントをもらっても、その場だけで終わる
  • 投票機能があるらしいけど、使い方が分からない
  • サプライズをやりたいけど、盛り上がらなかったら怖い

面白さが足りないとは限りません。配信者だけで進めていて、視聴者の行動が、LIVEの展開に反映されていないのかもしれません。

参加型LIVEの面白さは、派手な演出だけではありません。視聴者の選択によって、次の展開が変わることにあります。大きな企画も、たくさんの視聴者も、高額なギフトも要りません。

解決すると、こんな状態へ

「今日は何しよう」と迷うたびに同じ雑談をくり返す状態から抜けて、投票1つとサプライズ1つで、視聴者と一緒に展開をつくれるようになります。コメントが少ない日でも進められる代わりの手も、先に用意しておけます。

たとえば、こんな配信。

  • 「次の話、旅行の失敗談ならA、最近驚いた話ならB。多い方から話すね」
  • 人が少ない日でも、1つ「A」が来た。「Aね！ じゃあ、北海道で電車を乗り過ごした話から」
  • 30分後の小さなサプライズを、みんなが待っている。最後に「来週は、今日のBの話からやるね」。

まず、なぜ投票が参加しやすいのかを見ます。

投票は、いちばん入りやすい参加

投票は、視聴者がワンタップで気軽に参加できる、いちばん基本の参加のしかたです。配信の内容や進め方を視聴者に選んでもらうと、自然とコメントが増え、配信の一体感が生まれやすくなります。

「何か話して」「AかBで教えて」
視聴者がすること何を書くか考える1文字選ぶ
初めての人入りにくい入りやすい
配信者答えが来るか読めない答えを、すぐ展開に使える

ただし、投票にすれば必ず参加が増える、というわけではありません。「その答えが、このあと何に使われるか」が伝わって初めて、答えたくなります。

投票の呼びかけ

  • 次の話題を決める時

    よくない
    「AかBを選んでください！」（何に使うか分からない）
    より良い
    「次に話す内容を決めたい！ 旅行の失敗談ならA、最近驚いた話ならBで教えて。多い方から話すね！」
    上級の言い方
    「次の話、みんなに決めてほしい。A＝旅行の失敗談、B＝最近驚いた話。1文字でOK、30秒で締めるね。選ばれなかった方は、来週のおまけにする」（使い道 ＋ 答え方 ＋ 締め切り ＋ 負けた方の行き先）

注意

選ばせるだけの限界

選択肢が配信者の都合だけで決まっていると、選んでも「どっちでもいい」と感じられます。

  1. 1自分で決めた感覚

    強制されず、自分で選んだことには、気持ちが入りやすい。

  2. 2場を動かした手応え

    自分の1票で展開が変わると、「この場の一員」と感じる。

  3. 3みんなで決めた

    同じ方を選んだ人どうしで、ちょっとした仲間意識が生まれる。

ここが要点

判断できること

選択肢は、どちらを選んでも視聴者が楽しめるものにします。配信者がやりたくない選択肢は入れません。

次のLIVEでは：投票の結果で話を始める時に、「○○さんたちが選んでくれたAです」と言います。

投票に、もう1つ足すと企画になります。サプライズです。

3つのサプライズで、「このあと何か起こるかも」を作る

サプライズを入れると、視聴者に「このあと何か起こるかも」という期待が生まれます。内容は、シンプルなもので大丈夫です。

3つのサプライズ

  1. 時間指定

    配信の決まった時間に、ちょっとしたことを公開する。

    配信者「配信が始まって30分後に、最近買ったお気に入りのアイテムを1つ紹介します！ お楽しみに！」

    例
    開始30分後に発表／1時間後に特別企画
    向いている人
    最初にやってみる人。人数に関係なくできる
    気をつけること
    言った時間は守る。遅れる時は一言伝える

  2. 条件がそろったら（トリガー）

    みんなで何かを達成したら発動する。

    配信者「みんなで質問を10個集められたら、次のコーナーに進むね。今3個！」

    例（お金を使わない）
    みんなで質問を10個集めたら、次のコーナーへ／コメントで「おかえり」が5人そろったら、とっておきの話
    ギフトを条件にする時
    例「目標のバラが100個集まったら、未公開のショート動画を先行公開」。お願いの圧にならないか、届かなくても配信が成り立つかを先に考える
    気をつけること
    目標は少し頑張れば届くくらいに。難しすぎると、参加する気持ちが下がる

  3. 毎週の定期

    毎週決まった曜日・時間に行う企画。

    配信者「毎週金曜の最後は、みんなのコメントからアイコンを描く時間！ 来週もやるよ」

    例
    毎週金曜：視聴者のコメントからアイコンを描く／毎週日曜：質問コーナー
    向いている人
    続けて配信している人。常連を育てたい人
    気をつけること
    休む時は先に伝える。楽しみにしている人ががっかりしないように

定期の企画にすると、「この曜日になったら見に行こう」という習慣が生まれ、くり返し見てもらうことにつながっていきます。

一段上の攻略ポイント「このあと何か起こる」が、なぜ見続ける理由になる？期待を作りつつ、裏切らない予告ができるようになります。深掘りする ＋閉じる －

今覚えたこと：時間指定・条件・定期の3つのサプライズ。

注意

期待は、信頼の前借り

「このあとすごいことがある」と言って中身が薄いと、その日は見てもらえても、次の予告は信じてもらえなくなります。

  1. 1この先を見たい

    何が起こるか分かっていない時間は、見続ける理由になる。

  2. 2約束が守られる

    予告どおりに起きると、「この人の予告は本当」が積み上がる。

  3. 3小さくても本物

    大げさな予告より、小さくて確実なサプライズの方が、信頼が残る。

ここが要点

判断できること

予告は、中身より少し控えめに言うくらいがちょうどいい。実際の体験が予告を少し上回ると、次の予告も楽しみにしてもらえます。

次のLIVEでは：予告する時、「ちょっとした」「小さな」をつけて言ってみます。

企画の流れの例（架空。60分の配信の場合）

  1. 始まり（〜5分）

    今日のテーマを説明する。「今日は、みんなに話題を選んでもらう回！ 30分後に、ちょっとしたお楽しみもあるよ」

  2. 投票（5〜10分）

    A・Bの投票。「A＝旅行の失敗談、B＝最近驚いた話。1文字で教えて」

  3. 選ばれた話（10〜30分）

    結果を伝えて、選ばれた話をする。途中で「みんなは似たことある？」と聞く。

  4. 小さなサプライズ（30分ごろ）

    予告どおり、最近買ったお気に入りを1つ紹介。感想を聞く。

  5. 終わり（〜60分）

    参加してくれたお礼と、次回の予告。「来週は、今日選ばれなかったBの話から始めるね」

例AかBの2択・好きな食べ物前回の続き・部屋のおなじみネタ

判断できること

注意

毎回新しいと、疲れる

毎回まったく新しい企画は、準備が大変で、視聴者も「今日は何？」と構えます。逆に、毎回同じだと飽きられます。

    毎週同じ曜日の企画・いつもの投票。安心して来られる。

  2. 2新しい（たまに）

    月に何回か、初めての企画。新しい楽しさ。

  3. 3定番の中の新しさ

    いつもの投票の、お題だけ毎回変える。

ここが要点

判断できること

まず定番の投票を1つ決めて、毎回やります。新しい企画は、その定番に足す形で試します。
