キャラ・コンセプト

「みんなに好かれる」を捨てる。誰の5分を良くするかで、指名されるライバーになる市場戦略

  • 原本：パーソナルブランド・差別化戦略／プロフィール・第一印象設計（正本より）

あなたの個性を売り込む前に、誰の5分を良くするのか決めよう。視聴者の目的と似た配信を見て、自分が届ける体験を1枚にまとめる。

誰でも来てほしいのに、誰も残らない

こんなことで迷っていませんか。

  • 「誰でも来てね」と言っているのに、また来る人が増えない
  • 自分の個性は何？ と聞かれても答えられない
  • 人気の人の真似をしても、うまくいかない

足りないのは個性ではなく、その個性が、誰のどんな時間を良くするかが伝わっていないことかもしれません。

キャラは、あなたらしい振る舞い（素材）。市場の中での価値は、それが誰のどんな時間を良くするか。この教材は後者を決めます。

読み終えると、こんな状態へ

自分の「選ばれる仮説」が1枚にまとまり、次の配信のタイトル・冒頭30秒・プロフィールに使えます。

たとえば、次の配信のタイトルを決める時。

  • 「雑談します」ではなく、誰のどんな時間かが分かる言葉が出てくる。
  • 冒頭30秒で、今何をしていて何が楽しいかを言える。
  • 配信のあとに、その仮説が当たったかを確かめられる。

「みんな」ではなく「この時間のこの人」に届く配信が、少しずつ育っていく。

「誰にでも」と「この時間のこの人に」

同じくらい感じのいい、2つの配信

誰にでも向けた配信（架空）

  • タイトル：「雑談します！ 誰でも来てね」
  • 入ってきた人へ：「いらっしゃい！ 何でも話そう！」
  • 話題：その日に思いついたこと
  • 初めての人が見るもの：何の配信か、まだ分からない

感じのいい配信。でも、また来る理由がまだ見えにくい。

明確な目的で選ばれる配信（架空）

  • タイトル：「22時｜仕事終わりの失敗談、笑って寝よう」
  • 入ってきた人へ：「おつかれさま。今、今日の失敗を笑い話にしてるところ」
  • 話題：今日の小さな失敗と、それを笑いに変える話
  • 初めての人が見るもの：何をしていて、何が楽しいかが分かる

同じくらい感じがいい配信。違うのは、どんな時に選べばいいかが伝わること。

どちらが正しいではなく、求めている時間によって選ばれる配信が違います。A の人の魅力が B より劣るわけではありません。

キャラは「優しい」の一言ではなく、温度感・距離感・言葉の運び・笑いの作り方・感情の出し方・対人での役割・勝負の時の顔、の組み合わせで見えてきます。自分の素材の探し方は「キャラ」の教材へ。ここでは、その素材を誰に届けるかを決めます。

人は、どんな時にどの配信を選ぶのか。仮説から見ていきます。

人がLIVEを選ぶ理由は、仮説で持つ

「20代女性向け」のような属性だけでは、見る理由は分かりません。同じ人でも、帰宅直後・寝る前・休日で欲しいLIVEは違います。どんな時に、どんな気分で、何を求めて来たかを、仮説として持ちます。

自分でやる時の手順

  1. 自分の配信と、似た配信を3つほど選ぶ（ジャンルが同じでも、違ってもよい）
  2. 「癒やし系」などのラベルではなく、見えた行動で書く（例：初コメントのあと少し間を取って、相手の言葉をくり返す）
  3. どの欄に、自分なら別の体験を届けられる余白があるかを探す

比べる目的は、相手の良さを真似することでも、相手を下げることでもなく、自分が自然に届けられる体験の席を見つけることです。実在の配信者の名前・数字・個人の情報は、メモにも書きません。「ほかに無いから必ず伸びる」わけでもありません。 真似をして疲れた時は、真似で身についた技術（間の取り方・見せ方）は残し、疲れる人格の設定だけをゆるめます。

コツ

違いのつくり方の例

逆張りする（大声の中で、間と穏やかさ）・ずらす（同じジャンルで、時間や目的を変える）・反転する（失敗がいちばん楽しめる配信にする）・連続化する（一回の雑談を、続きが見られる番組に）・一緒につくる（視聴者の一言で育つ）。どれも正解ではなく、素材を活かすための発想です。

違いは、「空気」でもつくれる

同じ部屋・同じ雑談でも、流れる空気が違えば、届く体験は別のものになります。

  • 夜更けの作戦会議低めの声、手元のノート。今日の挑戦と振り返りを、静かに共有する
  • 失敗を笑える研究室試して、失敗して、リアクションする。視聴者が小さな案を出す
  • 会話のある休憩室ゆっくりした返事。常連が初めての人に、軽く背景を説明する
  • 普段は静か、勝負では沸く場所いつもは雑談。Matchの前に気持ちを切り替える合図がある

空気は、背景やインテリアより、声・話し方・コメントの速さ・終わり方などの行動の積み重ねから生まれます。4つとも架空の作例です。

最後に、仮説が外れた時の直し方です。

作った仮説が外れたら、どう直す？

1回の視聴者数やギフトで、合っていた・外れたを決めません。仮説 → 配信で試す → 何が起きたかを見る、をくり返して直します。

仮説が外れた時の直し方

配信のあとに確かめる5つ

  1. 自分が自然にできたか
  2. 約束した体験が、配信の中で実際に起きたか
  3. 視聴者がどの言葉・行動に反応したか
  4. また来た人は、何を理由に来たか（聞けたら聞く）
  5. 続けても、負担が増えすぎないか

コンセプトを変える前に：反応が薄い時の5つの別解

  1. 返事が短く、次に参加する余白がない
  2. 返事は丁寧だが、名前やアイコンなど、その人とのつながりが弱い
  3. 返事は面白いが、見ているだけの人に状況が伝わっていない
  4. 歌や集中する場面で、コメントを拾わない方が自然だった
  5. 声が小さい・音楽が大きい・カメラの外を見ているなど、表現の前の問題

反応が弱い時の4つの別解

  • 素材を磨く魅力の見せ方がまだ弱い。話し方や表情の小さな技術を足す
  • 伝え方を変える中身は良いが、初めての人に伝わるまで時間がかかる。入口で今の状況を一言で言う
  • 場面をずらすその時間帯に来る人の目的とずれている。時間や曜日を変えてみる
  • 主軸を変える本人に無理がある。もっと自然に続けられる価値へ移す

変える前に考える3つの更新

  • 延長核はそのまま、表情や企画を足す
  • 再解釈別々に見えた魅力を、一本の話に束ね直す
  • 転換本人の変化や視聴者の反応をふまえて、中心を移す

仮説を変えることは、ブレではありません。理由もなく毎回言うことが変わり、視聴者が何を期待すればいいか分からなくなることがブレです。1回の視聴者数やギフトで決めず、3〜5回ほど同じ軸を試して見るのが始めやすい目安です（決まりではありません）。

ここが要点

一文は、入口で伝えるための看板です。人格の仕様書ではありません。看板に合わない顔（勝負で熱くなる・意外な一面）も、消さずに魅力として育てます。

  • 強みを、視聴者が欲しい気持ちにつなぐ自分に合うLIVEスタイルを見つける
  • 視聴者への約束から、定番と流れをつくる配信スタイルの設計図
  • 入る理由を、タイトルとカバーに落とすLIVEタイトルとカバー
  • 反応を、事実と仮説に分けて確かめるLIVEの数字から、次に直す1つを見つける方法

本編の先へ

一段上の攻略ポイント

ここは読み飛ばしても、上の本編だけで次のLIVEを始められます。もっと伸ばしたくなったら、気になる見出しだけ開いてください。

読み飛ばして先へ
  1. 013秒・30秒・3分で、約束を見せる開く

    プロフィールより、今この瞬間に見えるものが入口になります。

    1. 1

      3秒

      表情・声・画面で、何をしているか

    2. 2

      30秒

      見ているものに意味を与える一言

    3. 3

      3分

      小さな約束を回収する

    秒数は考えるための目安で、決まりではありません。

  2. 02「ほかに無い」だけでは足りない開く

    似た配信に無い席でも、求める人がいて、本人が続けられて、配信で見せられることまで確かめます。

    1. 1

      求める人がいる

    2. 2

      自分が続けられる

    3. 3

      配信で見せられる

ファン化・応援につながる理由

  • 誰の時間 → 届ける体験 → 証拠 → また来る理由

    誰のどんな時間を良くするかが決まると、配信で見せる行動がそろい、また来た時にも同じ価値を期待してもらいやすくなります。

    「この1文を作れば必ず指名される」という話ではありません。

    1. 1誰の時間
    2. 2届ける体験
    3. 3配信で見える証拠
    4. 4また来る理由

市場戦略で覚える4つ

  1. 1

    個性を売り込む前に、誰の5分を良くするかを決める

  2. 2

    選ぶ理由は仮説。どんな時・どんな気分かで考え、確かめる

  3. 3

    似た配信と、届けている体験で比べて自分の席を見つける

  4. 4

    外れたら、4つの別解と3つの更新から選んで直す

次の配信で試すこと

できた数 0 / 4

全部試せました。下の「できた目安」を確かめましょう。

できた目安

「MY CHOSEN HYPOTHESIS」で、5つの問いと、ポジショニング文が書けていたらOK。

もう一歩作った言葉を、次の配信のタイトルと冒頭で使った。

さらに上3〜5回の配信のあとに、確かめる5つを見て、仮説を1か所更新した。

その先延長・再解釈・転換を使い分けて、仮説を育て続けている。

配信のあとに見ること

1回の数字で決めずに見ます。

次は？

ひとことで言うと個性を売り込む前に、誰のどんな時間を良くするかを決める。似た配信と比べて自分の席を見つけ、1枚の仮説にして、配信で確かめて直す。

自分が誰に、何を届けるかの仮説を持てるようになりました。素材の探し方・配信スタイル・タイトルは、関連の教材でさらに深められます。
