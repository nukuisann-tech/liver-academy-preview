集客・成長

相手の探し方・誘い方・会話・終わったあとまで。初めてのコラボ配信を、二人でつくる方法

  • 原本：プロから学ぶ！コラボ配信のコツ！

コラボは、相手の人気を借りるものではありません。自分一人ではできない体験を、二人でつくるものです。目的と相性で相手を選び、送れる依頼文を書き、事前の取り決めと進行台本で当日を回し、終わったあとのフォローと振り返りまで仕上げます。

コラボしてみたい。でも、誰に、どう声をかければ？

コラボを「人気のある人とつながること」だと考えていると、相手の規模ばかり気になって、自分が何を一緒につくれるかが見えなくなります。事前に会話・進め方・終わり方を決めていないと、当日の不安も大きくなります。

コラボは、相手の人気を借りるものではありません。自分一人ではできない体験を、二人でつくるものです。大切なのは、①視聴者が楽しめること、②相手も「やってよかった」と思えること、③見た人が、いつものLIVEにも興味を持てること、の順番です。

解決すると、こんな状態へ

人気の大小に振り回されずに相手を選び、断る自由のある依頼文を送り、当日は用意した話題で二人の会話を回せるようになります。相手の視聴者には自分の魅力を自然に伝え、終わったあとは感謝と振り返りで、次の企画につながる関係が残ります。

たとえば、学んだあとのハナさん（架空）。

  • 趣味の合う、近い規模の相手に「配信を始めたきっかけ」を話す20分の企画を、丁寧に誘う。
  • 当日は用意した3つの話題で会話を回し、相手側の視聴者に普段の雑談LIVEを一言で紹介する。
  • 終わったあと、「○○の話が特に楽しかったです」と具体的な感謝を送る。

「誰かとコラボする人」から、「二人だからこそ生まれる価値を設計できるライバー」へ。

  1. 01

    コラボは、二人でつくる体験

    視聴者の楽しさ → 相手の満足 → いつものLIVEへの興味、の順に考える。

    LIVEに効く理由相手の人気に振り回されずに済みます。

    だから誰とでも、自分らしいコラボを企画できる

  2. 02

    相手は、人気より相性で選ぶ

    配信内容・人柄とテンポ・視聴者への接し方・二人の企画・約束を守れるか。

    LIVEに効く理由規模だけで選ぶと、話が合わず、どちらの視聴者も楽しめないことがあります。

    だから自然な掛け合いが生まれる相手が見つかる

    依頼文の6つの要素・事前の8つの取り決め・紹介 → テーマ → 会話の始まり方。

    LIVEに効く理由断られる・沈黙する不安が小さくなります。

    だから当日、落ち着いて二人の会話を回せる

  4. 04

    終わったあとで、関係とLIVEにつなぐ

    具体的な感謝・振り返り・相手側の視聴者への自然な自己紹介。

    LIVEに効く理由一回きりで終わらず、次の企画が生まれます。

    だからコラボが、信頼と新しい出会いの入口になる

コツ

たとえば雑談ライバーなら

「初めての人にも、私の落ち着いた雑談の雰囲気を知ってもらいたい」が目的なら、突然のギフト対戦より、相手と好きなものを語り合う共同企画の方が合っているかもしれません。

一段上の攻略ポイントコラボとLIVE Match、どう使い分ける？二人の関係や目的に合わせて、共同企画と対戦を選べるようになります。深掘りする ＋閉じる －

今覚えたこと：コラボと対戦は別。目的を1つ決める。

注意

関係が浅いうちの強い演出

知り合ったばかりの相手と、煽りや罰ゲームの強い対戦をすると、不快に感じられたり、どちらかの視聴者が離れたりすることがあります。

共同企画対戦（LIVE Match）
生まれるもの会話・共通点・違いの面白さ共通の目標・時間制限・応援の盛り上がり
向いている時初めてのコラボ・知ってもらいたい時お互いが望む時。知らない相手とランダムに当たることもある
気をつけること内輪の話にしない煽りすぎない・視聴者に無理をさせない

ここが要点

判断できること

その相手との初めてのコラボでは、まず共同企画から。強い煽りや罰ゲームは、関係ができてから選びます。演出の強さは、二人の関係の深さを超えないようにします。

まずは相手の配信を、ふつうの視聴者として何度か楽しみます。依頼は、相手のLIVEのコメント欄など人前では送らず、アプリ内の個別のメッセージで送ります。人前だと、相手が断りにくくなるからです。

    より良い

注意

返事がない時

何度も催促しません。相手の生活や予定を大切にし、別の相手や企画を考えます。誘い文の中身も見直してみます。

  2. 2だいたいの長さ

注意

連絡と会うこと

連絡はアプリ内のメッセージで行います。本名・住所・個人の連絡先は交換しません。初めてのコラボで、直接会う約束はしません。

同意は、当日でも取り下げられます。相手が迷っていたり、嫌そうにしていたりしたら、その企画は止めます。

準備ができたら、当日です。

始まりは、紹介 → テーマ → 会話

  2. ゲスト

  3. ホスト

  4. ホスト

    初めて見る方もいると思うので、○○さん、簡単に自己紹介をお願いしてもいいですか？

注意

相手の視聴者を「奪う」言い方はしない

相手のファンを自分の方へ動かそうとするのではなく、新しい出会いの場をつくるつもりで。相手の紹介や宣伝も、どちらか一方の義務にはしません。お互いの魅力が伝わる状態をつくります。

話題が一方の視聴者にしか分からなくなったら、「今来てくれた人向けに説明すると……」と前提を足し、両方の視聴者に問いかけます。

ここが要点

判断できること

コラボで知ってもらうのは入口。いつものLIVEで、同じ魅力に出会えるようにしておくことが、次につながる条件です。

次のLIVEでは：コラボの次の配信で、コラボの話を1回だけ振り返ります。

では、20〜30分の進め方を通しで見ます。

初めてのコラボ、20〜30分の進め方

練習のための例です。決まった時間ではありません。

  1. 0〜5分：挨拶と紹介

    今日の企画・お互いの自己紹介・普段のLIVE。 視聴者への軽い問いを1つ。

  2. 5〜12分：共通のテーマ

    二人の好きなもの・配信を始めた理由・最近の出来事。

  3. 12〜20分：ちがいと掛け合い

    意見が分かれるテーマ・おすすめの紹介・お互いに聞きたいこと。

  4. 20〜25分：視聴者と一緒に

    答えやすい問いを1つ。答えなくても楽しめるように。

  5. 25〜30分：振り返りと終わり

    今日楽しかったこと・相手への感謝・双方の視聴者への感謝・普段の配信・自然な終わり。

企画と視聴者の反応に合わせて、時間は変えて大丈夫です。20分で終えたい時は、12〜20分の「ちがいと掛け合い」を短くします。長く続けること自体を、成功と考えません。

終わりの切り出し

  • 区切る人が

    より良い
    「あと5分くらいですね。最後に一つだけ聞いてもいいですか？」

  • 延長を頼まれた時

    より良い
    「楽しくてまだ話せそうですが、約束の時間なので今日はここまでに。続きは、また別のテーマでお願いしたいです！」

終わり方と、終わったあとが、次につながります。

終わり方と、終わったあとの振り返り

終わりの言葉

  • 相手へ

    より良い
    「今日は○○さんと一緒に話せて楽しかったです！ 特に○○の話が面白かったです。○○さん、ありがとうございました！」

  • 視聴者へ

    より良い
    「初めて来てくれた皆さんもありがとうございます。私は普段、夜にこんな雑談LIVEをしています。よかったらまた遊びに来てくださいね」

  • 終わったあと、相手へのメッセージ

    より良い
    「今日はありがとうございました！ ○○のお話が特に楽しくて、私自身も新しい発見がありました。また機会があれば、別のテーマでも一緒にお話しできたらうれしいです！」

具体的に感謝する。うまくいかなかった所を一方的に責めない。次回を強制しない。

注意

切り抜きやショートにする時

相手が同意していて、映像・音声・音楽・視聴者の情報の扱いに問題がない時だけ、見どころを動画にすることを考えます。無断の切り抜きや転載はしません。

振り返る視点見ること
企画二人で楽しめた？ 話題は成り立った？
視聴者の体験どちらの視聴者にも話が伝わった？ 初めての人に説明できた？
相手との関係相手は話しやすそうだった？ お互いに無理はなかった？
自分の成長コラボの前より、何ができるようになった？
数字（見られる範囲で）視聴者数・コメント・フォロー・その後のいつものLIVE

コラボをしたことと、数字が変わったことの原因関係は、決めつけません。

AFTER

  • 冒頭の自己紹介を、少し丁寧にする

ここが要点

判断できること

コラボの成果は、体験・相手との関係・いつものLIVEに来てくれた人を合わせて見ます。コラボは、終わったあとのフォローまでで1回です。

次のコラボのあとでは：自分の次の配信で、相手の良さを1つ、自分の視聴者に紹介します。

最後に、当日起きやすいトラブルを見ておきます。

トラブルの時の言葉を、先に持っておく

こんな時は

  1. 相手が遅れている

    配信者「○○さん、少し遅れているみたいです。5分ほど、今日のテーマの話を先にしていますね」（10分ほど待っても来なければ、今日は見送る。待つ時間を事前に決めておくと安心。相手を責める投稿はしない）

  2. 不快なコメント

    配信者「その話はここではしないことにしています。二人の話に戻りますね」（煽り返さない。コメント管理の機能を使う。続くなら企画を止める）

  3. 突然の対戦の提案

    配信者「今日は雑談コラボの予定なので、今回は対戦なしでお願いします。また今度、相談させてください！」

  4. 通信が切れた

    配信者「○○さんの通信が切れたみたいです。2分ほど待ちますね」→ 戻れなければ「今日はここで終わりにします。来てくれてありがとう」

  5. 相手の言動が気になる

    配信者相手が個人情報を話す・ギフトを強く求める・規約に反しそうなことを言う時は、話題を変える。続くなら、予定の途中でも終えてよい。

注意

未成年と、視聴者のプライバシー

相手や視聴者が未成年かもしれない時は、利用の条件をアプリと公式ヘルプで確かめます。個別のやりとりや外部への誘導はせず、迷ったらコラボを見送ります。コメントに名前・地域などの個人情報があっても読み上げず、相手側の視聴者の情報を、相手と共有したりあとで使ったりしません。困ったコメントへの対応は「LIVEセーフティー実践ガイド」の記事も見てください。

今覚えたこと：トラブルの時の言葉を、先に持っておく。

注意

全部に応えると

相手を大切にすることと、すべての依頼に応じることは違います。望まない企画を続けると、自分も視聴者も疲れてしまいます。

例

断っていいことの例

  • 望まない対戦や、強すぎる罰ゲーム

  • 視聴者にギフトや課金を強く求める企画

  • 住んでいる場所や私生活に踏み込む企画

  • 映像の無断の切り抜きや、二次利用

  • 個人の連絡先の交換・直接会うこと・外部のサービスへの誘導

コラボのあとに見ること

同時視聴者数だけで決めずに、5つの視点で見ます。

次のコラボは？

ひとことで言うとコラボの目的を1つ決め、人気ではなく相性で相手を選び、断る自由のある依頼文で誘い、事前に時間・テーマ・終わり方を決め、当日は紹介 → テーマ → 会話で二人で進め、双方の視聴者に自分の魅力を自然に伝え、感謝と振り返りで終える。
