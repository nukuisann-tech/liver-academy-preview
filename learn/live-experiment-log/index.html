データ・改善

「昨日より人が多かった」では、成長したとは言えない。ライバーのための実験思考と録画検証

  • 原本：KPI・改善実験・録画・振り返り・初月の正本より

勘のいい配信者より、自分の当たりを再現できる配信者へ。変えたことと同時に変わったことを分けて記録し、起きた・起きなかった・判断できないを同じ重さで残す。

試したことが効いたのか、たまたまなのか分からない

こんなことで迷っていませんか。

  • 話題を変えたら人が増えた。これが正解？
  • 良かった日と悪かった日の違いが分からない
  • いろいろ試しているのに、何が効いたか残っていない

数字が変わった日には、変えたこと以外にも、同時に変わったことがあるかもしれません。

1本のLIVEを素材に、分かること・分からないこと・次に試すことを分けて記録する、実験の組み立て方を学びます。

読み終えると、こんな状態へ

次の配信で変える1つを決め、同時の変化も記録した実験ログを作れます。

たとえば、人が増えた日のログを見返した時。

  • その日だけ、開始時刻が1時間早かったことに気づく。
  • 「話題のおかげ」と決めずに、「判断できない」と書く。
  • 次は同じ時間帯で、話題だけを変えて比べることにする。

一喜一憂が減って、自分に効くやり方が少しずつ残っていく。

実験の6つの手順と、紛らわしい「同時の変化」

実験の6つの手順

  1. 事実を残す配信の日時・長さ・時間帯・その日にあったこと（イベント・Matchなど）と、録画の時刻つきの出来事を書く。見ていない時間は「見ていない」と書く
  2. 仮説を作る「〇〇を変えると、△△が起きやすくなるかもしれない」と、確かめられる形の1文にする
  3. 変える条件を1つ選ぶ次の配信で変えるのは1つだけ。ほかはできるだけいつも通りにする
  4. 結果を比べる前と同じ観察区間・同じ見方で比べる。数字が取れなければ録画の出来事で比べる
  5. 代替の説明を探す同時に変わったこと（時間帯・曜日・イベントなど）が無かったかを確かめる
  6. 次回に生かす続ける・変える・やめる・判断できない、のどれかを決め、次に試すことを書く

実際の配信では、時間帯・来る人・その日の出来事を完全にそろえることはできません。だから1回の結果で「効いた」「効かなかった」と決めず、何回か分を見て、仮説を少しずつ更新します。

紛らわしい「同時の変化」と、3つの結果

同時に変わっていないか確かめること

  • 時間帯・曜日開始時刻が違う・平日と休日
  • 配信の長さいつもより長い・短い
  • イベント・ランキングその日だけイベント期間だった
  • Match・コラボMatchの回数や相手が違う
  • 告知・動画その日だけ予告やショート動画を出した
  • 常連の参加いつもの常連が来ていた・来ていなかった
  • 本人の調子疲れ・声の調子・機材のトラブル
  • アプリ側の変化機能や表示が変わった（分からないことも多い）

このどれかが同時に変わっていたら、結果を「変えた1つのおかげ」とは言えません。記録しておけば、次の配信で比べ直せます。

結果は3つのどれかで記録する

起きた
仮説どおりの変化が、録画やコメントで見えた。ただし、同時に変わったことが無かったかも書く
起きなかった・逆だった
変化が無かった、または逆の変化が見えた。これも大事な学び
判断できない
録画が無い・比べられる条件がそろわない・やれなかった。失敗ではない

3つとも同じ重さで記録します。「起きた」だけを残すと、何が効いたかを見誤ります。やれなかった回は「やれなかった」と書き、効かなかったとは書きません。

実験を選ぶ時は、候補を全部残してから1つに絞ります。

改善の候補は全部残す。今回試すのは1つだけ

候補の台帳今回の実験
数上限を決めない。自分やAIが見つけた候補を全部残す1つ（支える行動は少しだけ）
目的選ばなかった案も、次の機会に使えるように残す何が効いたかを見分けられるようにする
選ばなかった案消さない次の配信のあとに、また選べる

この教材で言わないこと

  • これは、専門のA/Bテスト（同じ条件で2つをランダムに比べる方法）ではありません。配信では条件をそろえきれないので、「効果が証明された」とは言いません
  • 統計的に意味のある差かどうかは、ここでは計算しません。少ない回数の結果は「可能性」として扱います
  • おすすめに出るしくみ（アルゴリズム）がどう動いたかは、外からは分かりません。数字の変化を、しくみのせいだと決めつけません

ファン化・応援につながる理由

  • 記録 → 比べる → 当たりが残る → 再現できる

    同時の変化まで記録しておくと、良かったやり方を、たまたまで終わらせずにくり返せます。

    「この手順なら必ず伸びる」という話ではありません。

    2. 2比べる

    4. 4再現できる
