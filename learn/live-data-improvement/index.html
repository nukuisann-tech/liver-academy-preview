データ・改善

数字は、成績表じゃない。LIVEの数字から、次に直す1つを見つける方法

分析画面を開いて、上がった・下がったで終わっていませんか。数字を「どこで何が起きた？」の手がかりに変えて、次のLIVEで変える1つと、何回か分で見るLIVE全体の方向まで、自分で決められるようにします。

分析画面を開いた。で、次は何をすればいい？

こんなことで迷っていませんか。

  • 数字が多すぎて、どれを見ればいいか分からない
  • 昨日より下がって、落ち込む
  • 人が少ない＝自分に魅力がない？
  • コメントは多かったのに、何が良かったのか分からない
  • 全部直そうとして、何が効いたか分からなくなる
  • 1回数字が悪いと、方向を変えてしまう

足りないのは、データではありません。数字を「評価」として見ていることが、次の一手を見えなくしています。

数字は、自分を採点するものではありません。「どこで、何が起きた？」を考えるための材料です。

解決すると、こんな状態へ

LIVEが終わるたびに一喜一憂して全部変える状態から抜けて、次に変える1つがその場で決まるようになります。何を変えて何が起きたかが積み上がり、成長・ファン・収益のどこを今育てるかも、自分で決められます。

たとえば、LIVEが終わったあと。

  • 以前なら、視聴数を見て「昨日より少ない…」と落ち込み、次の日に時間もタイトルも内容も話し方も全部変えていた。
  • 学んだ後は、「入ってくる人はいた。でも残っていなさそう」と見る。そのLIVEを思い出して、「途中で来た人に、今何をしているか言っていなかったかも」と気づく。
  • 次のLIVEでは、途中で来た人への一言だけを試す。そして、数字と視聴者の反応を見る。

「数字を見るLIVE」から、「数字から学べるLIVE」へ。

1つの数字だけで、LIVE全体の良し悪しは決まらない。

たとえば、視聴数は多いのにフォローが少ないなら、「見つけてもらう」はできていて、「関係」で止まっているのかもしれません。数字は、どの段階を見ればいいかを教えてくれます。

ただし、数字が教えてくれるのは「どこ」まで。「なぜ」は、まだ分かりません。

ここが要点

数字が低い ≠ あなたに魅力がない

数字が低いのは、多くの場合、入口や流れの作りの問題です。努力不足でも、魅力の否定でもありません。逆に、数字が高くても、すべてがうまくいっているとは限りません。

注意

平均の数字の限界

平均視聴時間のような平均の数字は、どんな人が来たかで動きます。たとえば、初めての人が大きく増えた日は、まだ慣れていない人が多いぶん、平均が下がることがあります。

  1. 1視聴者の入れ替わり（Viewer mix）

    いつもの常連が中心の日と、初めての人が多い日では、同じLIVEでも平均が変わる。

  2. 2来た道の変化（Acquisition change）

    どこから来た人が多いかが変わると、入ってすぐの反応も変わる。

ここが要点

判断できること

「平均が下がった＝失敗」と決めつけない。新しい人が増えた日なのか、いつもの人が離れた日なのかを、コメントや場面と一緒に見分けます。

次のLIVEで変えるのは、原則1つ。タイトル・時間・形式・話し方・背景・お願いの仕方を同時に変えると、何が効いたか分かりません。

注意

LIVEは実験室ではない

LIVEでは、曜日・イベント・来る人など、自分では変えられないものも毎回動きます。だからこそ、自分で変えるものは1つに絞るほど、結果が読みやすくなります。

  1. 1混ざると分からない（Confounding）

    タイトルと時間を同時に変えて人が増えたら、どちらのおかげか分からない。

  2. 2学ぶ速さ（Learning speed）

    1つずつ確かめると、遠回りに見えて、効くやり方が早く残る。

  3. 3見る数字と守るもの（Primary / Guardrail）

    上げたい数字を1つ決め、代わりに壊したくないものも決めておく。

判断できること

人が多いほど、1回の変化が大きく見えます。だからこそトップ層は、何が効いたのかを分けて確かめ、良いやり方だけを型として残します。

変える1つが決まったら、何を見て確かめるかを決めます。

    今回、良くしたいもの。例：参加を増やしたい → コメント・アクティブな視聴者。

  2. 2守るもの

    良くする代わりに、壊したくないもの。例：会話の中身・部屋の空気・自分の続けやすさ。

注意

全部を同時には伸ばせない

数字は同時には伸びません。順番があります。全部を一度に追うと、どれも中途半端になりやすくなります。

  1. 1いちばんの詰まり（Bottleneck）

    流れのいちばん細い所が、全体の量を決める。そこ以外を広げても、流れは増えにくい。

  2. 2力には限りがある（Creator energy）

    準備・配信・振り返りに使える時間と気力は有限。分散すると、どれも浅くなる。

  3. 3今いちばんの目的（Primary objective）

    今の時期に、何を一番に育てるかを1つ決める。

  4. 4何かを取ると、何かが下がる（Trade-off）

    広げる時期は、関係を育てる施策を少し待つ。全部を最大にはしない。

ここが要点

判断できること

トップクラスでも、全部を同時に最大にはしません。今いちばん大きな壁を、1つずつ壊す。

  1. 1一部の人への偏り（Revenue concentration）

    1人が離れたら大きく揺れる。部屋がその人中心になる危うさもある。

  2. 2ファンの疲れ（Fan fatigue）

    毎回が山の日だと、応援する側が疲れていく。

  3. 3応援への依存（Supporter dependency）

    特定の人の応援がないと成り立たないLIVEになる。

  4. 4自分の疲れ（Creator fatigue）

    売上を保つための無理が、配信を続ける力を削る。

  5. 5一時の山と、続く収益（Short-term peak vs sustainable）

    山の日の数字に合わせず、いつもの日の価値を育てる。

判断できること

売上が上がった時ほど、偏り・疲れ・次の回に戻ったかを一緒に見ます。決まった目安はありません。前の自分とくらべます。
