会話・参加

コメント・いいね・シェアが自然に生まれるLIVE参加設計

「反応して」と頼み続けるのではなく、視聴者の一言やタップが、LIVEの一部になる部屋を作ります。

学んだ先に変わること

  1. 配信者がすること答えやすく聞き、反応をLIVEに使う
  2. LIVE視聴者が、一言・タップで参加できる
  3. 視聴者「自分の答えがLIVEを動かした」
  4. また参加する・また来る
  5. その先「自分もこの場所を作っている」関係

攻略ノート

このコンテンツで学べること

  1. 01

    聞く → 気づく → LIVEに使う

    反応をもらうだけでなく、LIVEに返すところまで設計する。

    LIVEに効く理由「自分の答えがLIVEを動かした」が、また参加する理由になります。

  2. 02

    参加しやすくなる4つの条件

    分かる・簡単・自分向け・返ってくる。

    LIVEに効く理由「コメントして」と頼まなくても、反応が生まれやすくなります。

  3. 03

    コメント・いいね・シェアの違い

    それぞれの手間と、お願いの仕方・タイミング。

    LIVEに効く理由その瞬間に合った、1つだけのお願いができます。

  4. 04

    参加がファン化につながる理由

    数より、「自分もこの場所を作っている」という体験。

    LIVEに効く理由コメント数ではなく、関係の深さが育ちます。

「お願いするのが苦手」という人へ

こんな気持ちになったことはありませんか。

  • 「コメントして」と言っても静か
  • 何度もお願いすると、しつこく感じられそう
  • いいね・シェアのお願いが、なんとなく気まずい
  • コメントは来ても、そこから続かない

問題は、お願いの回数ではないことがあります。足りないのは、行動する理由・自分で選べる感覚・行動した後の意味です。

ここが要点

視聴者が感じたのは「自分たちの反応で、部屋が変わった」。参加したくなるのは、押してほしいと頼まれたからだけではありません。押した後に意味があるからです。

このやり取りを、3つの動きに分けて見ます。

聞く → 気づく → LIVEに使う

コメント・いいね・シェアは、視聴者がLIVEへ参加するためのコミュニケーションです。

    聞く

    「AとBどっち？」

  2. 2

    気づく

    「B多いね」

  3. 3

    LIVEに使う

    「じゃあBでやる」

コメントをもらうことがゴールではない。その反応をLIVEへ返すところまでが参加設計。

では、そもそも人はどんな時に反応しやすいのか。

参加しやすくなる、4つの条件

  1. 1分かる

    何をすればいい？

  2. 2簡単

    今すぐできる？

  3. 3自分向け

    自分が答える意味がある？

  4. 4返ってくる

    反応した後、何か変わる？

手間（目安）向いている瞬間
いいねかなり少ないことが多い共感した時
コメント言葉を考えるぶん増えやすい選ぶ・答える時
シェア誰に送るか・送る意味まで考えるので、状況によって大きい役立った・面白かった時

視聴者や場面で変わります。決まった順位ではありません。

一段上の攻略ポイント参加しやすさの4条件は、なぜ効く？反応が静かな理由を、4つのどれが足りないかで見分けられるようになります。深掘りする ＋閉じる －

  1. 1前提が少なくて済む（Low context）

    説明なしで、何をすればいいか分かる。

  2. 2手間が少ない（Low friction）

    1タップ・1文字で参加できる。

  3. 3自分ごと（Relevance）

    自分の経験や気持ちで答えられる。

  4. 4すぐ返ってくる・動かせる（Feedback／Agency）

    反応がすぐ返り、自分の答えでLIVEが動く。

まず、いちばん会話になりやすいコメントから。

コメントは、答えやすい入口から、少し深い話へ

コメントは、質問をして答えてもらい、質問で返して会話を続けると生まれやすくなります。視聴者を分けて声をかける・話題を前もって準備する・同じ一言を続けて書いてもらう、も効きます。

入口は低く、あとで少し深く

  1. 1

    答えやすい入口

    AかB・はい／いいえ・絵文字

  2. 2

    少し深く

    「なんでそっち？」「どんな経験？」

全員を深い答えに連れていく必要はありません。

コメントのループ

  1. 1

    聞く

    「AとBどっち？」

  2. 2

    気づく

    「B多いね」

  3. 3

コツ

数と、意味の両方を見る

100回の「A」と、視聴者が自分の話をしてくれて、配信者と部屋がそれを覚えている状態では、関係の深さが違います。始めは答えやすい反応から。慣れてきたら、ときどき話・アドバイス・一緒に作る参加も。

一段上の攻略ポイントコメントが生まれる質問には、どんな型がある？その日の話題に合わせて、答えやすい質問を5つの型から作れるようになります。深掘りする ＋閉じる －

  1. 1質問をする

    自由に答えられる質問「みんなは週末どんなことをしているの？」／選ぶ質問「渋谷と原宿だったらどっちの方がショッピングしやすい？」

  2. 2質問で返して続ける

    「渋谷の方多いね！じゃあ、渋谷だったらどこらへん行くの？」

  3. 3視聴者を分けて声をかける

    「普段バイトしてるみんなは、1週間どれくらい働いてるの？」「今日の初見さんどれくらいいますか？ほーい！ってコメントしてくださーい！」（初めての人がコメントしやすくなる）

  4. 4話題を準備しておく

    難しすぎず、でも皆それぞれの意見を言いたくなるような話題。例「最近海外旅行する人多くない？みんなどこ行きたい？」

  5. 5同じ一言を続けて書いてもらう

    「今年の冬、イルミネーション見た？見た人は『1』とコメントして！」

ただし、聞いたのに使わないと、逆効果になります。

選ばせたなら、できる範囲で結果に使う

BEFORE

よくない

  • 「AとB選んで！」→ Bが多い
  • 「ありがとう」と言って、最初から決めていたAをやる
  • これをくり返す → 視聴者「答えても意味ない」

AFTER

より良い

  • 選ばれた方を、できる範囲でやる
  • できない時は「今日はAで決めてるけど、次回Bやります」と、答えに意味を返す

選ばせたなら、できる範囲で結果へ反映する。

コメントを書かない人にも、参加の入口があります。

いいねは、声を出さずにできる参加

トークの合間・歌の合間・パフォーマンスの合間に「いいね」をしてほしい気持ちを伝えていくと、「いいね」をすることが部屋の習慣になっていきます。

例

いいねを「静かな反応」として使う

  • 「今の話わかる人、いいねで教えて。」

  • 「この企画の続き見たい人、いいねで反応ください。」

いちばん考えて行われるのが、シェアです。

シェアは、「誰に」と「なぜ」を渡す

視聴者が自分のアカウントやほかのサービスにシェアすると、新しい視聴者に届きます。シェアしてほしい理由を一緒に伝えると、シェアしやすくなります。

シェアは「このLIVEが好き」だけでは起きないことがあります。視聴者は無意識に、誰に送る？ その人に役立つ？ 送って変じゃない？も考えます。

BEFORE

よくない

  • 「シェアお願いします」

AFTER

より良い

  • 「同じゲームで詰まってる友達いたら、これ送ってあげて」
  • 「仕事終わりで疲れてる人がいたら、一緒に来てもらえたら嬉しい」

送る相手と、送る理由を渡します。

シェアのお願いを作る時のチェック

注意

シェアの多いクリエイターほど、ギフトも多く集まる傾向があります。ただしこれは一緒に起きやすいという話で、「シェアすればギフトが増える」という意味ではありません。

では、お願いの言い方そのものを見直します。

視聴者は、自分で決めて参加したい

行動させるのではなく、参加したくなる理由を作る。

強い命令をくり返されると、人は「やらされている」と感じて、かえって動きたくなくなることがあります。視聴者は、自分で決めて参加したいのです。

    配信者が知りたい・一緒にやりたい理由

  3. 3視聴者が選べる？

    答え方・参加のしかたを選べる

  4. 4してくれたら、どう嬉しい？ 何に使う？

  • いいね

    よくない

一段上の攻略ポイントなぜお願いが強すぎると、逆に動きたくなくなる？視聴者が「自分で選んだ」と感じられることは、参加にも、ファンの信頼にも大切です。言い方を場面で使い分けられるようになります。深掘りする ＋閉じる －

場面

場面

配信の始まりから、「コメントして！」「いいね押して！」「シェアして！」が何度も続く。

  1. 最初はコメントしていた人も、だんだん静かになる

  2. 見ているだけの人は「何か求められている」と感じて、居づらくなる

お願いが強いほど、動きたくなくなることがあります。

  1. 1反発したくなる気持ち（Psychological reactance）

    自分の自由が狭められると感じると、人はかえって逆を選びたくなる。

  2. 2自分で決めたい（Autonomy）

    自分で選んだ行動は、気持ちよく続けやすい。

  3. 3自分が動かした（Agency）

    自分の答えでLIVEが変わると、参加に意味を感じる。

  4. 4自分を見て、自分を知る（Self-perception）

    何度か参加すると、「自分はこのLIVEの参加者だ」と感じるようになる。

  5. 5小さな一歩（Micro-commitment）

    一文字・いいね1回のような小さな参加が、次の参加をしやすくする。

ここが要点

現場での判断

1つの瞬間に、お願いは1つ。理由・選べる答え方・反応のその後を添えます。

注意

使わない方がいい時

「選べる」と言いながら、結果を使わない時（聞いたのに使わない、と同じになります）。小さな一歩を、あとで大きなお願いにつなげるための仕掛けとして使う時。

次のLIVEでは、お願いを1回だけにして、理由と選べる答え方を1つずつ添えてみてください。

ファン化は、言うことを聞かせることではない。「自分の意思でこの場に参加している」が積み重なること。

一段上の攻略ポイント「私」から「みんな」へ、をどう作る？部屋全体で達成する体験を、ギフトに頼らず設計できるようになります。深掘りする ＋閉じる －

AかBの結果・みんなでのチャレンジ・部屋全体への質問などで、参加の主語が「私」から「みんな」に変わります。「今日はみんなで10個アイデア出せた」のような小さな達成が、一緒にやれたという感覚（集団でできたという手応え）を生みます。ギフトの目標に限りません。
