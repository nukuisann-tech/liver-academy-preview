「反応して」と頼み続けるのではなく、視聴者の一言やタップが、LIVEの一部になる部屋を作ります。

「お願いするのが苦手」という人へ

こんな気持ちになったことはありませんか。

  • 「コメントして」と言っても静か
  • 何度もお願いすると、しつこく感じられそう
  • いいね・シェアのお願いが、なんとなく気まずい
  • コメントは来ても、そこから続かない

問題は、お願いの回数だけではありません。

大事なのは、なぜ今？　自分で選べる？　やった後どうなる？の3つです。

このページで進む道

  1. 参加しやすい状態
  2. 行動別のお願い
  3. 自然なタイミング
  4. 反応をLIVEへ返す

読み終える頃には、お願いする気まずさが減り、瞬間に合った誘い方と、反応をLIVEへ返す流れが手に入ります。沈黙を1人で埋めるのではなく、視聴者と一緒に進むLIVEへ。

コツ

定期配信と、続きが気になる企画

たとえば「毎週月〜木曜19時から」のように決まった時間に配信し、毎回テーマを変えたり、続きが気になる企画にしたりすると、視聴者が予定を合わせて戻ってきやすくなります。雑談なら、月曜は近況・火曜は質問・水曜はテーマ雑談・木曜は週末の予定、のように役割を分けられます。月〜木曜19時は紹介された例で、誰にでも合う時間という意味ではありません（時間の決め方は「勘で決めない」「週17.5時間を目指す、LIVEの時間設計」で）。

一段上の攻略ポイントコメントが生まれる質問には、どんな型がある？その日の話題に合わせて、答えやすい質問を5つの型から作れるようになります。深掘りする ＋閉じる －

  1. 1質問をする

    自由に答えられる質問「みんなは週末どんなことをしているの？」／選ぶ質問「渋谷と原宿だったらどっちの方がショッピングしやすい？」

  2. 2質問で返して続ける

    「渋谷の方多いね！じゃあ、渋谷だったらどこらへん行くの？」

  3. 3視聴者を分けて声をかける

    「普段バイトしてるみんなは、1週間どれくらい働いてるの？」「今日の初見さんどれくらいいますか？ほーい！ってコメントしてくださーい！」（初めての人がコメントしやすくなる）

  4. 4話題を準備しておく

    難しすぎず、でも皆それぞれの意見を言いたくなるような話題。例「最近海外旅行する人多くない？みんなどこ行きたい？」

  5. 5同じ一言を続けて書いてもらう

    「今年の冬、イルミネーション見た？見た人は『1』とコメントして！」

反応が来た時の、返し方の近さも大事です。

「今の自分への返事だ」と分かる近さで返す

反応が来てから、ずっと後に返すと、視聴者は自分の反応とのつながりが分かりにくくなります。

選ばせたのに使わないと、逆効果になります。

選ばせたなら、できる範囲で結果に使う

BEFORE

よくない

  • 「AとB選んで！」→ Bが多い
  • 「ありがとう」と言って、最初から決めていたAをやる
  • これをくり返す → 視聴者「答えても意味ない」

AFTER

より良い

  • 選ばれた方を、できる範囲でやる
  • できない時は「今日はAで決めてるけど、次回Bやります」と、答えに意味を返す

選ばせたなら、できる範囲で結果へ反映する。

投票やアンケートは、結果を発表して、意見に反応して、次の行動を決めるところまでで1つです（「このプレイ、何点？」→「平均7点！ 次はもっと上を狙う」）。投票の機能が使えない時は、コメントで選択肢を聞きます。

コメントを書かない人にも、参加の入口があります。

いいねは、声を出さずにできる参加

トークの合間・歌の合間・パフォーマンスの合間に「いいね」をしてほしい気持ちを伝えていくと、「いいね」をすることが部屋の習慣になっていきます。

例

いいねを「静かな反応」として使う

  • 「今の話わかる人、いいねで教えて。」

  • 「この企画の続き見たい人、いいねで反応ください。」

いいねを押しやすい配信にする

  1. 見逃せない場面をつくる

    「これは見逃せない！」と思える企画や場面。

  2. 自然な流れで伝える

    「楽しんでくれているなら、いいねを押してね！」「今のどうだった？ よかったらいいねで教えて！」

  3. 感謝を伝える

    「いいね、ありがとう！ みんなの反応がうれしいです」

いいねの数のランキングで、上位の人の名前を呼んでお礼をする、という使い方も紹介されています。今のアプリで同じランキングが見られるかは画面で確かめます。見られなくても、いいねへのお礼はいつでもできます。呼ぶ時は上位だけを特別扱いせず、「いいねしてくれたみんな、ありがとう」も必ず添えます。順位を競わせる言い方はしません。コメントしなくても、いいねで参加できることが、参加の入口を低くします。

いちばん考えて行われるのが、シェアです。

シェアは、「誰に」と「なぜ」を渡す

視聴者が自分のアカウントやほかのサービスにシェアすると、新しい視聴者に届きます。シェアしてほしい理由を一緒に伝えると、シェアしやすくなります。

シェアは「このLIVEが好き」だけでは起きないことがあります。視聴者は無意識に、誰に送る？ その人に役立つ？ 送って変じゃない？も考えます。

BEFORE

よくない

  • 「シェアお願いします」

AFTER

より良い

  • 「同じゲームで詰まってる友達いたら、これ送ってあげて」
  • 「仕事終わりで疲れてる人がいたら、一緒に来てもらえたら嬉しい」

送る相手と、送る理由を渡します。

強い命令をくり返されると、人は「やらされている」と感じて、かえって動きたくなくなることがあります。視聴者は、自分で決めて参加したいのです。

    答え方・参加のしかたを選べる

  4. 4してくれたら、どう嬉しい？ 何に使う？

言い方を見くらべる

  • コメント

    よくない
    「コメントして！」
    より良い
    「みんなの感覚が知りたい。AとBどっちか、一文字だけでも教えて。多かった方から話すね。」
    上級の言い方
    「疲れてる人も一文字でOK。A＝もう無理、B＝まだいける。Aが多かったら今日はゆるく、Bが多かったら少し攻めた話にするね。」

  • いいね

    よくない
    「いいね連打して！」
    より良い
    「この話、もうちょっと聞きたい人いたら、いいねで合図して。反応多かったら続きも話すね。」
    上級の言い方
    「声出さなくて大丈夫。『わかる』って思ったら、いいねで合図ちょうだい。いっぱい来たら、もう1個エピソード出す（笑）」

  • シェア

    よくない
    「シェアお願いします。」
    より良い
    「これ、同じことで悩んでる友達がいたら、送ってもらえたら嬉しい。よかったら次のLIVE、一緒に来てもらうのも大歓迎。」
    上級の言い方
    「今の話、月曜がしんどい友達にちょうどいいかも。送るなら『これ聞いて元気出た』って一言添えてくれたら、その人も入りやすいと思う。」

    「教えてくれたら嬉しい」

  2. 2目的

    「みんなの感覚を知りたい」

  3. 3その後

    「多かった方からやる」

全部を「〜してくれたら嬉しい」にしません。3つを使い分け、組み合わせます。

  • 元気なキャラ

    より良い
    「AかB！ どっち！？」

  • 落ち着いたキャラ

    より良い
    「AとBなら、どちらが近いですか？ 一文字だけでも大丈夫です。」

  • 世界観のあるキャラ

    より良い
    （例：占い師の枠なら）「今宵の運命は、AかBか。あなたの一文字で決めましょう。」

コツ

選べることを守る一言

必要な時だけ、「聞くだけでも大丈夫」「答えたい人だけでOK」を添えます。毎回付けると長くなるので、初めての人が多い時や、深い質問の時に。

一段上の攻略ポイントなぜお願いが強すぎると、逆に動きたくなくなる？視聴者が「自分で選んだ」と感じられることは、参加にも、ファンの信頼にも大切です。言い方を場面で使い分けられるようになります。深掘りする ＋閉じる －

場面

場面

配信の始まりから、「コメントして！」「いいね押して！」「シェアして！」が何度も続く。

  1. 最初はコメントしていた人も、だんだん静かになる

  2. 見ているだけの人は「何か求められている」と感じて、居づらくなる

お願いが強いほど、動きたくなくなることがあります。

  1. 1反発したくなる気持ち（Psychological reactance）

    自分の自由が狭められると感じると、人はかえって逆を選びたくなる。

  2. 2自分で決めたい（Autonomy）

    自分で選んだ行動は、気持ちよく続けやすい。

  3. 3自分が動かした（Agency）

    自分の答えでLIVEが変わると、参加に意味を感じる。

  4. 4自分を見て、自分を知る（Self-perception）

    何度か参加すると、「自分はこのLIVEの参加者だ」と感じるようになる。

  5. 5小さな一歩（Micro-commitment）

    一文字・いいね1回のような小さな参加が、次の参加をしやすくする。

ここが要点

現場での判断

1つの瞬間に、お願いは1つ。理由・選べる答え方・反応のその後を添えます。

注意

使わない方がいい時

「選べる」と言いながら、結果を使わない時（聞いたのに使わない、と同じになります）。小さな一歩を、あとで大きなお願いにつなげるための仕掛けとして使う時。

ここが要点

やわらかく、でもはっきり

参加するかどうかは自由。でも、何をすればいいかは明確に。「答えたい人だけでいいので、AかBを一文字で」のように、選べる自由と、具体的な行動を両方渡します。

次のLIVEでは、お願いを1回だけにして、理由と選べる答え方を1つずつ添えてみてください。

同じお願いでも、「いつ言うか」で受け取られ方が変わります。

お願いは回数より、「今この瞬間に自然か」

    価値のある瞬間

    役立つ話・笑い・共感・達成

  2. 2

    その行動が合う

    今なら自然か

  3. 3

    お願い

    1つだけ

ここが要点

コメント・いいね・シェア・フォロー・ギフトを一気に頼まない。1つの瞬間に、お願いは1つ。LIVEを「やることリスト」にしません。

一段上の攻略ポイント毎回「コメントして」と言わずに、参加が生まれる部屋を作れる？「この時間は参加するところ」と視聴者が分かっていると、お願いを減らしても反応が生まれます。お願い疲れを防ぐ仕組みを作れるようになります。深掘りする ＋閉じる －

場面

場面

毎回の配信の始まりに、同じ質問のコーナーがある。

  1. 常連は、始まった瞬間に「今日の一言」をコメントする

  2. 初めての人も、みんなが答えているのを見て一言書く

お決まりがあると、お願いしなくても参加が生まれます。

例

参加のお決まりの例

  • 定番のAかBコーナー

  • 始まりの質問（「今日の気分を一言で」）

  • 終わりの投票（「次回のテーマどっち？」）

  • いつもの絵文字（「おつかれの人は🍵」）

  • 視聴者が選ぶコーナー

ここが要点

現場での判断

お決まりは1つから。同じ場所・同じ言い方でくり返すと、「あ、この時間は参加するところ」と覚えてもらえます。番組の型づくりは「LIVEフォーマットの作り方」で扱います。

注意

使わない方がいい時

お決まりを増やしすぎて、LIVEがコーナーの連続になる時。新しい人に意味が分からない内輪の合図だけになる時（初めての人向けに一言添えます）。

ファン化は、言うことを聞かせることではない。「自分の意思でこの場に参加している」が積み重なること。

ここが要点

欲しいのは、コメント数だけではありません。「またこの部屋に参加したい」と思える体験です。

一段上の攻略ポイント「私」から「みんな」へ、をどう作る？部屋全体で達成する体験を、ギフトに頼らず設計できるようになります。深掘りする ＋閉じる －

AかBの結果・みんなでのチャレンジ・部屋全体への質問などで、参加の主語が「私」から「みんな」に変わります。「今日はみんなで10個アイデア出せた」のような小さな達成が、一緒にやれたという感覚（集団でできたという手応え）を生みます。ギフトの目標に限りません。

一段上の攻略ポイント参加の段階は、なぜ押し上げてはいけない？見るだけの人を大切にしながら、参加の入口を増やせるようになります。深掘りする ＋閉じる －

一段上の攻略ポイント人数が増えたら、参加の受け止め方はどう変える？人数が多くても、進行を止めずに反応を返せるようになります。深掘りする ＋閉じる －
