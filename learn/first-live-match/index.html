イベント・成長

相手選び・5分を想定した台本・勝敗のあとまで。初めてのLIVE Matchを、勝っても負けても楽しい時間にする

  • 原本：プロから学ぶ！LIVE Matchのコツ！

LIVE Matchは、数字だけの勝負ではありません。勝敗があるからこそ生まれる緊張感・一体感・笑いを、視聴者と一緒に楽しむ企画です。しくみと目的を押さえ、相性で相手を選び、5分を想定した練習用の台本で進め、勝っても負けても相手と視聴者を大切にして、いつものLIVEへつなげます。

Matchをしてみたい。でも、ちょっと怖い。

こんなことで迷っていませんか。

  • Matchって、ギフトをたくさんもらうための勝負？
  • リーグの高い人と戦えば伸びる？
  • 始まったら、5分間なにを話せばいい？
  • 負けたら気まずい
  • 対戦中だけ盛り上がって、終わると静かになる

Matchを「数字の勝負」とだけ考えていると、スコアばかり見て話せなくなったり、勝敗で気持ちが大きく揺れたりします。勝敗のスコアと、視聴者が楽しいと感じる時間は、同じものではありません。

LIVE Matchは、勝敗があるからこそ生まれる緊張感・一体感・笑いを、視聴者と一緒に楽しむ企画です。そして、勝利を目指すことと、視聴者に課金を強いることは、ちがいます。

解決すると、こんな状態へ

Matchのしくみと目的が分かり、相性で相手を選べます。始まる前にルールを確かめ、5分を想定した台本で落ち着いて進め、勝っても負けても相手と視聴者に感謝して、いつものLIVEへ自然に戻れるようになります。

たとえば、学んだあとのミユさん（架空）。

  • 同じ雑談LIVEの相手と、ルールと「負けた時は相手のよいところを3つ紹介」を事前に決める。
  • 対戦中は、状況を伝えながら、用意した3つの話題で相手と掛け合う。
  • 結果のあと、相手と視聴者に感謝して、「普段はこんな雑談をしています」といつものLIVEへ戻る。

「ただ勝負をするライバー」から、「勝敗のある時間を、また見たくなる時間に変えられるライバー」へ。

  1. 01

    Matchは、勝敗のある企画

    しくみ・コラボとのちがい・前／最中／あとの3段階・目的を1つ。

    LIVEに効く理由スコアだけを追わずに済みます。

    だから目的に合ったMatchを選べる

  2. 02

    相手は相性で選び、始める前に確かめる

    相手選びの5つの軸・リーグの考え方・始まる前に相談する6つ。

    LIVEに効く理由かみ合わない対戦や、同意のない罰ゲームを防げます。

    だから二人とも安心して始められる

  3. 03

    短い対戦時間を、台本と言葉で進める

    始まる前の1分・5分を想定した練習用台本・ギフトの受け方・勝敗の言葉・課金を強いない応援の言葉。

    LIVEに効く理由始まった瞬間に黙ってしまう不安が小さくなります。

    だから見ているだけの人も楽しめる対戦になる

  4. 04

    終わったあとで、いつものLIVEにつなぐ

    感謝の順番・つながっている間と切ったあと・いつものLIVEへの戻り方・あと10分を見る視点。

    LIVEに効く理由対戦中だけの盛り上がりで終わりません。

    だからMatchが、新しい出会いと次のLIVEの入口になる

学んだ先に変わること

  1. 配信者がすること目的と相性で、Matchの相手を選べる
  2. ルールを確かめ、短い対戦時間を台本と言葉で進められる
  3. 視聴者ギフトを送らない人も、対戦の緊張感と掛け合いを楽しめる
  4. LIVEMatchで初めて来た人に、いつものLIVEの魅力が伝わる（約束ではない）
  5. その先勝っても負けても敬意を保つことで、また対戦したい相手が増えていく
  6. 「ただ勝負をするライバー」から、「勝敗のある時間を、また見たくなる時間に変えられるライバー」へ

ボタンの名前・使える条件・画面の表示は変わることがあります。招待のほかに、知らない相手とつながる方法がある場合もあります（要確認）。初回は、招待で知っている相手と始めるのが安心です。

ここが要点

何がポイントになるかは、Matchの形式で変わる

ギフトや「いいね」がポイントに関係する形式があります。一方で、特定のギフトだけが最終スコアの対象になる形式もあると案内されていて（要確認）、その時はほかのギフトや「いいね」が得点にならないことがあります。「いいねを押せば、どのMatchでも必ず得点になる」とは言えません。始まる前に、画面のルールを確かめて、視聴者にもそのまま伝えます。

ふつうのコラボLIVE Match
中心にあるもの二人の会話と企画勝敗のある、時間の決まった対戦
視聴者の楽しみ二人の掛け合い・共通点・ちがい掛け合いに加えて、残り時間の緊張感と結果を一緒に見守ること
必要な力相手選び・誘い方・会話を回すルールの説明・状況の実況・勝敗への対応・終わったあとの切り替え

相手の探し方・誘い方・コラボの基本マナーは「初めてのコラボ配信」の記事にあります。このページは、勝敗のある時間の進め方を中心に扱います。

注意

ギフトのこと

ギフトは、お金で購入したコインを使って送るバーチャルアイテムです。送る側にも受け取る側にも、年齢（原則18歳以上）などの条件があり、地域やアカウントで変わることがあります。Matchを楽しむ方法は、ギフトだけではありません。

Matchは、対戦している数分間だけで終わる企画ではありません。前の準備と、終わったあとまで含めて1つの体験です。

  1. A普段とちがう楽しさをつくる

    雑談だけでは生まれにくい緊張感や掛け合いを楽しむ。

  2. B新しいライバーと交流する

    ほかのライバーの進め方から学ぶ。

  3. C新しい人に知ってもらう

    普段は接点のない人が、自分の配信を知るきっかけにする。

  4. D視聴者と一緒に応援を楽しむ

    試合の状況を共有して、一緒に盛り上がる。応援の仕方は視聴者が自由に選ぶ。

  5. E自分の進行力を鍛える

    短い時間で、説明・会話・盛り上げ・締めまでを練習する。

今回のMatchで一番大切にしたいことを、1つ選びます。

注意

全部を一度に狙うと

「楽しく話す」「勝つ」「新しい人に知ってもらう」を全部同時に追うと、進行がぶれて、どれも中途半端になりやすくなります。

目的合う進め方
交流・学び勝敗より掛け合い。終わったあとの会話を長めに
新しい人に知ってもらう最初の紹介と、終わったあとの自分の配信の一言を丁寧に
視聴者と応援を楽しむ状況の実況をこまめに。無料で参加できる方法も正しく案内
競争を楽しむお互いが本気の対戦を望んでいる相手と。勝敗後の敬意を先に決めておく

ここが要点

判断できること

目的に合わせて、相手・ルール・話題・終わり方を選びます。目的が変われば、同じ相手でも進め方は変えて大丈夫です。

次のMatchでは：目的を1つ書いてから、相手を探します。

目的が決まったら、相手を選びます。

対戦相手は、リーグより相性で選ぶ

  1. 1配信スタイル

    落ち着いた雑談型？ にぎやかな企画型？ 歌やゲームが中心？

  2. 2視聴者との関わり方

    初めての人を大切にしているか。ギフトを強く求めていないか。困ったコメントに落ち着いて対応しているか。

  3. 3相性

    会話のテンポ・言葉づかい・笑いの好み・勝負への考え方。

  4. 4対戦の目的が近いか

    気軽な交流か、本気の競争か、企画を楽しみたいのか。

  5. 5同意と負担

    二人とも対戦に納得しているか。無理な時間帯や長さになっていないか。

誘い方と、ボタンを押す前に決めること

初めての相手を誘う

  • 依頼文

    よくない
    「Matchしてください！」（何をしたいのか、相手が判断できない）
    より良い
    「はじめまして。普段、夜に雑談LIVEをしているミユです。いつも配信の雰囲気がすてきだなと思って見ています。もしよければ、今度短めにLIVE Matchをご一緒できたらうれしいです。私はまだ経験が少ないので、最初はルールを確認しながら、楽しく対戦できたらと思っています。ご都合が合わなければ、もちろん大丈夫です！」

相手の配信を見て、相手に合う言葉へ直します。相手のLIVEのコメント欄など人前では誘わず、アプリ内の個別メッセージで送ります。

  1. 1形式

    個人対戦か、チーム対戦か。初回は1対1の個人対戦がおすすめ。チーム対戦なら、話す順番・紹介の順番・誰がルールを説明するかを先に決め、味方のライバーの視聴者にも挨拶する。

  2. 2ポイントの対象

    ふつうのギフトや「いいね」も対象か。特定のギフトだけが対象か。

  3. 3時間と回数

    画面に出る制限時間。何回するか。初回は1回と決め、負けた直後の「もう1回」は、決めた回数を超えてしない。

  4. 4負けた時の演出

    負けた時の演出（罰ゲーム）をするか。するなら何をするか、二人とも同意しているか。候補は次の「負けた時の演出」で。

  5. 5視聴者への説明

    初めて来た人にも分かるように、ルールをどう一言で伝えるか。

  6. 6安全と配慮

    不快な発言・強すぎる課金のお願い・個人情報・相手への攻撃が出た時、どうするか。自分の配信では、Matchの前にモデレーターとNGワードを設定しておく（「LIVEセーフティー実践ガイド」）。

この6つを、誘う時か、始まる前に相談します。

ここが要点

対戦ボタンを押す前に

二人とも、これから何をするか分かっている状態をつくってから始めます。コラボに「いいよ」と言ったことは、対戦・罰ゲーム・ギフトの企画にまで「いいよ」と言ったことにはなりません。

注意

知らない相手と、急につながる時

準備なしで知らない相手と対戦がつながることもあります。その時も、最初に挨拶して、今の対戦の形式とポイントの対象を画面で確かめ、視聴者に一言で伝えます。相手の言動が合わない・不快な時は、言い返さずに対戦や共同ホストを終えます。性的な内容・危険な行為・個人情報が相手の画面に出た時は、すぐに終えて、必要ならブロック・通報します。日時と相手のアカウント名をメモしておくと、通報する時に役立ちます。途中で終える方法と、終えた時の扱いは、事前に画面で確かめておきます。

負けた時の演出は、何なら安心して楽しめる？

負けた時の演出（罰ゲーム）は、二人が同意したものだけ

  1. 1早口言葉チャレンジ

    事前に決めた短い早口言葉に挑戦する。

  2. 2相手のよいところを3つ紹介

    負けた側が、相手を褒める。

  3. 3いつもとちがう声で一言

    本人が同意した範囲で、短いセリフを言う。誰かのまねや、からかいに見える声は選ばない。

  4. 4好きなものを30秒で熱弁

    好きな食べ物などを、30秒で紹介する。

  5. 5次回の話題を相手が決める

    事前に合意した、安全で話しやすい候補の中から選ぶ。

初心者向けの、安全な候補の例です。

例

しないこと

  • 危ない体の動き・無理な飲食

  • 性的な演出

  • 見た目や人柄を傷つける内容

  • 恥ずかしい格好・衣装を強いること

  • 性別・年齢・出身などの属性や、差別につながる内容をネタにすること

  • 個人情報を出させること

  • アイコンや名前の変更・SNSへの投稿など、配信が終わったあとまで続くこと

  • 家族・友人・視聴者など、その場にいない人や同意していない人を巻き込むこと

  • ギフトの数・金額・種類を条件にした罰や演出（金額の大小にかかわらず）

  • 相手が嫌がっているのに続けること

ここが要点

負けても、その人の尊厳は傷つけない

演出の強さは、二人の関係の深さを超えないようにします。初めての相手とは軽いものから。罰ゲームをしないで終えるのも、立派な選択です。同意は当日でも取り下げられます。

準備がそろったら、対戦中の立ち回りです。

Match中の立ち回り：5つの行動

  1. 1相手を紹介する

    「今日は○○さんとMatchします！ 普段は歌のLIVEをされている方です」

  2. 2今日の企画を伝える

    「今日はお互い、楽しく対戦しながら話していこうと思っています」

  3. 3今の状況を伝える

    「今、対戦が始まりました！」「残り時間を見ながら楽しんでいきます」

  4. 4勝負以外の楽しさをつくる

    相手との掛け合い・短い質問・対戦にちなんだ遊び・共通の話題。

  5. 5結果に合わせて反応する

    勝っても相手を大切に。負けても視聴者を責めない。

対戦中の言葉

  • スコアを見ながら

    よくない
    「もっと！ もっと！ もっと！」「残り10秒、あと○ポイント！」（スコアだけを見て、同じ言葉や数字をくり返す）
    より良い
    「今ちょっとリードされてる！ ○○さん、さっきの話の続き聞かせてください。来てくれた皆さん、見ててくれてありがとう！」（状況を伝える → 相手と会話する → 感謝する、を組み合わせる）

Match中にギフトが届いたら

  • 1つ届いた時

    よくない
    （スコアを見たまま）「ありがとうございますー」
    より良い
    「○○さん、ありがとう！ 一緒に楽しんでくれてる感じ、うれしい。で、△△さん（相手）、さっきの特技の話の続き——」（名前と一言 → 話へ戻る）

  • 続けて届いた時

    よくない
    （一人ずつ読み上げて、掛け合いが止まる）

    毎回、勝敗に強いストレスを感じていない？

正しい回数は、人によってちがいます。最初から毎日する必要はありません。続けて楽しめるスタイルなら、経験を深める選択もあります。

Academyの練習例です。3回で勝てるようになる、という意味ではありません。

  1. LIVE 1 しくみを知る

    対戦の種類と、ポイントの対象を確かめる。安全設定（モデレーター・NGワード）も確かめる。自分の配信で「Matchって知ってる？」と話してみる。

  2. LIVE 2 1回だけ、短く試す

    相性のよい相手と、目的とルールを決めて、このページの台本で試す。

  3. LIVE 3 1つだけ直す

    最初の挨拶・話題の準備・終わったあとの感謝・いつものLIVEへの戻り方、から1つ。

ここが要点

自信がなくても大丈夫

最初からMatchが得意である必要はありません。しくみを知る → 目的を1つ → 相性のよい相手 → 簡単な台本 → 1回試す → ふり返る、の順で進めます。そして、Matchを使いこなすことと、Matchを必ずすることは、ちがいます。自分の配信に合わなければ、無理に増やさなくて大丈夫です。

一段上の攻略ポイントMatchをしない、という判断Matchを毎回の義務ではなく、使い分ける戦略の1つとして選べるようになります。深掘りする ＋閉じる －

今覚えたこと：頻度は5つの軸で決める。まずは1回。

注意

Matchばかりになると

盛り上がりの多い配信が続くと、雑談やいつもの会話でできる関係づくりの時間が減り、視聴者も配信者も疲れやすくなります。応援してくれる人がまだ少ない時期は、スコアの差が大きく見えて、常連さんが「自分が送らないと」と申し訳なさを感じることもあります。その時期は、勝敗より企画の色が強い相手や進め方を選びます。
