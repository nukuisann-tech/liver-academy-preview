収益・成長

ポイントを集める前に。人気LIVEランキングで、参加したくなるチームを育てる方法

「ポイントお願いします！」だけでは、初めての人には理由も意味も届きません。チームポイントの仕組みを正しく知ったうえで、視聴者が「自分もこのLIVEの一員」と感じて参加したくなる、15分の流れを作ります。

ランキングを見ても、何をお願いすればいいか分からない

こんなことで迷っていませんか。

  • 人気LIVEランキングって何？
  • チームポイントは、どうやって貯まるの？
  • 常連が少なくても、参加できる？
  • コメントが少なくて、盛り上がらない
  • 応援をお願いするのが苦手
  • 上位の人は、どうしてあんなに一体感があるんだろう？

ポイントが伸びない理由は、お願いが足りないからとは限りません。もっと手前で、視聴者が、そのLIVEにどう参加すればいいか分からないことが多いのです。

ランキングは、結果を示す仕組みです。参加したくなるチームづくりは、日々の配信から始まります。そして、参加の仕方は1つではありません。

解決すると、こんな状態へ

「ポイントお願いします」しか言えない気まずさから抜けて、初めての人も常連も、見ているだけの人も参加できる15分の流れを、自分で作れるようになります。小さな共通の体験が積み上がり、「今日もあのLIVEへ行ってみよう」が育っていきます。

たとえば、こんな配信。

  • 以前は、自分だけが話し続けていた。コメントを待っても、なかなか反応がない。
  • 答えやすい問いを用意したら、初めての人がコメントする。常連がそのコメントを拾う。ライバーが、一人ひとりの参加を歓迎する。
  • 配信の空気が、少しずつ「みんなの時間」に変わっていく。

やがて視聴者の間に、「今日もあのLIVEへ行ってみよう」という理由が生まれていく。

注意

コメントを拾うだけの限界

「ありがとう」と読み上げるだけだと、自分の参加が場に何か起こした実感は残りにくい。

  1. 1影響の手応え

    場面：「家派」とコメントしたら、ライバーが「じゃあ今日は家でできる遊びの話にしよう」と話を変えた。

  2. 2自分で選べる

    場面：「コメントでも、見てるだけでもいい」と言われ、自分のタイミングで一言書けた。

  3. 3認められる

    場面：初めてのコメントに名前で返事があり、ほかの視聴者も「わかる」と続いた。

ここが要点

判断できること

コメントをもらったら、その答えで、配信の何かを少し変える。それが「また参加したい」につながりやすくなります。

次のLIVEでは：もらった答えを1つ、実際に話の流れに使います。

一段上の攻略ポイント常連が増えるほど、初見が入りにくくなるのはなぜ？常連との関係を大切にしながら、新しい人の居場所もつくれるようになります。深掘りする ＋閉じる －

今できること：1人のコメントを、会話に広げられる。

注意

仲が良いほど起きること

常連との会話が盛り上がるほど、あとから来た人には「内輪の話」に見えて、入るきっかけがなくなることがあります。

  1. 1今の話を一言で

    「今ね、○○の話で盛り上がってたところ」と、途中で来た人に渡す。

  2. 2常連に、初見をつないでもらう

    「○○さん、初めての人にこの話のきっかけ教えてあげて」と、常連を迎える側にする。

  3. 3誰でも答えられる問い

    内輪ネタではなく、初めての人も答えられるお題を、時々はさむ。

ここが要点

判断できること

一体感がある部屋は、閉じているのではなく、新しい人が入れる入口を、常連と一緒に用意している部屋です。

次のLIVEでは：途中で来た人に、「今の話」を一言で伝えます。

では、これを15分の流れにします。そのまま次のLIVEで試せる形です。

15分の参加シナリオ：そのまま試せる流れ

次のLIVEの最初の15分を、この流れで進めてみます。ランキングの話は、しなくても大丈夫です。

  1. 0〜3分：参加しやすい入口

    「こんばんは！ 今日はみんなに聞きたいことがあるんです。休みの日は、家でゆっくりする派？ 外に出る派？」——最初に、答えやすい問いを1つ。

  2. 3〜7分：1人の参加を、会話へ広げる

    「家でゆっくり派なんですね！ 私も今日はそうしたかったんです。ちなみに、何して過ごすことが多いですか？」——答えてくれたことを歓迎し、もう一歩深く聞く。

  3. 7〜12分：同じ時間を、みんなで楽しむ

    「今の話、ほかのみんなはどう思う？」——何人かが同じ話題に入れるようにする。必要なら、ここでチームの目標を分かりやすく伝える。

  4. 12〜15分：感謝と、次に来る理由

    「今日はいろんな意見が聞けて楽しかった！ 次は○○の話をしてみたいな。見てくれた人も、コメントしてくれた人もありがとう！」——順位ではなく、一緒に過ごした時間を振り返る。

15分は、練習のための例です。どの配信でもこの時間がいちばん良い、という決まりではありません。

流れができたら、ランキングへの挑戦を、部屋の物語にしてみます。

ランキングへの挑戦を、部屋の物語にする

BEFORE

数字だけ

  • 「今日は○位を目指します！ 応援お願いします！」

AFTER

物語にする

  • 「いつも少人数で話してるこの部屋が、今日は初めてチームのランキングに挑戦する日です」
  • 「目標は、みんなで○○まで行くこと。届いても届かなくても、今日のことは一緒に振り返ろう」

  1. 1届いた時

    一緒に喜ぶ。「みんなで来れたね」と、誰の応援かではなく、みんなの時間として振り返る。

  2. 2届かなかった時

    一緒に挑戦した時間を振り返る。「悔しいけど、今日のこの空気、すごく楽しかった」。

注意

しないこと

目標を「ギフトの量」だけにしない（コメントの人数・初めて来た人を迎える・みんなでお題に答える、なども目標になります）。応援の量によって、扱いや仲間としての立場が変わるような見せ方はしません。

一段上の攻略ポイントチームの目標は、どう作ると一体感になる？お金に頼らない目標で、みんなが「自分も役に立てた」と感じる挑戦を作れるようになります。深掘りする ＋閉じる －

今覚えたこと：挑戦を、部屋の物語にする。

注意

目標が順位だけだと

順位は、ほかのチームの動きでも変わります。順位だけが目標だと、届かなかった日に「何もできなかった」感覚が残りやすい。

  1. 1共通の目標

    例：今日は、初めての人3人と話す。お題に全員で答える。

  2. 2役割

    例：常連は初めての人を迎える係、静かな人はいいねで応援。

  3. 3挑戦

    例：「この部屋で初めて」の何か。

  4. 4達成の体験

    例：届いた瞬間をみんなで喜び、次の配信で振り返る。

ここが要点

判断できること

一体感は、誰でも届けられる役割が用意されているかで決まりやすい。お金を使う人だけが役に立てる目標にしません。

次のLIVEでは：お金を使わなくても参加できる小さな目標を、1つ用意します。

一段上の攻略ポイントランキングで新しい人が来たら、どう迎える？上位の表示で来てくれた人を、一度きりで終わらせず、また来たくなる人に変えられるようになります。深掘りする ＋閉じる －

今できること：挑戦を物語として伝えられる。

注意

見つけてもらうだけでは終わる

上位の表示で人が来ても、迎える・フォローの理由・また来る理由が弱いと、一度きりで終わりやすい。

  1. 1迎える

    「ランキングから来てくれたのかな？ ようこそ！ 今、○○の話をしてるよ」

  2. 2何の配信か伝える

    「いつもは平日の夜に、こんな話をしてる部屋です」

  3. 3また来る理由

    「次は○曜日に、今日の続きをやるよ」

ここが要点

判断できること

ランキングの成果は順位ではなく、来てくれた人が、また来たかで見ます。

次のLIVEでは：初めての人に、「次はいつ、何をするか」を1つ伝えます。

挑戦のあとは、振り返りです。順位だけでなく、参加を見ます。

振り返りは、順位と「参加」の両方で

例

ランキングのあとに見ること

  • 何人くらいが参加した？（コメント・いいね・見てくれた人）

  • 初めてコメントした人はいた？

  • 会話は続いた？

  • 次の回にも、来てくれた人はいた？

  • 応援の呼びかけが、負担になっていなかった？

注意

順位やポイントが動いても、今回の工夫だけが理由とは限りません。曜日や、その日に来た人、ほかのチームの動きでも変わります。

一段上の攻略ポイント盛り上げるほど、疲れさせていない？短い盛り上がりと、長く続く信頼を分けて、どちらも壊さない加減を選べるようになります。深掘りする ＋閉じる －

今覚えたこと：振り返りは、順位と参加の両方で。

注意

盛り上がりの裏側

何度も応援を呼びかけると、その場は盛り上がっても、視聴者が「来ると気をつかう」と感じ始めることがあります。

短い盛り上がり長く続く信頼
中心今日の順位・ポイントまた来たい・応援してよかった
呼びかけ回数が増えやすい必要な場面だけ
見ること今日の結果次の回に戻ったか・疲れていないか

ここが要点

判断できること

呼びかけのあと、コメントが減った・空気が固くなったと感じたら、その日はいつもの会話に戻ります。

次のLIVEでは：応援の呼びかけは、意味のある場面で1回だけにしてみます。

一段上の攻略ポイントランキングに挑戦した後の、いつもの配信は？挑戦の日が終わっても、来たくなる理由を残せるようになります。深掘りする ＋閉じる －

今できること：ランキングの日を、物語として振り返れる。

注意

山のあとの谷

挑戦の日だけが盛り上がると、いつもの日が「何もない日」に見えて、来る理由が薄くなることがあります。

  1. 1挑戦の話を、いつもの日に持ち帰る

    「この前のランキングの日、楽しかったね」と、共通の思い出として話す。

  2. 2いつもの楽しみを残す

    お題・コーナー・決まった時間など、挑戦がなくても来たくなる理由。

  3. 3次の挑戦は、少し先に

    毎回を挑戦の日にしない。いつもの日が、関係を育てる日。

ここが要点

判断できること

挑戦の次の配信に、挑戦の日に来た人が戻ってきたかを見ます。戻っていれば、チームが育っています。

次のLIVEでは：挑戦の日の思い出を、1回だけ話題にします。
