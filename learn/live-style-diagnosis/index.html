自分に合うLIVEスタイルを見つける

診断から始めません。まず4つのLIVEの場面を見て、続けやすくて視聴者にも喜ばれる「自分の強み」を1枚にします。

学んだ先に変わること

  1. 配信者がすること自分の強みを見つける
  2. LIVE毎回同じ価値を出しやすい
  3. 視聴者視聴者が「この人を見る理由」を分かる
  4. 期待して、また来る
  5. その先「この人といえば」が育つ

攻略ノート

このコンテンツで学べること

  1. 01

    4つのLIVEの場面から、入口を見つける

    雑談・パフォーマンス・知識・キャラクターで、視聴者の体験がどう違うかを見る。

    LIVEに効く理由「一番すごい」ではなく、自分が続けやすい入口が見つかります。

  2. 02

    公式の3つの質問で、最初の仮説を出す

    疲れにくさ・周りの評価・続けたい理由から、主軸とサブの候補を出す。

    LIVEに効く理由出発点が決まると、「何を配信すればいい？」で止まらなくなります。

  3. 03

    強みを「続けやすさ×視聴者の反応」で見る

    上手いことだけでなく、毎回届けられる価値を言葉にする。

    LIVEに効く理由毎回同じ価値があると、視聴者が「この人を見る理由」を持てます。

  4. 04

    3回のLIVEで、仮説を確かめる

    楽だった？反応は？またやりたい？を記録して、続ける・調整する・外すを決める。

    LIVEに効く理由1回の反応で決めず、くり返し出る反応から強みを育てられます。

A〜Dは、公式の診断の4タイプ（雑談・コミュニケーション型／パフォーマンス・スキル型／知識・経験シェア型／キャラクター・非顔出し型）です。

一段上公式ページの4タイプと、それぞれのポイント慣れてからで OK

  • A 雑談・コミュニケーション型

    人の話を聞くのが得意・共感やリアクションが自然。毎回の定番テーマを作り、名前とコメントを覚える。

  • B パフォーマンス・スキル型

    歌・ダンス・ゲーム・料理・メイク・イラストなど。「見せる」だけでなく、視聴者を参加させる工夫を。

  • C 知識・経験シェア型

    旅行・留学の体験談、語学、仕事や趣味の経験。「専門家じゃないとダメ」と思う必要はない。

  • D キャラクター・非顔出し型

    顔出しに抵抗がある・キャラ設定や表現が好き。最初は設定をシンプルに。

公式の3つの質問で、最初の仮説を出す

LIVEの方向性は、最初から完璧に決めるものではありません。まずは公式の3つの質問に答えて、出発点を見つけます。

ここが要点

出てきたのは、まだ「あなたの正解」ではありません。最初の仮説です。雑談×特技のような組み合わせも、配信しながら見つけていきます。

なぜ、この3つを聞いたのか。1問ずつ意味を見ます。

3つの質問は、それぞれ何を見ている？

  1. Q1いちばん疲れにくいのは？

    → 続けられるかを見ています。LIVEは何度も続けるもの。疲れにくいことは、長く続けられる強みの候補です。

  2. Q2周りからよく言われるのは？

    → 自分では普通でも、人には価値に見えている所を見ています。配信の経験がなくても、日常の評価がヒントになります。

  3. Q3視聴者が少なくても、続けたい理由は？

    → 反応が少ない時期も続けられるかを見ています。始めたばかりは、見る人が少ない日もあります。

3問で見えてくるのは、「上手いこと」だけではない強みです。

強みは「上手い」だけではない

続けやすさと相手の反応。両方を見ると、強みの使い方が変わります。

ファン化・応援につながる理由

  • 強み × 視聴者の欲しいもの × くり返し、で関係が育つ

    同じ強みでも、誰のどんな気持ちに応えるかで、好かれ方が変わります。

    1. 1あなたの強み
    2. 2視聴者が欲しい気持ち
    3. 3くり返される体験
    4. 4「この人の、この時間」
    5. 5期待して、また来る

  • 一貫した価値が、期待を作る

    毎回同じ価値があると、視聴者は「この人のLIVEなら○○」と期待できます。期待どおりの体験が、見続ける・話す・また来る、につながります。

    「このスタイルなら伸びる」という話ではありません。
