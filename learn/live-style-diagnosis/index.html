自分に合うLIVEスタイルを見つける

診断から始めません。まず4つのLIVEの場面を見て、続けやすくて視聴者にも喜ばれる「自分の強み」を1枚にします。

このページでは

  1. 1知る4つのLIVEの場面を見る
  2. 2自分に合わせる診断して、自分の強みを1枚にする
  3. 3次のLIVEで試す3回のLIVEで、仮説を確かめる

読み終わると「自分は○○を武器に、△△を視聴者へ届けてみる」と言えます。

A〜Dは、公式の診断の4タイプ（雑談・コミュニケーション型／パフォーマンス・スキル型／知識・経験シェア型／キャラクター・非顔出し型）です。

どれが「一番すごいか」を選ぶ診断ではありません。あなたが自然に続けやすい入口を探します。

では、公式の3つの質問に答えて、あなたの入口の候補を出します。

自分にする選ぶ

公式の3つの質問で、最初の仮説を出す

LIVEの方向性は、最初から完璧に決めるものではありません。まずは公式の3つの質問に答えて、出発点を見つけます。

ここが要点

出てきたのは、まだ「あなたの正解」ではありません。最初の仮説です。雑談×特技のような組み合わせも、配信しながら見つけていきます。

なぜ、この3つを聞いたのか。1問ずつ意味を見ます。

知るなぜ？

3つの質問は、それぞれ何を見ている？

  1. Q1いちばん疲れにくいのは？

    → 続けられるかを見ています。LIVEは何度も続けるもの。疲れにくいことは、長く続けられる強みの候補です。

  2. Q2周りからよく言われるのは？

    → 自分では普通でも、人には価値に見えている所を見ています。配信の経験がなくても、日常の評価がヒントになります。

  3. Q3視聴者が少なくても、続けたい理由は？

    → 反応が少ない時期も続けられるかを見ています。始めたばかりは、見る人が少ない日もあります。

3問で見えてくるのは、「上手いこと」だけではない強みです。

知るたとえば

強みは「上手い」だけではない

続けやすさと相手の反応。両方を見ると、強みの使い方が変わります。

例

2つの例

  • 例1　歌が上手い

    でも、毎日は疲れる → 特別な回の枠に強い

  • 例2　話を聞くのは、普通

    でも、視聴者から「話しやすい」と言われる → 毎日の軸の候補

では、あなたの場合は？ 診断の結果を、自分の言葉にします。

深める

一段上の攻略ポイント

ここから先は、必要な人だけ。上までで、次のLIVEはもう始められます。気になる見出しだけ開いてください。

読み飛ばして先へ
  1. 01楽さ × 反応の4マスで見る開く

    慣れてきたら、試したことを2つの軸で置きます。

    反応が弱い反応が強い
    疲れにくい届け方・合う人を見直す主軸の候補
    疲れやすい一度外す候補特別な回の候補

    コツ

    1回だけ反応が弱くても、すぐ外しません。何回か同じことを試し、くり返し出てくる反応を見ます。これは上級運用の考え方で、決まった回数の基準ではありません。

  2. 02スタイルごとに、視聴者がしていること開く

    同じLIVEでも、視聴者の役わりと、好きになる理由が違います。

    1. A 雑談

      視聴者がしていること
      話す・聞いてもらう
      好きになる理由
      自分を見てもらえる・話を聞いてもらえる

    2. B パフォーマンス

      視聴者がしていること
      見届ける・選ぶ・励ます
      好きになる理由
      成長を見届ける・感動する・一緒に達成する

    3. C 知識・経験

      視聴者がしていること
      質問する・自分の例を話す
      好きになる理由
      分かるようになる・相談できる・信頼できる

    4. D キャラクター

      視聴者がしていること
      世界に入る・合言葉で参加する
      好きになる理由
      世界観に入れる・共通の言葉を持てる

    スタイルを選んで見る

    スタイルだけでは、ファンにはなりません。あなたの強み × 視聴者の欲しいもの × くり返される体験で考えます。

  3. 03スタイルは檻ではない。組み合わせで育てる開く

    診断の後に、「私は雑談だから歌わない」のような決めつけを作りません。

    例

    組み合わせの例

    • A ＋ C：会話の中で、学びを1つ

    • B ＋ A：練習を見せながら、雑談

    • D ＋ B：キャラのまま、歌やゲーム

    ここが要点

    視聴者の反応と自分の感覚で、何度でも更新します。

  4. 04伸び方との関係は、こう考える開く

    「このスタイルなら伸びる」という決まりはありません。

    1. 1

      毎回同じ価値がある

    2. 2

      「この人のLIVEなら○○」と期待できる

    3. 3

      見続ける・また来る

    コツ

    LIVEで反応がよかった場面を短いショート動画にすると、どこに反応が集まるかを確かめられます。少ない反応を、絶対の結論にはしません。
