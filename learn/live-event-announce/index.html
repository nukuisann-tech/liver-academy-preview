ショート動画

予定を登録するのではなく、会いに来たくなる約束をLIVE EVENTで、配信前から「見に来たい」をつくる方法

  • 原本：配信を事前に予告する　LIVE EVENT機能

LIVE EVENTは、次のLIVEの予定を前もって知らせ、興味のある人が登録できる機能です。次の1回を企画し、来たくなるタイトルを付け、ショート動画とつなぎ、当日は予告した体験を届けて、登録・来た・また来たを分けて振り返ります。

LIVEの集客は、配信を始める前から始まっています

こんなことで迷っていませんか。

  • LIVEを始めても、なかなか人が来ない
  • 次のLIVEをどう知らせればいいか分からない
  • LIVE EVENTという機能を知らない。予定だけ伝えても来ない

視聴者は、あなたの配信時間をいつも覚えているとは限りません。次のLIVEの予定を、前もって知らせることには意味があります。

ただし、日時を登録するだけでは足りません。そのLIVEで何を楽しめるのかまで伝えて、当日はその体験を届けます。

解決すると、こんな状態へ

次のLIVEを1つ企画して、来たくなるタイトルを付け、LIVE EVENTを作って状態を確かめ、3つの方法から1つでショート動画とつなげます。告知の台本と当日の進め方を用意し、登録・来た・また来たを分けて振り返れます。

たとえば、学んだあとのミオさん（架空）。

  • 「金曜21時｜最近の小さな失敗を、みんなで笑い飛ばす夜」とタイトルを付けた。
  • 前回の雑談の切り抜きを関連投稿にして、前日に企画の理由を1行足した告知を出した。
  • 当日は最初に「今日は予告していた失敗談のLIVEです」。終わる前に次の予告をした。

「配信を始めてから視聴者を待つ人」から、「配信前から会いに来たくなる理由をつくれる人」へ。

まず、LIVE EVENTが何をする機能なのかを見ます。

LIVE EVENTは、次のLIVEを前もって知らせる機能

LIVE EVENTは、次のLIVEの予定を前もって知らせ、興味のある人が予定を登録できるTikTokの機能です。動画から配信の予定を伝えておくと、配信前に知ってもらいやすくなり、当日来てもらうきっかけになります。

目的伝えること
予定を知らせるいつ始まるか
中身を伝える何を楽しめるか
予定を残せるようにする興味がある人が、イベントを確かめて登録できる
ショートとLIVEをつなぐ動画を見た人が、次のLIVEに興味を持つ入口
次も楽しみにしてもらう一度きりで終わらず、次の回も待ちたくなる体験

注意

公式のランキングイベントとは別のもの

ここで扱うLIVE EVENTは、自分の配信予定を知らせる機能です。TikTokが開催するランキングやミッションのイベントとは違います（そちらは「イベントで関係と成長を育てる方法」で扱います）。また、TikTok Shopのお店向けのイベント管理とも別の機能です。

LIVE EVENT 4ステップ

  1. 1

    DISCOVER

    知ってもらう（ショート・プロフィール・LIVE中の予告）

  2. 2

    WANT

    楽しみにしてもらう（何を・なぜ・誰に）

  3. 3

    REGISTER

    予定を残してもらう（希望する人だけ）

  4. 4

    ATTEND

    当日、予告した体験を届ける

Academyの整理で、TikTokのしくみの説明ではありません。

登録数より大切なのは、登録したくなる理由と、当日の満足感。

次に、見る側からはどう見えるのかを確かめます。

見る人からは、どう見える？登録・通知・カレンダー

視聴者がイベントを登録する流れです。画面は変わることがあります。

  1. クリエイターのプロフィールを開く

    動画に表示された予定から開ける場合もあります。

  2. LIVE Eventを選ぶ

    予定されているイベントが並びます。

  3. 見たいイベントを選んで登録する

    登録したイベントについて、お知らせを受け取れる仕組みがあります。

  4. 必要ならカレンダーに追加する

    スマホのカレンダーに予定を入れられる場合があります。

  5. 当日、来るかどうかを決める

    登録をやめることや、イベントを共有することもできます。

覚えておくことなぜ
登録は自由登録していない人も、LIVEに来られる
登録した人が必ず来るわけではない当日の予定や気分は変わる
お知らせが全員に必ず届くとは限らない通知の設定や受け取り方は人によって違う
日時は、見る人の地域の時刻で表示される動画の中に日本時間で書いた時刻と、イベント画面の時刻がずれて見える人がいる（海外の視聴者など）

しくみが分かったら、あなたの次のLIVEを1つ決めます。

STEP 1〜2：次のLIVEを1つ決めて、来たくなるタイトルを付ける

最初から、いくつもイベントを作らなくて大丈夫です。次の1回だけ決めます。

例

決める4つ（架空の例）

  • いつ？

    金曜21時

  • 何をする？

  • 誰に来てほしい？

イベントのタイトルを見くらべる

  • 雑談

    よくない
    「今日もLIVEします」
    より良い
    「金曜21時｜仕事終わりのゆる雑談」
    上級の言い方
    「金曜21時｜最近の小さな失敗を、みんなで笑い飛ばす夜」

日時の案内だけでなく、来ると何を楽しめるかが伝わるようにします。型はどんな人に＋楽しめること＋日時。

ジャンルタイトルの例
雑談「水曜22時｜一日の終わりに、最近の小さな幸せを話す夜」
ゲーム「土曜20時｜あの難関ボスに再挑戦。成功するまでの道のりを見届けて！」
音楽「日曜21時｜秋の夜に聴きたい曲を届けるLIVE」
コラボ「金曜20時｜初コラボ！ お互いの意外な一面を話す夜」
参加型「土曜21時｜みんなのおすすめ映画を持ち寄る雑談LIVE」

注意

実際にできない内容は約束しません。結果が分からない挑戦は、成功を約束するタイトルにしません。

STEP 4：ショート動画とつなぐ、3つの方法

あなたに合う方法は？

  1. A すでにある動画

    TikTok Studioで作ったイベントに、投稿済みの動画を「関連投稿」として選ぶ

    流れ
    TikTok Studio → LIVE EVENTS → 配信スケジュールを設定 → イベントの詳細で「関連投稿」 → 最新の投稿動画などを選ぶ → 完了
    どう見える？
    動画の左下に、LIVEの予定が表示される
    向いている時
    次のLIVEに関係する動画が、もうある
    画面の例
    関連投稿の欄に、動画を足す「＋」。何本か選べるという案内もあった

  2. B 新しく作る動画

    新しい告知動画の投稿画面で「リンクを追加」からイベントを選ぶ

    流れ
    投稿画面 → 「リンクを追加」 → 「LIVE EVENTS」 → 「イベントの選択または作成」 → イベントを選ぶ → 投稿
    どう見える？
    動画の左下に、配信予定が表示される
    向いている時
    特別な企画や次のLIVEを、新しい動画でまっすぐ紹介したい
    投稿前に
    正しいイベントか・日時は合っているか・動画とLIVEの中身は合っているか・イベントは公開できる状態か

  3. C ステッカー

    新しい動画の編集画面で、LIVE EVENTのステッカーを貼る

    流れ
    編集画面 → 「ステッカー」 → LIVE EVENTSのアイコン → イベントを指定 → 好きな位置に置く → 投稿
    どう見える？
    動画の中に、配信予定が表示される
    向いている時
    日時を、動画の中で目立たせたい
    置く場所
    顔や大事な字幕を隠さない・日時が読める・画面のボタンと重ならない

    日付の文字や画像を自分で貼るのと、LIVE EVENTの機能でつなぐのは別のことです。

タップで切り替えて、3つの方法を見くらべる

3つ全部を使う必要はありません。自分の状況に合う1つを選びます。

方法主な使い方おすすめの時
A すでにある動画とつなぐ前に出した動画を生かす次のLIVEに関係する動画がある
B 新しい動画にリンクを足す告知の動画を新しく作る特別な企画や次のLIVEを、まっすぐ紹介したい
C ステッカーを貼る動画の中で予定を見せる日時を目で見て分かるようにしたい

用語

1本ずつ選ぶ？ まとめて付ける？

記事の画面例には、関連投稿を1本ずつ選ぶ欄のほかに、「全動画にイベントのリンクを追加」という切り替えもありました。まとめて付けられる画面がある時でも、次のLIVEと関係のない動画にまで付けるかは、よく考えて。再生数が多いだけの、中身の違う動画から来た人は、期待と違って感じるかもしれません。何本選べるか、まとめて付けられるかは、アカウントや時期で変わることがあります。

コツ

どの方法も出てこない時は

ボタンを探し続けなくて大丈夫です。作る場所（アプリとTikTok Studio）を確かめて、それでも使えなければ、ショート動画やプロフィール、LIVE中の予告など、ふつうの方法で知らせます。このあとの台本や予告の流れは、そのまま使えます。

方法が決まったら、どの動画とつなぐかを選びます。

    より良い

    上級の言い方
    動画を見た人の興味と、次のLIVEで楽しめることをそろえる

  1. 1

  2. 2

日時だけの広告で終わらせず、企画の魅力そのものを伝えます。

告知の台本の例

  1. 共感型（雑談）

    冒頭
    「仕事終わりって、誰かとちょっと話したくなる夜ありませんか？」
    背景
    「最近、小さな失敗をしてしまって、今では笑い話なんです」
    告知
    「金曜21時から、みんなの最近あった失敗談を話す雑談LIVEをやろうと思っています」
    案内
    「LIVE EVENTも作ったので、興味があれば予定を確認してみてください。見るだけでも歓迎です」
    なぜ伝わる？
    共感・人柄・楽しめる企画・入りやすさが一度に伝わる

  2. 挑戦型（ゲーム）

    冒頭
    「前回、どうしてもクリアできなかったステージがあります」
    背景
    「何度も失敗したんですが、次こそ挑戦したいです」
    告知
    「土曜20時から、もう一度やってみます」
    案内
    「どうなるか気になる人は、LIVE EVENTで予定を確認してみてね」
    なぜ伝わる？
    まだ終わっていない挑戦の結果を、見届けたくなる（成功は約束しない）

  3. 参加型（映画）

    冒頭
    「みんなのおすすめ映画、聞いてみたいです」
    内容
    「次のLIVEでは、最近見てよかった映画を話そうと思っています」
    日時
    「土曜21時からです」
    案内
    「映画好きな人は、よかったら遊びに来てください。LIVE EVENTからも予定を確認できます」
    なぜ伝わる？
    共通の好き・参加する理由・会話の入口がある

タップで切り替えて、3つの台本を見くらべる

台本ができたら、いつ・何回知らせるかを決めます。

STEP 7：知らせ方と、登録の案内

告知の4段階（例）

  1. 1

    3日前

    ちょっとした予告：「今週末、新しい企画を考えています」

  2. 2

    前日

    背景と見どころ：「○○をみんなと楽しみたくて」

  3. 3

    当日

    当日の案内：「今日21時から、いよいよ○○」

  4. 4

    翌日

    振り返り：「昨日のLIVEで、こんなことが」

Academyの提案で、TikTokがすすめる回数ではありません。回数をこなすことではなく、毎回ちがう価値のある情報を届けることが目的です。

登録の案内のしかた

  • 短く

    より良い
    「次のLIVEの予定をLIVE EVENTに登録しました。気になる方は、プロフィールや動画に出ているイベントから予定を確認できます」

  • 少し詳しく

    より良い
    「イベントに登録すると、TikTokの通知で予定のお知らせを受け取れる仕組みもあります。無理に登録しなくても大丈夫なので、気になる方は使ってみてください」

登録を強制しない・義務にしない・お知らせが必ず届くとは言わない。

一段上の攻略ポイントXやメールでも知らせるなら？すでに使っている場所があれば、同じ企画を、毎回ちがう角度から届けられます。深掘りする ＋閉じる －
順番Xの投稿（例）メールの件名（例）
1 予告「今週末のLIVE、いつもと少し違う企画を準備しています」【今週末】次のLIVEで、ちょっと特別な企画をします
2 背景・見どころ「前回のLIVEで○○の話がすごく盛り上がったから、あの続きを一緒に」明日のLIVE、こんな時間にしたいと思っています
3 当日「本日21時から。時間が合う方は、ぜひ遊びに来てください」【本日21時】今夜のLIVEのお知らせ
4 終わったあと「昨日は映画の話で盛り上がりました！ 次は○○も話したいな」昨日のLIVE、ありがとうございました

Academyが足した応用例です（記事にあった内容ではありません）。メールは、読者が受け取ることに同意しているリストがある時だけ。XやメールはLIVE EVENTを使う条件ではなく、使っていない人がやる必要もありません。

ここが要点

判断できること

同じ告知をくり返すのではなく、予告 → 理由 → 当日 → 振り返りで、毎回ちがう「来たくなる理由」を足す。次の告知では：前日の投稿に「なぜこの企画をやるのか」を1行入れます。

ここから当日です。予告した体験を届けます。

STEP 8：当日は、予告した体験を届ける

予告した内容を、当日楽しめること。

当日の言い方

  • 始まってすぐ

    より良い
    「こんばんは！ 今日は予告していた、みんなの最近の失敗談を話すLIVEです」

  • 途中で来た人へ

    より良い
    「今来てくれた方、こんばんは！ 今日は最近あった小さな失敗談を話しています」

  • 終わる前

    より良い
    「今日はみんなの話を聞けて楽しかったです。次は○○の話もしてみたいですね」

コツ

コメントが少なくても進められるように

告知したテーマを中心に進めます。コメントが少ない時に備えて、自分で話せる失敗談やエピソードを2〜3個用意しておきます。

LIVE EVENTがうまくいったかは、登録の画面だけでは決まりません。

予定が変わった時の対応も、先に決めておきます。

STEP 9：予定が変わった時

こんな時すること
始まるのが遅れる分かった時点で、告知の内容を直す

ここが要点

最後に、結果を分けて振り返ります。

STEP 10：登録・来た・また来た、を分けて見る

分けて見ること意味
REGISTERED　登録イベントを登録した人
ATTENDED　来た実際にLIVEを見た人
RETURNED　また来た次のLIVEにも戻ってきた人

登録した人と来た人が、一人ずつ結びついているとは確かめられないことが多いです。その時は「登録した人のうち何％が来た」とは計算しません。

終わったら確かめる

こんな時見直すこと（仮説）
登録が少ないタイトルと企画の魅力
登録はあるが、来る人が少ない時間帯・当日の案内・企画と告知のつながり
来ても、すぐ出ていく始まってすぐの進め方
来るが、また来る人が少ない次の企画と、終わる前の予告
