配信準備 / 入室

LIVEタイトルとカバーで「入る理由」をつくる

何をしているLIVEかを一瞬で伝え、入室後の体験までズラさない。

学んだ先に変わること

  1. 配信者がすること「今、何をしているか」を1行にする
  2. 視聴者何のLIVEかが、入る前に分かる
  3. 興味が合う人が入る
  4. LIVE入った後の体験と、期待がそろう
  5. その先「また入りたい」LIVEになる

攻略ノート

このコンテンツで学べること

  1. 01

    何をしているLIVEか伝える

    「誰か」や「気分」ではなく、「今、何をしているか」を1行にする。

    LIVEに効く理由視聴者は、タイトルを見て「どんな配信か」「興味がある内容か」を判断します。

  2. 02

    入室する理由を作る

    何をしているかに、参加のしかたや今日の特別を少し足す。

    LIVEに効く理由「入ったら何が起きるか」が分かると、入る理由になります。

  3. 03

    タイトル・カバー・中身を一致させる

    入る前に見せた期待を、入った後の体験で回収する。

    LIVEに効く理由期待と中身がズレると、入ってもすぐ離れてしまいます。

  1. STEP
  2. 01今、何をしているか
  3. 02タイトルを作る
  4. 03カバーと中身をそろえる
  5. 試すこと

STEP01今、何をしているか

最初は「今、何をしているか」で十分

LIVEタイトルは、視聴者が「おすすめ」であなたのLIVEを見かけたとき、最初に表示される一行の文です。

視聴者は、タイトルを見て「どんな配信か」「興味がある内容か」を判断します。だから、タイトルは空欄にしません。

タイトルは挨拶ではなく、「何をしている配信か」を伝えるもの。

BADやりがち

「暇」「雑談」「誰か来て」「おはよう」「新人です」「疲れた」

GOODこう変える

「夕飯作りながら雑談」「歌枠🎤｜リクエストOK」「深夜雑談｜無言OK」

なぜ良い？「誰か」や「気分」ではなく、「今、何をしているか」が分かります。

STEP02タイトルを作る

3つの部品で、自分のタイトルを作る

「今なにをする？」を軸に、今日の特別と参加のしかたを足して組み立てます。

ワークショップ

タイトル・ビルダー

書いた言葉から、3つの案ができます。最後は、自分の言葉で直します。

  1. 1今、なにをする？

  2. 2今日は何が特別？（なくても大丈夫）

  3. 3視聴者は、どう参加できる？（なくても大丈夫）

  4. 4自分の言葉に直す

    下の案を見ながら、自分のタイトルを1行に。

タイトルの案

わたしのタイトル

タイトルの3つの確認

3つともYESなら、そのタイトルでOKです。

STEP03カバーと中身をそろえる

カバーは「マイナスにならない」ことが大事

カバー画像は、必須ではありません。実際、多くのクリエイターはデフォルトのアイコンをそのまま使っています。

カバーを設定するなら、最低限この3つ

例

避けたいカバー

  • 黒い画面・部屋だけの写真

  • 顔が分からない写真

  • ライブの内容と関係ない画像

タイトルは「何をしている配信か」。カバーは「マイナスにならない」こと。

ここが要点

カバーは「見た目の約束」

主役が分かる・テーマと合う・小さく表示されても迷わない・タイトルと矛盾しない・情報を詰め込みすぎない。細かい文字をたくさん置きません。表示の切り取られ方は、アプリの更新で変わることがあります。

STEP の先へ

一段上の攻略ポイント

ここは読み飛ばしても、STEP 1〜3 だけで実践できます。もっと伸ばしたくなったら、気になる見出しだけ開いてください。

読み飛ばして先へ
  1. 01上級者は「入ったら何が起きるか」まで伝える開く

    「今、何をしているか」に、入る理由と参加のきっかけを少し足します。全部を詰め込みません。

    例

    例

    • 仕事終わり雑談｜今日一番疲れた話きかせて

    • 初見で○○攻略｜詰んだら助けて

    • リクエスト1曲ずつ歌います

    コツ

    決まった文字数はありません。入力できる長さは、アプリの更新で変わることがあります。

  2. 02「気になる」と「分からない」は違う開く

    気にさせるのは良いこと。でも、何のLIVEか分からないのとは別です。

    BADやりがち

    「ヤバいこと起きました」——何の配信か分からない。

    GOODこう変える

    「初見○○攻略｜今日ラスボスまで行ける？」——テーマが分かった上で、先が気になる。

    なぜ良い？まず理解。そのあと興味。

  3. 03タイトルは「期待の約束」開く

    タイトルとカバーで作った期待は、入った後の最初の体験で回収します。

    1. 1

      タイトル・カバー

    2. 2

      期待

    3. 3

      入る

    4. 4

      最初の体験

    5. 5

      残る・離れる

    BADやりがち

    タイトルは「歌います」。入ったら、ずっと無言で設定中。

    GOODこう変える

    始めたら、すぐ1曲目を歌う。

    なぜ良い？期待と中身がそろうと、入った人ががっかりしません。

  4. 04タイトルとカバーは、別々に作らない開く

    タイトル＋カバー＋入った瞬間の画面を、ひとつのセットとして考えます。

    BADやりがち

    タイトルは「弾き語り」なのに、カバーはゲームの機材。

    GOODこう変える

    タイトルもカバーも画面も、弾き語りで統一する。

    なぜ良い？期待が割れず、入る理由がはっきりします。

    自分らしい色・言葉・雰囲気を、カバーに少し残すと、「この人だ」と分かる目印になります。くわしくは、関連コンテンツ「『キャラ』の作り方」で。

ファン化・応援につながる理由

  • タイトルは「今日の物語の入口」でもある

    タイトルは、新しい人だけでなく、いつもの視聴者への「今日、何する？」でもあります。

    1. 1いつもの雑談の人
    2. 2「今日は視聴者の恋愛相談だけ」
    3. 3常連も、今日の回を分かって入れる

  • 参加できるLIVEなら、タイトルに参加のきっかけを

    「次の曲をコメントで決める」「AとBどっちがいい？」「初見攻略｜ヒント歓迎」のように、参加のきっかけを入れられます。

    視聴者が選んだのに、結果に反映しない設計にはしません。

    1. 1参加のきっかけ
    2. 2視聴者が選ぶ・書く
    3. 3結果に反映する

SNSとLIVEで、言葉を育てる

  2. LIVEタイトルで試す
  3. LIVEで反応された言葉
  4. 次のショート動画へ

くり返す

最後の「次のショート動画へ」から、最初の「ショート動画・SNSで反応された言葉」へ戻る

ショート動画やSNSで反応が集まった言葉を、LIVEタイトルの仮説に使えます。逆に、LIVEで反応された言葉を、次のショート動画のタイトルへ。

同じ内容で、タイトルだけを変えて何回か比べます。一度で結論を出さず、タイトル・カバー・時間・内容を一度に全部変えません（1回1仮説）。

やってみる行動

反応が良かった言葉を1つ選び、次のLIVEタイトルに入れてみる。

少ない数の反応を、絶対の結論にしません。
