集客・成長

TikTok LIVE 成功の教科書｜偶然じゃない！再現できる成長の仕組みLIVE GROWTH ENGINE

  • 原本：セミナー資料（6.29 まとめ）

LIVEが伸びる仕組みを「流入・滞在・ファン化」に分けて、自分の課題を見つけ、次の配信でやることを1つ決めます。13のテーマを、図で見て、読んで、試せる形にまとめました。

LIVEが伸びない。でも、何を直せばいい？

こんなことで迷っていませんか。

  • 人が来ない
  • 来てもすぐ帰ってしまう
  • 常連が増えない
  • 何から直せばいいかわからない

「伸びない」をひとまとめにすると、長く配信する・とにかく頑張る、になりがちです。でも、人が来ないのか、すぐ帰るのか、また来ないのかで、直す場所はちがいます。

LIVEの成長は、流入 → 滞在 → ファン化の3つのエンジンで考えられます。どこで止まっているかが分かれば、次にやることが1つに決まります。

解決すると、こんな状態へ

自分のLIVEの課題が、流入・滞在・ファン化のどこにあるかを見分けられます。最初の5秒の一言、最初の3分の進め方、道具箱の3つ、試す時間帯、変える1つを決めて、次のLIVEで試せます。

たとえば、学んだあとのミオさん（架空）。

  • 自分の課題は「滞在」だと分かる。
  • 初めて来た人へ、今何の話をしているか伝える、を1つだけ決める。
  • 次のLIVEで試し、反応を振り返って、次はタイトルを見直す。

「何となく配信を続けるライバー」から、「自分の課題と次の行動を判断できるライバー」へ。

まず、3つのエンジンの全体像から。

LIVEが伸びる仕組みは、3つに分けて考えられる

LIVEが伸びないと感じたら、最初に考えるのは「どこで視聴者が止まっているのか？」。そもそも見つけてもらえていないのか。見に来ても、すぐ帰ってしまうのか。楽しく見てくれていても、次のLIVEへ戻ってこないのか。原因によって、改善することは変わります。

初見は、入室しただけではファンにならない。最初の数秒で「見る理由」をつくり、その後の時間で「居場所」をつくる。

3つのエンジンの内側では、初めての人の気持ちが流入 → 注目 → 継続 → 安心 → 再訪と少しずつ進みます。どの段階で止まっているかが分かると、次に変えることが具体的になります。

最初のエンジン、流入から。人はどこから来る？

あなたのLIVEへ、人はどこからやって来る？

おすすめのLIVEから見つける人。プロフィールを開いて来る人。ショート動画を見て興味を持つ人。入口は1つではありません。まず、自分のLIVEに来る入口を考えてみます（「まだわからない」も正しい答えです）。ショート動画からの入口は「LIVEにまた来たくなる、ショート動画28選」で。

ここが要点

注目を引くことと、居心地をつくることは別

注目は「今ここを見る理由」。画面・声・話題で生まれます。居心地は「ここにいても大丈夫」という安心。見るだけでも歓迎され、途中からでも話が分かることで生まれます。注目だけでは帰ってしまい、居心地だけでは入ってきてもらえません。

すべての初見が、LIVEの最初から見ているわけではありません。配信開始直後、雑談の途中、常連との会話中、Match中、企画の終盤。人はいろいろな場面から入ってきます。だから、今の状況を短く説明する／見る理由をつくる／参加を強制しない、の3つを、配信の途中でも使えるようにします。

注意

入るたびに、最初からやり直さない

新しい人が入るたびに会話を最初からやり直すと、今いる人が置いていかれます。話題の切れ目など、自然なタイミングで短く説明します。誰が入ったか画面で分からないときも、「途中から来てくれた方へ」と、ときどき今の状況を伝えます。

よくある失敗最初の5秒でやってはいけない6つ無言・状況不明・いきなり要求…深掘りする ＋閉じる －

  2. 2状況不明

    本人の配信コンセプトと合わない、過剰な叫びだけで引き留めようとする。
