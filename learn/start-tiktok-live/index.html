配信準備

初LIVEは、この3ステップで始められる

練習 → 確認 → 開始。最初の1回を「完璧に」ではなく、安全に始めて、終えるところまで。

学んだ先に変わること

  1. 配信者がすることLIVEを始める流れが分かる
  2. 本番前に一度ためす
  3. LIVE「分からない」が減って、開始できる
  4. 自分で終えて、気づきを1つ残す
  5. その先2回目を、もっと良くできる

攻略ノート

このコンテンツで学べること

  1. 01

    LIVEを始める流れ

    LIVEの作成画面へ進み、確かめて、開始するまでの流れ。

    LIVEに効く理由流れが分かると、開始ボタンの前で迷わなくなります。

  2. 02

    本番前に一度試す意味

    いきなり本番にせず、カメラ・音・明るさなどを一度見ておく。

    LIVEに効く理由「分からない」が減るほど、始めるのが怖くなくなります。

  3. 03

    初配信で何を成功と考えるか

    人数や反応ではなく、「始めて、終えて、気づきを1つ残す」を合格にする。

    LIVEに効く理由1回目が基準点になり、2回目を良くできます。

  2. 01入口を知る
  3. 02本番前に試す
  4. 03成功の条件を下げる
  5. 試すこと

STEP01入口を知る

LIVEを始める入口は、1つとは限らない

TikTokアプリには、LIVEの作成画面へ進む入口があります。入口は1つとは限りません。

例

公式ページで紹介されている入口（記事作成時点）

  • 画面中央の「＋」から、下のメニューで「LIVE」を選ぶ

  • 画面左上の「LIVE」から、「LIVEを開始」を選ぶ

ここが要点

大事なのは、LIVEの作成画面へ入れることです。ボタンの位置を暗記する必要はありません。画面が変わったら、アプリの最新の表示に従います。

  • 音声チャット

    顔を出さずに、視聴者とおしゃべりするLIVE

  • デバイスカメラ

    カメラを使って配信する、一般的なLIVE

  • モバイルゲーム

    ゲームをプレイしながら配信するLIVE

  • LIVE Studio

    パソコンを使った、より本格的なLIVE

気分やスタイルに合わせて、配信方法を選べます。

STEP02本番前に試す

いきなり本番にしなくていい

設定から、自分だけが見られる練習で試したり、公開する範囲を選んだりできます。

本番前に一度見るだけでも、不安は減ります。

本番前に、一度見るもの

映っていないか、見ておくもの

コツ

練習できる機能や公開範囲の名前・場所は、アプリの更新で変わることがあります。くわしい準備の確認は、別のコンテンツで扱います。

STEP03成功の条件を下げる

初配信の成功条件を下げる

準備ができたら、開始します。開始方法さえ分かれば、準備は十分です。気軽に、第一歩を踏み出します。

人数・フォロー・ギフト・完璧なトークを、1回目の合格の条件にしません。

    STEP の先へ

    一段上の攻略ポイント

    ここは読み飛ばしても、STEP 1〜3 だけで実践できます。もっと伸ばしたくなったら、気になる見出しだけ開いてください。

    読み飛ばして先へ
    1. 01「怖い」の正体は、分からないことが多い開く

      何が起きる？ 誰か来たら？ 音は聞こえてる？ 止め方は？——分からないことが多いほど、開始ボタンは重くなります。

      1. 1

        読む

      2. 2

        練習する

      3. 3

        一度見る

      4. 4

        本番

      ここが要点

      勇気を増やす前に、「分からない」を減らす。

    2. 02最初の配信で、全部直そうとしない開く

      終わったら、2つだけ書きます。

      終わった後に書くこと

      「次は○○を試す」まで決めたら、それが次のLIVEの目標になります。目標の立て方は、関連コンテンツ「LIVE目標は『数字』で立てる」で扱います。

    3. 03「初配信」は、弱みではなく参加のきっかけにもなる開く

      初めてであることを伝えると、視聴者が「教える」「声をかける」という役割を持ちやすくなることがあります。

      LIVE会話の例
      1. 配信者

        今日、初LIVEです。コメントの見え方を覚えたいので、何か一言もらえたら嬉しいです

      注意

      「初心者だから助けて当然」にはしません。お願いは軽く、断られても気にしない形で。

    4. 04開始前のルーティンを固定する開く

      毎回、判断し直さないための仕組みです。

      1. 1

        水

      2. 2

        充電

      3. 3

        カメラの画面

      4. 4

        今日の目標

      5. 5

        深呼吸

      6. 6

        開始

      これは儀式ではなく、開始までの迷いを減らす仕組みです。

    ファン化・応援につながる理由

    • 「初めて」を一緒に経験した人は、あとで共通の思い出になる

      初回からファンを作ろうと焦らなくて大丈夫です。ただ、初配信に来てくれた人とは、「初配信から見てる」という共通の思い出が残ることがあります。

      1. 1初LIVE
      2. 2来てくれた人
      3. 3「初配信から見てる」
