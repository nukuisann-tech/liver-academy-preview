LIVER ELITE ACADEMY

このサイトの使い方

ここは教材の棚ではなく、配信と配信のあいだで使う道具です。やることは 1 回の配信につき 1 つだけです。

  1. 入口診断で、始める場所を決めます。
  2. まだ配信したことがない人は、初配信までの道を 1 歩ずつ進みます。
  3. 配信の前に配信前の確認を開き、毎回の確認（BASELINE CHECK）と、今日伸ばす 1 つ（TODAY'S ONE FOCUS）を見ます。
  4. 配信のあとに配信後の記録で 4 つだけ記録し、次の 1 つを決めます。
  5. 配信の無い日は、学習マップから次の Lesson を 1 本読みます。

JavaScript が動かない環境では、「今日やること」の自動表示と記録の保存は使えません。Lesson・学習マップ・道具箱は、そのまま読めます。

学習マップ
初配信までの道と、15 の章 配信前の確認
BASELINE CHECK と ONE FOCUS 配信後の記録
4 つだけ記録する スキルと習熟
9 つのトラックと証拠 道具箱
チェックリスト・用語・事例・いまの仕様 ONE FOCUS の候補
次の配信で試す 1 つを選ぶ

初版は手元の Mac・ログインなし・ブラウザ内保存。これは最終形ではない。データは Database や API に載せ替えられる形（JSON）で持つ。
