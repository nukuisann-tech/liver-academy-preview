このサイトについて

これは初版です

このサイトは初版で、見た目は仮のデザインです。全体がつながって動くことを先に作ってあり、細かい所はこれから直します。

  • 初版は手元の Mac・ログインなし・ブラウザ内保存。これは最終形ではない。データは Database や API に載せ替えられる形（JSON）で持つ。
  • Lesson の「要点」「手本」と、一部の課題・「次の配信で試す 1 つ」は準備中です。準備中の所は、隠さずに「準備中」と出しています。
  • Lesson の「深く読む」には、もとになった教材（原本）の節を、要約せずに全文で出しています。
  • TikTok 公式のサイトではありません。段・チェックリスト・関門は、TikTok 公式の資格基準ではありません。
  • 検索エンジンには載せない設定にしてあります。

出どころの見方

このサイトの内容には、出どころの違うものが混ざっています。混ぜて見せないために、区分を 3 つに分けています。

印入るもの
① TikTok 公式（保存時点）原本で OFFICIAL が単独・明示で付いたブロックと、URL・確認日つきの [OFFICIAL] だけ。印の形を他と変える
② 教材・実例投入教材・実践者に由来する記述（原本の SOURCE、[SRC]）、支援ケース（「ある条件での実例」と添える）、この Project の実測（「実測」と添える。現在 0 件）、出典を示せる外部資料
③ 専門家の整理・補強（実データ未検証）原本内の専門 Agent の追加・推論（EXPERT ADDITION／INFERENCE）、この Project の補強（[EXPERT] の approved／conditional）、但し書き、タグの無い節、複合タグで分けられないブロック、制作（教材として作った例・クイズ）

変わる仕様 は区分ではなく性質です。TikTok の仕様のように変わることがある内容に、区分が何であっても重ねて付けます。保存時点の情報です。現在の条件は TikTok の公式案内で確認してください。

画面での出し方

  • Lesson の頭に、主な区分を 1 つ出します。主な区分がまだ記入されていない Lesson には印を出さず、「区分は未記入」と出します。
  • 「深く読む」の原本の節には、原本に付いているタグ（[SOURCE]・[EXPERT ADDITION] など）を、そのままの表記で出します。タグの意味は用語辞書の末尾にあります。
  • この Project の専門家（AI の専門 Agent）が足した補強は、点線の囲みと「専門家による補強（実データ未検証）」の見出しで、教材や公式の情報と分けて出します。
  • 「根拠を見る」を開くと、その Lesson の出どころの記録がすべて出ます。
  • 原本の中で記述が分かれている所には「原本の中で記述が分かれています」と出します。

区分は、内容の正しさを保証するものではありません。どこから来た情報かを示すものです。

考え方

  • 読んだことと、できることは別に見ます。段は、残した証拠でだけ動きます。
  • 1 回の配信で伸ばすのは 1 つ（ONE FOCUS）。安全・音と画面・進行の最低限（BASELINE CHECK）は毎回すべて守ります。
  • 人と比べる表示・順位・連続日数はありません。比べるのは自分の過去だけです。
  • 視聴者の気持ちを利用する手法（煽り・罪悪感・依存）は扱いません。
  • 入口診断
  • ONE FOCUS の候補
  • 設定・自分のデータ
  • このサイトについて／出どころの見方
